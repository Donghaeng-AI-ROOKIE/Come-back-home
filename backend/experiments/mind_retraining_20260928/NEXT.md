# 다음 판정과 남은 과제

1. 회피·조건의 부정·예외·미확인을 보강한다. 현재 학습72개에서 continue25개·avoid4개로 불균형이 있다. unknown을 false로 바꾸지 않고, 근거 문장을 입력 사실에 맞게 학습시키는 데이터 검수가 우선이다.
2. 2epoch를 최적값으로 확정하지 않는다. 개발 loss는0.4375→0.3922로 하락했지만 최종 행동은9/16이고 설명 오류가 남았다. 보강 데이터에서2·4·6epoch 체크포인트를 비교할 계획을 세우고, 초기화 seed·학습률 스케줄까지 고정한다. 이번에 추가 학습은 실행하지 않았다.
3. 서로 다른 사람·표현·복합 조건을 가진 새 평가를 사용한다. 이미 오답 분석한 개발·기존 K 평가를 새 독립 평가라고 다시 부르지 않는다. 독립 돌봄 경험자 검수와 실제 온보딩 저장 결과 연결도 필요하다.
4. 마음모델 후보가 확정되면 KINTEX에서 이동→트리거→해석→행동→상태 갱신을 연속 검증한다. 저장 응답의3초 재생과 고정 공급기의3시간 보행은 이 검증을 대신하지 않는다.
5. 직접 호출과 예산3/5/확장 조건의 재사용을 비교한다. 비용뿐 아니라 피로·환경·이력이 바뀐 사람에게 과거 답을 적용하는 오류와 시간별 확률지도 차이를 함께 평가한다.

현재 완료된 것은 실패 재현·연구용 전달/실행 계약·K 후보 비교·새 LoRA 첫 학습이다. 운영 교체·최적 호출 예산·실제 실종 경로 정확도·발견율은 확보되지 않았다.
