## 용어

- **골드셋 dev**: `experiments/mind_goldset/` 의 시나리오 G01~G08(측정 당시 구성).
  각 시나리오 × 상황 2종(A_귀소·B_불안) × 4회 표집 = 64콜. 판정자 3인(2/3 합의)
  라벨과 대조해 채점한다. G09~G20 은 제한적 홀드아웃 — 최종 측정 전 실행 금지.
- **계약 v2**: 마음 재해석의 1인칭 출력 계약
  `{inner, status, confusion_level(하/중/상), behavior(닫힌 4종), goal_label}`.
- **게이트(사전 등록)**: 행동 allowed 94% 수준 유지 + confusion 적합 90%+ +
  형식 무결(파싱 실패 0·어휘 밖 0) + 치명(FORBIDDEN) 0. 미달이면 배포하지 않고
  base 프롬프트-온리(실측 기준선)로 복귀한다.
- **행동 allowed / confusion 적합**: 골드셋 라벨의 허용 행동 집합 적중률 /
  혼란도 수치가 라벨 범위 안에 든 비율.
- **어댑터 판번**: v1 = 게이지 반향 혼란 라벨 데이터, v2 = 혼란 규칙 수정
  데이터(중증도·정보량 기반), v3 = v2 데이터 + NEFTune 5 + lr 5e-5.
  서버 보존 경로 `~/sar-ft/exaone-mind-lora-v{1,2,3}`.

## 2. 모델 4종 × RAG 유무 8셀 전수 비교

같은 dev 64콜, 계약 v2. RAG = 논문 발췌 청크를 참고지식 블록으로 주입.

| 모델 | RAG | 행동 | conf적합 | conf분포 하/중/상 | 형식 |
|---|---|---|---|---|---|
| base | off | 80% | 83% | 7/51/6 (유일한 3단 분화) | 안정 |
| base | on | 84% | 88% | 0/64/0 — 전원 "중" | 안정 |
| sar | off | 72% | 73% | 1/48/15 | 안정 |
| sar | on | 94% | 88% | 0/64/0 — 전원 "중" | 안정 |
| **mind-v1** | **off** | **94%** | **88%** | 0/63/1 | 안정 |
| mind-v1 | on | 94%* | 81% | 0/61/3 | **behavior 누락 30/64** |
| mind-v3 | off | 92% | 81% | 1/51/12 | 누락 2 |
| mind-v3 | on | 81% | 69% | 5/34/25 | 누락 17 + 어휘 밖 5 |

전 셀 치명 0. (*분모 34 — 누락 제외 착시.) 원본: `mind_goldset/results/` 8쌍.

발견 3가지:

1. **RAG 의 confusion 88%는 가짜 개선.** base·sar + RAG 는 64콜 전부 "중"을
   냈고, dev 라벨 대부분이 중을 포함해 무정보 전략이 88%를 얻는다. 따라서
   conf 90% 게이트는 분산 요건 없이는 "전부 중" 전략으로 게임 가능한
   왜곡 지표다 → 게이트 재설계 필요.
2. **튜닝 어댑터 + RAG = 형식 파괴.** 어댑터가 RAG-off 입력으로 학습돼
   참고지식 블록이 들어오면 분포를 이탈(behavior 누락 최대 30/64).
   마음 경로에서 RAG 는 이득 없이 해만 확인됨 — 제외 확정.
3. **LLM confusion 출력은 8셀 어디서도 정보성이 없다.** 3단 분화는
   base×off 뿐이고 고적합 셀은 전부 중 고정의 산물 → 혼란도를 LLM 책임에서
   빼고 규칙/게이지 기반 산정으로 전환하는 것이 구조적 해법(팀 합의 안건).

## 4. v4 재도전 준비 완료 (데이터 v5) — 학습 대기 중

v3 confusion 미스의 원인 특정: **학습 데이터에 기능 수준(중증도) 축이 부재.**
dev G03(작년 진단·초기 처방·대화 원활 → 기대 0.3~0.5)·G07(경증 발달·단독
이동 능숙 → 0.25~0.5)은 경증 신호가 입력에 가득한데, 데이터 생성기에
경증/중증 어휘가 0회 — 모델이 조건화할 대상 자체가 없었다. G08 은
"빈약→상 40%" 규칙의 과잉(0.85 출력, 기대 ≤0.8).

`build_dataset.py` 수정(생성기 v5):

1. 기능 수준 축 신설 — 경증/미상/중증(3:4:3)을 표집해 조각 조합식 문장
   (진단 시기 × 의사소통 × 이동능력, 셀당 27~48조합)으로 입력 노트에 삽입.
   미상은 문장 없음(신호 부재도 학습 대상).
2. `confusion_for` 에 기능 수준 반영 — 경증 한 단계 명료 쪽(단 정보 빈약
   archetype 에서는 차단, G08 기대와 정합), 중증 한 단계 혼란 쪽.
   빈약→상 40%→25% 완화.
3. 결과 분포: "하" 12%→16%, 경증 행 = 하 40%/상 3%, 중증 행 = 상 56%/하 0%.
   train 2,232 / val 446 (규모·논문단위 분할 동일 — 데이터 효과만 분리).

학습 레시피는 v3 그대로(NEFTune 5 + lr 5e-5 — 형식 안정 검증 조합).
사전 기준: confusion 81%→90%+ (특히 G03·G07 A_귀소 회복), 행동 92% 유지,
형식 무결, 치명 0. **유의: dev 미스를 보고 데이터를 고친 것이므로 dev 순환
최적화 위험이 있다 — v4가 dev 를 통과해도 최종 판단은 봉인 test 1회 측정.**

### v4 결과 (같은 날 실행) — 실패, SFT 라인 종결

행동 94%(49/52)·치명 0이나 confusion **73%**(v3 81%에서 후퇴), conf 분포

작동 — G03 미스 4→2, 하 출력 1→6 — 했으나 중증 상향 규칙이 과잉 일반화돼

## 6. 혼란도 규칙 산정 실증 — 16/16 (구조적 해법의 수치 근거)

"혼란도를 LLM 에서 분리해 규칙으로"라는 결론을 즉시 실증했다.
`mind_goldset/rule_confusion.py` — 파라미터 5개(기능수준 신호 차, 정보 빈약
분기, 상황 오프셋 +0.15, 기준값 3단)와 일반 표현 어휘만으로 보호자 진술에서
결정론 산정. **dev 16상황 전부 판정자 범위 적합(100%)** — LLM 최고치 88%
(그마저 전원-중 퇴화)를 상회. 판정자 합의가 가능했다는 것 자체가 혼란 판단이
소수 요인으로 설명된다는 뜻이고, 규칙은 그 요인을 직접 구현한 것이다.

정직한 한계: dev 를 보고 설계한 규칙이므로 100%는 적합도이지 일반화 증명이
아니다(파라미터 5개 vs LoRA 9.4M — 과적합 용량은 비교 불가하게 작음).
최종 판단은 봉인 test 1회. 운영 반영 시 어휘 매칭 대신 등록 챗봇의 구조화
필드를 직접 쓰므로 취약부(어휘 사전)는 사라진다.

**최종 제안 조합(팀 합의 안건)**: 행동·목적지·서사 = mind-v1 × RAG-off(94%,
형식 무결) + 혼란도 수치 = 규칙 산정(16/16). 이 조합은 게이트 전 항목을
구조적으로 충족한다. LLM 의 confusion_level 출력은 서사 정합용으로만 두고
하류(전략 가중)에서는 규칙값을 쓴다.

## 7. v5 = 규칙 증류 SFT (생성기 v6) — 86%, 최고 어댑터이나 미달. 하이브리드 확정

v1~v4 라벨이 rng 60/40 표집(같은 조건에 다른 정답 = 라벨 노이즈 → "중 도피"가
합리적 학습)이었다는 진단에 따라, 검증된 규칙(6절)을 결정론 교사로 증류:
라벨 = f(기능수준 문장, 정보빈약, 트리거, 게이지 극단 클램프) — 경증×귀소=하 /
중증×불안=상 / 그 외=중 (하 181·중 1,793·상 258). 레시피 v3 동일.

결과: 행동 **95%**(역대 최고)·goal **100%**·치명 0·상 과열 해소·형식 회복
(누락 2)이나 confusion **86%** — "하" 출력 0/64. 소수 클래스(8%)가 "중"으로
흡수돼 경증→하 판별(G03·G07 A_귀소 = 미스 9건 중 8건)만 전이 실패.

5판 궤적 88→70→81→73→86 종합: 잔여 실패가 소수 클래스 흡수 하나로 좁혀짐 —
유일하게 표준 처방이 존재하는 실패라 마지막 1판을 추가 실행(8절).

## 8. v6 = v5 + "하" 오버샘플링 (생성기 v7) — 최종판, 결과와 무관하게 튜닝 종료

처방: 교사 라벨 "하" train 행만 3배 복제(181→543, 8%→21%). val 은 무증량
(감시 왜곡 방지), 그 외 전부 v5와 동일(증류 교사·NEFTune 5·lr 5e-5).
train 2,594 / val 446. 사전 등록 기준: conf 90%+ (G03·G07 A_귀소 "하" 등장),
행동 92%+, 형식 무결, 치명 0.

**결과: 실패 — conf 73% (행동 91%·누락 0·치명 0). 튜닝 라인 종료.**
"하" 출력은 생겼고(0→16회) 표적 G07 A_귀소는 4/4 회복됐으나, 중증 G01·G06과
빈약 G08 에 "하"를 오발(9건)했고 같은 경증인 G03 은 여전히 4/4 "중".
6판 궤적 88→70→81→73→86→73 의 최종 해석: **7.8B 는 소수 라벨을 "내는 것"은
배우지만 "언제 내는가"의 판별 정밀도가 없다.** 규칙은 같은 판별을 16/16 으로
한다 — 하이브리드가 우연이 아니라 구조적으로 옳은 답.

**최종안(팀 합의 안건)**: 혼란도 수치 = 규칙 산정(rule_confusion.py, 운영은
등록 챗봇 구조화 필드 기반) + 행동·목적지·서사 = mind-v5(행동 95·goal 100·
누락 2) 또는 mind-v1(94·97·형식 무결) 택일. 봉인 test 1회는 운영 통합 확정 후.

## 9. 형식 누락 근본 수정 — 구조 강제 guided decoding (v5 재검증 완료)

v5 의 behavior 누락 2/64 원인 판독: 지식 문제가 아니라 디코딩 사고 —
(1) inner 내 개행 후 유사 JSON 붕괴 1건(내용은 정답이었음), (2) "집에 가고
싶다" 반복 루프로 JSON 미완성 1건. 처방과 실측:

- vLLM `guided_json` 으로 **JSON 구조·필수 필드만** 강제 + repetition_penalty
  1.05 → **누락 0·어휘 밖 0, goal 100%·conf 86%·행동 적중 동급(59→58/64),
  분포 자연 유지.** 게이트의 형식 항목이 구조적으로 충족된다.
- **함정 실측: 한글 enum 을 문법으로 강제하면 안 된다** — xgrammar 가 비ASCII
  리터럴을 UTF-8 바이트 이스케이프(\u00XX)로 컴파일해 모델이 학습 토큰을 못
  쓰고 출력 분포가 붕괴(은신·멈춤 2→57 왜곡, conf 전원 이탈). "구조는 강제,
  어휘는 모델"이 정답. 이스케이프 잔재는 latin-1→UTF-8 왕복 복원 가드로 처리
  (`exaone.py _fix_mojibake` — 정상 한글엔 구조적으로 무해).
- 구현: `exaone.py chat()` 에 guided_json/repetition_penalty 스위치(기본 None
  = 운영 무변경), 실험은 `first_person.patch` 가 주입. 운영 채택은 전환 PR 에서.

| 행동 allowed | 91~95% | **83%** (중립 16, G14 에 4건 집중) |
| 혼란도 — 규칙 | 100% | **88%** (이탈 3 = G15B·G16A/B, 어휘 사전 한계) |
| 혼란도 — LLM | 86% | **92%** (중 89/96 — 중 우세 전략) |

판독: (1) dev→test 하락 = dev 순환 최적화 거품이 걷힌 실제 일반화 수치 —
예고했던 현상이며 이 값이 정직한 인용 기준. (2) 안전 축(치명·서사·형식)은
봉인셋에서 완벽 일반화 — "개인 근거 우선" 핵심 주장 유지. (3) 혼란도는
test 에서 LLM 92% > 규칙 88%(오차 수준, 둘 다 중 우세). 규칙 이탈 3건은
전부 어휘 매칭 한계로, 운영의 구조화 필드 산정에서는 구조적으로 사라지는
부분. 하이브리드 확정안 유지 권고 + 팀 자료에 LLM 단일 92% 병기가 정직.

표현 규율 적용 문구: "합성 골드셋의 제한적 홀드아웃(생성 관여자 작성) 12종
96콜 기준 — 치명 위반·서사 오염·형식 결함 0, 행동 허용범위 83%, 혼란도
88~92%. 실제 실종자 행동 분포의 재현 주장은 하지 않는다."
