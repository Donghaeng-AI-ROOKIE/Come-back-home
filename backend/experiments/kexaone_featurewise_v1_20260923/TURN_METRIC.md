# 방향 전환 보조 지표 정의

24회 생성 진행 중, 새 출력 내용·새 경로 결과를 열람하기 전에 기존 path_stats 구현을 확인하여 정의. 추가 API 호출·보행 실행은 없으며 승인한 경로 파일에서 계산하는 진단 지표. 기존 동결 모델 입력·프롬프트·보행 코드는 변경하지 않음.

기존 turn_fraction은 인접한 두 변위 벡터의 값이 다른 비율이다. 방향이 같아도 변위 길이가 다르면 달라지므로, 그 값만으로 '갈림길에서 좌우로 자주 방향 전환'을 평가하기 어렵다. 기존 지표는 그대로 보존하고 아래 보조 지표를 추가.

- 선택 가능한 갈림길: 현재 노드에서 이전 노드를 제외한 서로 다른 다음 노드가 2개 이상인 경우. 실제 통행 가능성의 추가 교통·인지 판단은 아님.
- 각도: 저장된 동일 OSM 도로 폴리라인의 진입 끝 접선과 진출 시작 접선 사이 각도. 위도/경도는 이 지역의 근사 스케일(111/88 km)로 변환. 0도 직진, 180도 역방향.
- 옆 방향 전환: 위 갈림길에서 45도 이상 150도 미만.
- 큰 역방향/되돌아감: 이전 노드로 직접 되돌아가거나 150도 이상.
- 지표: 전체 방문한 갈림길 기회 중 옆 방향 전환 비율 및 45도 이상 전체 전환 비율. 분자·분모를 함께 저장. 경로가 특정 갈림길을 얼마나 방문하는지도 구성에 따라 달라질 수 있어, 동일 갈림길에서의 인과 선택 확률로 해석하지 않음.

각도 경계는 진단용 정의이며 치매 행동의 임상적 기준이 아님. 이 지표의 큰 차이가 정답이라는 기준도 두지 않음. 동일 사례·반복·시드 대응 비교와 원시 전략·경로를 함께 검토. 0기회 또는 접선 계산 불가 시 미확인으로 남기고 0%로 채우지 않음.
