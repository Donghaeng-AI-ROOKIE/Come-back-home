# D12 확대 개발 검증 — 반복 수정에 쓰지 않은 나머지 24명

고정 실패 입력8개에서 D12는62/64 장면, 조건 비교12/16, 보행10/14였다. 원문 재검토D14는63/64로 올랐으나 조건 비교12/16이며 새 오답도1장면 생겼다. 반복 재검토를 기본 구조로 채택할 근거는 없다. D12를 고정한 채 기존 개발 자료의 나머지24명을 확인한다.

## 입력과 비교

- 기존 dev128의 original 형식만 사용. 수리 실험의8개 root_id는 모든 표현형을 제외한다. 24명×2반복=48출력,4장면씩192판정.
- 환경4명·대기4명·외부상태4명·원문 충실성4명·시간3명·휴식2명·목적지2명·복합행동1명. 선택은 결과를 보기 전에 고정한다.
- 개발 자료이며 독립 최종 시험이 아니다. 과거 D2~D4 개발에 사용된 자료다. eval64와 사람 검토 서명은 건드리지 않는다.
- 모델에는 보호자 원문과 기존 장소·개인 해석만 제공한다. 장면·정답·점수·D4응답은 보내지 않는다.
- D12 모델·프롬프트·컴파일러·샘플링 그대로. 대문자 논리 연산자 허용 실험은 별도 오프라인 분석이며 이 묶음에 섞지 않는다.
- 같은 입력의 저장된 D4 출력48개와 장면·추가 조건·KINTEX 보행을 비교한다. 원자료와 기존 점수는 보존한다.

## 실행 범위와 기록

2026-10-08 사용자의 같은 목표 반복 개선 지속 지시에 따른 묶음이다. 최초48회+검증 실패 응답 수정 최대48회, K-EXAONE 최대96회. 실패 포함, 전송 자동 재시도 없음, 동시2회. 입력 요청40,000바이트·출력16,384토큰/호출, 전체 출력 상한1,572,864토큰. 수정은 검증 오류만 제공하며 정답 힌트를 주지 않는다. 시작/종료 원장을 공용 usage_events.jsonl에 남긴다. 단가·청구액·지원 차수·입력 토큰 사전 총량은 미확인.

신규 Mi:dm·RAG·임베딩·지도·GPU 학습·배포 없음. 저장된 KINTEX 실도로 지도와 같은 합성 시설·관측을 사용한다. OSM 장소 분류는 실제 소음·혼잡 관측이 아니다.

## 사전 판정

완료 후 기존 확대 검사 기준(전체 장면90%·각 행동군80%·supported/unknown 각각90%·실행 가능한 출력95%·측정 가능한 치명 오류0)을 보고한다. 추가 조건 검사48출력의90% 이상, 구별 가능한 보행 출력의90% 이상도 별도로 확인한다. 비측정·구별 불가·미완료는 성공으로 세지 않는다. 반복 동일성, 수정 전후, D4 대비 회복/퇴행을 함께 제시한다.

이 묶음만으로 배포나 임상 타당성을 선언하지 않는다. 문답 하나에 포함된 모든 특성의 보존은 아직 자동 측정하지 못한다. 규칙의 시작·종료·숫자·장소 범위 원문 검토와 실제 앱 연결 근거를 함께 사용한다. 실패하면 원문/정답 이견, 모델 해석 오류, 컴파일러/보행 오류를 구분한 뒤 다음 후보를 정한다.
