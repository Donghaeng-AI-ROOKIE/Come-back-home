# 실제 앱 합성 온보딩의 특성별 소비 범위

가상 보호자의 답변을 실제 앱이 물은 질문에 넣은 자료다. 아래는 AI의 코드·저장 응답 대조이며 전문가 판정이 아니다. 근거 ID를 달았다는 사실과 그 문답의 모든 의미를 행동으로 구현했다는 사실을 구분한다. 채점표의 기존 정답은 바꾸지 않는다.

| 원문에 있는 의미 | 현재 소비 위치 | 확인 범위와 남은 부분 |
|---|---|---|
| N0·N1: 세 장소를 보호자와 함께 방문 | 초기 `habitual_visit`, `accompanied_only`, 경로 익숙함0.3 | 저장값과 실제 Persona 사용 확인. 동행 경험이 독립 길찾기 능력이라는 뜻은 아님.0.3은 잠정 매핑 |
| N0·N1: 혼자 가는 곳은 없음 | 동행 경험으로 해석 | 혼자 외출한 적 없다는 관찰을 물리적으로 혼자 움직일 수 없다는 뜻으로 강제하지 않음 |
| N0·N1: 정해진 길·방향 없음 | 방향unknown | 특정 방향·회귀 경로를 개인 사실로 생성하지 않음 |
| N2: 과거 장소를 반복해서 찾지 않음 | 과거 목적지 없음 | 과거 집·직장을 마음 목적지로 추가하지 않음 |
| N3: 실종 경험 없음 | 발견 이력not_reported | 실제 경로 정답 없음. 길을 잠깐 잃은 N4와 완전히 같은 사건이라고 단정하지 않음 |
| N4: 길 잃음을 인지하고 보호자가 없을 때 기다림 | D12 조건부wait |500명×3장면에서 조건 밖 개인 대기와 필요한 대기 중 이동 없음 |
| N4: 보호자가 오면 기다림 종료 | wait 조건의 family_present=false |90분·230분 귀환 관측에서 해당 개인 규칙 해제 확인 |
| N4: 조건부 기다림이 초기 머무름 배율에도 쓰임 | 초기3배 가중과 마음 규칙이 동시에 적용 | 분리 후보 비교 완료. 통계 머무름은 보존. 문장별 근거 소유까지 자동 검증하지는 못함 |
| N5: 차도·물가·계단 회피는 모름 | 해당 개인 반응unknown | 도로 안전 행동을 관찰된 능력처럼 생성하지 않음 |
| N5: 해든상가에서 시끄러우면 밖으로 나옴 | 장소 한정avoid |소음 관측 시간과60m장소 근사 범위에서 확인. 인지 거리를 실측한 것은 아님 |
| N5: 다른 상가 반응은 모름 | 일반화하지 않음 | 이 합성 사례의 규칙은 해든상가에 한정 |
| N6: 방향을 잘못 들어 보호자가 알려줌 | 원문 보존, 익숙함 관련 정보 일부만 소비 | 보호자의 방향 안내에 실제로 고개를 돌리거나 경로를 바꾸는 상호작용은 미구현 |
| N6: 혼자 돌아올 능력은 모름 | 독립 경로 능력으로 확정하지 않음 | 동행 장소와 실제 기억하는 상세 경로는 서로 다름 |
| N7·N8: 이름을 부르면 보호자를 쳐다봄 | 원문 보존 | 고개·주시 방향과 호출자 인지 명령이 없어 실제로 구현되지 않음 |
| N7·N8: 낯선 사람·경찰 반응은 모름 | 개인 반응 생성 안 함 | 구조자 접근 반응 검증 미수행 |
| N9:6분 또는280m 중 먼저 도달하면 쉼 | 조건부rest |두 임계점과 보행 상태를 규칙으로 보존. 필요한 휴식 누락 여부까지 전원 검사 |
| N9:5분 앉아 쉰 뒤 다시 걸음 | hold_minutes=5 |완료된 휴식 구간의5분 길이 확인.6시간 종료에 걸친 휴식은 검열 구간으로 별도 기록 |
| N9: 천천히 걸음, 무릎 때문에 제약 | mobilityB·휴식 규칙 |개인 휴식은 반영. 개인 속도는 미반영이며 공통48m/분 사용.280/6을 실제 속도로 계산하지 않음 |
| N10: 불안할 때 이동 변화는 모름 | emotionunknown |관찰되지 않은 개인 불안 반응은 생성하지 않음. 엔진 공통 게이지의 가정과 구분 |
| N11: 약 누락·밤·추위·더위 반응 모름 | 원문 보존 |개인 반응으로 확정하지 않음. 미관찰과 반응없음은 다름 |
| N12: 요약 확인 “네, 맞아요” | 원문 보존 |어떤 요약 문장인지 분리된 자료만으로 모든 서술의 근거가 되지 않음 |

D12의 `unrepresented`는 문답별 일반 설명이며 일부 응답에서 같은 설명이 여러 문답에 반복된다. 이를 문장별 완전성 평가로 세지 않는다. 예를 들어 N9를 휴식 규칙이 인용했어도 같은 문답의 “천천히”가 속도로 실행되는 것은 아니다.

센터 검토에서 보여 줄 수 있는 것은 **관찰된 기다림·휴식·장소 한정 반응이 실제 도로 보행으로 연결되는 과정**이다. 모든 임상 행동, 모든 원문 특성, 실제 실종 위치의 재현을 완료했다고 설명해서는 안 된다. 미구현 의미는 버리는 대신 원문·근거와 함께 남겨 다음 엔진 기능과 평가 대상으로 연결한다.
