# 2026-10-08 후속 비교와 실제 앱 합성 사례 연결

최신 비교는 모두 완료됐다. **[현재까지 확인 결과](continuation/현재까지_확인결과.md)**부터 읽으면 된다. D12를 고정한 확대 개발24개에서는 조건별 행동 선택170/192→187/192, 구별 가능한 보행26/34→33/34였다. 실제 앱 질문에 합성 보호자가 답한 별도1개 사례에서는 두 응답 모두 작성자 기준의 실행 조건과3장면 보행을 보존했다. D13~D16은 후퇴 또는 보행 개선 부족으로 기본 후보로 채택하지 않았다.

이 PR은 연구 코드와 증빙이다. 온보딩 장소 유형·시각 비교 수정 및 새 장소별 실행기 코드는 같은 기반 브랜치에서 별도 수정 PR로 분리했다. 연구 결과를 운영 API에 연결하거나 배포한 상태는 아니다.

이 폴더는 작은 검토용 근거 묶음이다. 모델 최종 공개 응답·전체 원장·전 보행 데이터는 팀 결선/실험의 MIND_compact12_20261008, MIND_compact13_20261008, MIND_captured_initial_20261008, MIND_captured_policy_20261008, MIND_captured_walk_20261008에 있다. 링크가 외부 결선 폴더를 가리키는 부분은 로컬 재현 위치 안내다.

새 모델 학습이나 운영 배포는 하지 않았다. 합성 사례이고 전문가 정답·실제 실종 경로의 정확도가 아니다. 모든 모델 호출의 단가·실청구액·지원 차수는 미확인이다.
