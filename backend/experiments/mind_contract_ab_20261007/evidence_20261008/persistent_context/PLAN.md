# 미확인 상태의 대기 쏠림 수정 계획

- 목적: 저장된 개인 해석을 고정한 채 반복 행동 추첨이 대기를 누적시키는지 분리하고, 사실별 가정을 시간에 걸쳐 보존하는 실행 후보를 검증한다.
- 기준선: 제품 6810087, 연구 71b3b9e. 기존 결과·정답·D12 출력은 수정하지 않는다.
- 신규 모델·API·GPU·지도·임베딩 호출 0회. 기존 KINTEX GraphML과 합성 온보딩 캡처 재사용. 이번 범위는 로컬 CPU 계산이며 유료 호출 비용을 0으로 환산하지 않는다.
- 먼저 기준선에서 대상/행동 후보 변화와 대기 진입을 기록한다. 지도와 무관한 상태 전이 검사와 KINTEX 재생을 구분한다.
- 후보: 사실별 가정이 다른 행동의 발동·목적지 변경만으로 다시 뽑히지 않도록 보존한다. 관측은 가정보다 우선하며 만료 시에는 다시 미확인으로 표시한다. 가정은 임상 확률이나 실제 관측으로 표시하지 않는다. 지역별 환경·대상 장소의 인지는 분리한다.
- 명시적 대기 시간은 시작 시점부터 계산하며 매 검사마다 연장하지 않는다. 시간 미제공 대기는 임의의 개인 지속시간을 만들지 않는다.
- 같은 입력·D12 출력·초기 성향, seed 17/29/43, 각 500명·6시간·1/2/4/6시간 점검으로 기준선/후보 최대 6회. 알려진 휴식·장소 회피는 합성 부품 검사로 따로 회귀 검증한다.
- 판정: 새 정보 없이 같은 사실 가정을 다시 추첨하지 않음, 서로 배타적인 사실 동시 생성 없음, 관측 우선/만료/장소 구분/저장 복원, 명시 지속시간 준수, 기존 명시적 행동 유지. 대기가 적거나 이동거리가 길다는 이유로 성공으로 판정하지 않는다.
- 신규 가정은 민감도 비교 대상으로 남긴다. 실제 실종 위치 정확도·임상 현실성을 주장하지 않는다. 모델 자체의 우월성이나 운영 배포 완료 판정이 아니다.

## 추가 회귀 범위 (결과 확인 전 고정)

- 초기 후보의 저장 호환성과 완전히 알려진 조건의 행동 충돌 처리에서 회귀가 발견됐다. 원 결과를 보존하고 해당 두 부분을 고친 최종 소스로 3개 seed와 알려진 2장면을 다시 실행한다.
- 기존 D12 확대 개발24개×2응답=48개 저장 규칙에 대해 기준선/후보 각각 16명·4시간·seed17, 새 관측 없음으로 실행 호환성과 미확인 상태를 점검한다. 합성 시설·같은 초기 기본값을 쓰는 규칙 실행 검사이며 48명의 전체 온보딩 검증이나 정확도 평가가 아니다. 실패는 삭제하지 않는다.
- 미확인 자각의 가정값 민감도는 0.1/0.9 두 설정으로 동일한 캡처 사례·500명·6시간·seed17을 추가 비교한다. 실제 확률을 추정한 값이 아니라 결과가 가정에 얼마나 의존하는지 보여 주는 검사다.
- 이 추가 범위도 모델·GPU·지도·임베딩 호출 0회다.
