# D12 원문 재검토(D14) 결과

같은 K에게 저장된 D12 초안과 보호자 원문을 다시 주었다. 정답이나 검사 장면은 보내지 않았다. 자기 재검토이며 전문가 검토가 아니다.

| 검사 | D12 | D14 |
|---|---:|---:|
| 고정 개발 장면 |62/64|63/64|
| 조건 조합 추가 검사 |12/16|12/16|
| KINTEX 보행 특성 보존 |10/14|10/14|
| 사용 가능한 최종 출력 |16/16|16/16|

장면2개가 복구됐지만 이전에 맞던1개가 틀렸다. 장소 도착 조건의 누락, 휴식의 걷기 조건 누락, 자정 구간 해석 오류가 남았다. 점수1개 상승을 이유로 추가 재검토 호출을 기본 구조로 채택하지 않는다. D12를 고정해 수리에 사용하지 않은 나머지 개발24명으로 범위를 넓힌다.

D14 재검토 첫 응답은55/64, 검증 실패 수정2회 뒤63/64이다. 원래 D12 생성은17회였고, 이번 재검토에 추가18회를 사용했다. 총35회 파이프라인을17회 방식과 비교한 것이므로 추가 비용을 숨기지 않는다. 이번 원장은18회 시작/종료 일치·전송 오류0·132,816토큰, 금액·지원 차수 미확인이다.

16출력은8개 개발 문답의2반복이다. 독립 환자16명·임상 정확도·실종 위치 정확도가 아니다. 문답 안의 모든 특성 보존은 아직 측정 불가이며 보행에서 구별되지 않는2출력은 따로 표시했다.
