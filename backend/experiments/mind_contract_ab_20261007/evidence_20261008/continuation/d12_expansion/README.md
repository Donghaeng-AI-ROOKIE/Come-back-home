# D12 확대 개발 24개 사례 — 완료

보호자 문답에서 해석한 조건부 행동이 실제 KINTEX 도로 위 보행까지 보존되는지 비교했다. 기존에 고치던 8개 원형을 제외한 나머지 24개 합성 원형을 두 번씩 실행했다. 새 환자 48명이나 임상 평가가 아니라, 이미 결과를 본 개발 자료 24개에 대한 반복 비교다. 모델은 K-EXAONE, 후보 D12는 간단한 조건식 출력과 엄격한 실행 규칙 검증을 사용한다. 원문 단어를 코드가 행동으로 매핑하지 않는다.

| 확인한 것 | 이전 D4 | D12 | 뜻 |
|---|---:|---:|---|
| 작성한 4장면의 행동 선택 | 170/192 | 187/192 | 발동·해제·경계·미관찰 상황에서 작성자 참조와 일치 |
| 최종 실행 가능한 출력 | 44/48 | 48/48 | 수정 응답을 포함한 형식·실행 검증 |
| 추가 조건 조합 비교 | 38/48 | 43/48 | 작성한 4장면 밖에서 차이가 발견되지 않은 출력 |
| KINTEX 보행 보존 | 26/34 | 33/34 | 조건을 넣었을 때와 뺐을 때 구별되는 34개 출력만 분모 |

192장면은 24개 입력×2반복×4장면이다. 보행은 출력별 150명의 가상 보행자를 3개 합성 상황에서 6시간 연속 계산했다. 14개 출력은 기존 보행 검사로 특성 유무를 구분하지 못하여 성공률 분모에서 제외하고 따로 남겼다. 33/34는 실제 실종 위치 예측 정확도가 아니다.

장면 점수는 21개를 고치고 4개가 악화됐다. 보행 판별 가능 34개에서는 7개를 고쳤고 기존 성공의 악화는 없었다. 모델 응답 형식이 맞아도 의미가 다를 수 있으므로 형식 성공만으로 후보를 확정하지 않았다.

## 남은 차이

- 가족이 돌아오면 끝나야 하는 대기에 종료 조건을 빠뜨린 출력 1개. 실제 보행에서도 대기가 너무 길어졌다.
- 다른 사람에 대한 설명을 정정한 문답에서 대상 어르신 본인의 계속 걷기도 함께 버린 출력 1개. 기존 기본 보행도 걷고 있어 원래 검사에서는 구분되지 않았다.
- 이미 고정된 장소 유형 회피를 특정 장소 규칙으로 중복한 출력 1개. 현재 공간 정의와 추가 반례의 현실적 도달 가능성도 함께 검토해야 한다.
- 오전 시각 구간을 대기 지속시간 60분으로도 넣은 출력 2개. 현재 엔진은 대기를 매 시점 재검토하므로 보행은 같았지만 원문 해석 차이는 그대로 남긴다.

마지막 두 출력의 실행 효과만 비교하면 추가 조건 비교는 45/48이다. 이는 별도 보충 분석이며 원래 엄격 비교 43/48을 덮어쓰지 않는다. 또한 엔진이 명시적 대기 지속시간을 온전히 실행하지 못하는 문제를 성공으로 바꾸는 근거가 아니다.

## 검사 자체의 빈틈 보완

‘계속 걷기’를 뺀 출력을 구별하기 위해, 기본 성향을 모두 제자리 머무름으로 둔 별도 합성 장면을 만들었다. 길 잃음 인지가 10~20분에만 켜지고, 전체 30분 동안 150명을 계산했다. 도로는 같은 KINTEX 캐시다.

참조와 올바른 두 번째 출력은 평균 0.4797km를 걸었다. 계속 걷기를 누락한 첫 번째 출력은 0km였다. 따라서 원래 보행 검사의 ‘구분 불가’를 성공으로 세면 안 된다는 것을 재확인했다. 이 극단적 사전분포는 검사 구분력을 확인하는 가정이며 실제 치매 인구 비율이 아니다.

## 사용량과 증빙

K 호출 53회(최초48+수정5), 통신 오류0, 시작·종료 원장53쌍. 입력111,737토큰·출력258,247토큰·합계369,984토큰. 단가·실청구액·지원 차수는 미확인이다. API 경과시간을 GPU 과금시간으로 쓰지 않는다. 새 지도·임베딩·GPU 학습 없음.

주요 파일: `d12_dev24/scored.json`, `condition_probes.json`, `iteration_audit.json`, `engine_outputs_reused_v2.json`, `walking_paired_with_d4.json`, `explicit_walk_stress.json`, `usage_summary.json`.

결론: D4 대비 개인 조건 전달 개선 근거는 확보했다. 개발 자료 내 개선이며 전문가 검토·실제 경로 정확도·운영 배포 완료를 뜻하지 않는다.
