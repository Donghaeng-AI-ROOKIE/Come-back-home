# 돌아오길 개인 행동 연결 — 2026-10-08 확인 결과

> **후속 수정·검증:** 미확인 사실의 반복 추첨과 명시 대기 시간 연장을 실행 후보에서 고쳤다. 3시드 KINTEX 비교·92개 검사·48개 저장 규칙 검사를 완료했다. 운영 API 기본 실행기 변경은 아니다. [최신 결과](../persistent_context/README.md).

> **2026-10-08 목적 정정:** 가족과 재회하여 안전 확보가 확인되면 사건 종료다. 아래의 가족 귀환 후 보행은 과거 합성 부품 검사이며 실종 예측 성공 근거로 쓰지 않는다. 미래 관측을 빼고 재검사하니 대기 쏠림이 드러났다. [정정과 실제 재검사 결과](../search_scope/README.md).

목표는 보호자가 온보딩한 특정 어르신의 특성을 해석하고, 그 특성이 KINTEX 도로 위의 이동·휴식·대기·회피에 실제로 반영되게 하는 것이다. 형식이 맞는 JSON을 만드는 것과 원문 의미를 보존하는 것, 보행에 반영하는 것은 따로 검사한다.

## 확보한 개선 근거

**D12의 간단한 조건식 계약은 기존 D4보다 개선됐다.** 별도 확대 개발24개 합성 사례×2반복에서 조건별 행동 선택은170/192→187/192, 구별 가능한 보행 출력은26/34→33/34였다. 14개 출력은 기존 보행 장면으로 개인 규칙의 유무를 구별할 수 없어 성공률에 넣지 않았다. 실제 환자48명의 예측 정확도가 아니다.

**실제 앱 질문에서 보행까지 연결한 합성 사례1개를 확보했다.** 앱이 한15턴의 질문과 합성 보호자 답변에서 원문13개를 저장하고, 초기 개인 해석과 마음 규칙으로 연결했다. D12가 만든 두 응답 모두500명·3상황·6시간 보행에서 작성자 참조와 같은 분포·집계를 보였다. 실제 환자나 보호자를 모집한 검증은 아니다.

첫 응답에 대해 가상 보행자500명 전원의779,303구간을 확인했다. ‘6분 또는280m를 먼저 채우면5분 휴식’, ‘길 잃음을 인지하고 가족이 없을 때 대기, 가족 귀환 시 해제’, ‘특정 상가에서 소음이 있을 때 회피’의 누락·잘못된 발동 위반은0건이었다. 구간 수를 독립 사례 수로 세지 않는다.

**시간은 실제로 이어진다.**1·2·4·6시간 확률지도는 서로 달랐다.1·2·4시간마다 상태를JSON으로 저장한 뒤 새로운 시뮬레이션 객체에서 복원해도6시간 연속 계산과 분포·집계·원문 행동 검사가 같았다. 운영DB나 작업자 장애복구까지 시험했다는 뜻은 아니다.

초기 성향에서 ‘기다림’을 높이는 가중과 같은 원문의 조건부 대기가 중복되는 부분도 분리해 비교했다. 그 가중 하나만 제외하자 초기부터 머무르는 가상 보행자가107/500→39/500으로 줄었고 조건부 대기·휴식·회피 검사는 유지됐다. 실제 인구의 적정 머무름 비율이39/500이라고 주장하지 않는다.

## 이번에 더 확인한 것

- D15·D16 지시 수정은 ‘계속 걷기’ 누락을 고쳤지만 다른 조건의 누락·출력 실패가 발생했다. D12를 전면 교체할 근거로 삼지 않는다.
- 기본 보행이 원래 걷고 있으면 ‘개인 계속 걷기’를 빼도 검사에서 구별되지 않는다. 별도 머무름 기준선을 둔 검사로 누락을 잡았다.
- 길게 깨진 모델 응답 때문에 수정 요청을 보낼 수 없던 실행 문제를 고쳤다. 보호자 원문을 그대로 두고 미완성 모델 응답만 생략한 별도1회 호출은 완전한 규칙과 조건24조합 일치를 확인했다. 일반적인 복구 성공률은 아직 아니다.
- ‘도착’과 ‘장소 인지’의 대상 장소가 엔진에서 충분히 구분되지 않는 문제를 재현했다. 선택 목적지의 과거 도착 상태가 다른 장소의 규칙과 섞일 수 있었다. 이후 장소별 사실을 읽는 별도 실행기를 구현하고 신규9개·기존37개 검사와500명×3상황 보행 회귀 검사를 통과했다. 운영API에는 연결하지 않았다.

## 현재 판단과 다음 작업

개인 특성을 행동으로 보존하는 개선 근거와 한 합성 사례의 전체 연결 근거는 확보했다. 모든 온보딩이나 모든 치매 행동을 재현한다고 확정할 단계는 아니다. 현재 연구 후보는 D12를 기준으로 유지하며, 운영 배포는 하지 않았다.

아래는 목적 정정 이전의 작업 순서다. **현재 우선순위는 정정 문서의 미확인 상태·대기 쏠림 검사**이며, 가족 귀환 후 재출발은 실종 예측의 완료 기준에서 제외한다.

당시 다음 수정은 두 곳에 집중했다. 첫째, 보호자 질문에 들어 있는 종료 조건이 짧은 답변에서 사라지는 문제를 해결한다. 둘째, 구현·검증한 장소별 도착·인지 실행기의 관측 입력·저장 경로를 API와 연결하고 복수 장소의 의미를 검증한다. 원문과 참조의 이견(P08 등), 실제 이동 속도 개인화, 명시적 대기 지속시간처럼 아직 충분히 표현하지 못하는 특성도 별도로 남긴다. 기존 정답을 모델 답에 맞춰 바꾸지 않는다.

최신 실험 묶음은 모두 완료됐다. 검증·비용 원장·코드 및 작은 증빙 묶음을 로컬 커밋으로 보존했다. 현재 백그라운드에서 새 모델 실험이 자동 진행 중인 상태는 아니다.
