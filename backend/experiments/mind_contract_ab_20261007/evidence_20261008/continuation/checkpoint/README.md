# 실제 앱 합성 인물의 시간별 저장·복원 확인

같은 가상 인물의500명 보행자를3개 장면에서6시간 실행했다.1·2·4시간에 상태를JSON으로 직렬화하고 새Population에 복원했다.

세 장면 모두 중단 없이 계산한 경우와1·2·4·6시간 위치 분포 및 누적 행동량이 정확히 같았다. 고정5명의 전체경로도 같고,500명 전원의 휴식·대기·회피 검사 결과도 같다. 휴식 중 남은 시간, 보행 누적량, 난수 상태가 이 비교에서는 유지됐다.

새 외부 호출0. 원래 개인 초기 가중치를 사용했으며 중복 대기 제거 후보는 이 비교에 넣지 않았다. 실험용 JSON 저장·복원 검증으로, 실제API·작업큐·DB·서버 재시작 복구를 확인한 것은 아니다. 임상 정확도나 배포 완료 판정이 아니다.

`checkpoint_audit.json`에 비교 결과, `checkpoints/`에3시점×3장면의 저장본, `manifest.json`과`source_snapshot/`에 실행 근거가 있다.
