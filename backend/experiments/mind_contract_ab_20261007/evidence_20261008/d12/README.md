# D12: 개인 조건을 간단한 실행 조건식으로 전달한 비교

D12는 모델이나 학습 데이터를 바꾼 실험이 아니다. K-EXAONE이 개인의 말뜻을 해석하되, 여러 겹의 조건 JSON 대신 제한된 논리식으로 시작·종료·장소 조건을 적게 했다. JSON schema, Thinking, 공식 권장 샘플링은 유지했다. 코드는 보호자의 단어를 매핑하지 않으며 모델이 적은 조건식만 허용된 문법으로 검사·변환한다.

## 무엇을 비교했나

이미 실패를 확인한 개발 입력8개를 각각2회 생성하고, 입력당4개 장면에서 행동을 검사했다. 즉 **16명 시험이 아니라8개 입력·16개 출력·64개 행동 판정**이다. 기존 정답과 원문은 바꾸지 않았다. 참고로 이8개는 성능이 나쁜 사례를 골라 수정하는 개발 자료여서 독립 평가가 아니다.

| 검사 | D12 결과 | 뜻 |
|---|---:|---|
| 첫 응답의 행동 판정 |58/64|수정 요청 전|
| 최종 행동 판정 |62/64|형식 오류 수정1회 포함|
| 실행 가능한 최종 출력 |16/16|개인 해석이 맞다는 뜻은 아님|
| 추가 조건 조합에서 기준과 같은 행동 |12/16|일부 경계 조건을 더 점검한 개발 진단|
| KINTEX 보행에서 기준 행동 보존 |10/14|차이를 구별할 수 있는 출력14개 기준|
| 행동 차이를 구별하지 못한 출력 |2/16|보행 보존 비율에서 따로 표시|
| 보행 코드 오류 |0|실제 환자 동선의 정답과 비교한 결과는 아님|

보행은 기존 KINTEX 실제 도로, 합성 시설·관측, 출력당150명·3장면·6시간이다. 기준 결과를 재사용하기 전에 앱 코드108개와 지도·입력·기준의 동일성을 검사했다.

## 여전히 다른 행동이 나온 이유

- 솔빛쉼터 사례2개 출력: 원문은 실제 도착하고 알아본 뒤 기다림이다. 모델은 알아본 조건만 남겨, 아직 도착하지 않은 경우에도 기다릴 수 있었다.
- 자정을 넘는 기다림1개 출력: 앞의 넓은 대기 규칙이 남아 새벽1시에 끝난다는 제한이 무효가 됐다.
- 통증 휴식1개 출력: 걷기를 전제로 하지 않아, 쉬고 난 뒤에도 통증 조건만으로 계속 쉬는 경우가 생겼다. 이 사례는 별도로 ‘숨차도 계속 걸었다’는 원문을 기존 기준이 충분히 표현하지 못한 문제도 있으므로 원문·정답 논쟁과 모델 오류를 구분한다.

문장별 특성 누락률은 이 간단한 계약으로 측정하지 않았다. 미측정을 누락0건으로 표기하지 않는다. 현재는 개선 후보이며 배포 성공으로 판정하지 않았다.

## 사용량

K17회(시작·종료 원장 일치), 입력36,705·출력78,188·총114,893토큰. 통신 오류0건. 단가·실청구액·지원 차수 미확인. API 응답 시간은 GPU 청구시간이 아니다.
