# 보행 검사 판별력 검증 (2026-10-07)

`engine_mutation_check.py` 결과. 모델 호출 없음. dev128 참조 정책 중 개인 규칙이 있는 108입력에, 일부러 틀린 변형 3종을 만들어 보행 검사가 잡는지 확인했습니다. 시나리오 3개, 보행자 40명, 시드 17·18·19를 썼고, 1·2·4·6시간에 각각 비교했습니다. 시설은 **실험용 합성 시설 레이어**이며 실제 KINTEX 환경 검증이 아닙니다.

| 틀린 변형 | 검출 |
|---|---:|
| 행동 바꾸기(대기→걷기, 휴식→걷기 등) | 108/108 |
| 규칙 삭제 | 102/108 |
| 첫 조건 뒤집기(참↔거짓, 이상↔미만) | 93/108 |
| 오경보(규칙 순서만 바꾼 참조를 틀렸다고 판정) | 6/108 |

- 세 변형을 모두 놓친 입력은 0입니다.
- 행동군별로 보면 환경 회피는 삭제 5/11, 뒤집기 5/11만 검출했습니다. 시나리오가 '그 장소 근처 + 소음·혼잡' 조건을 거의 만들지 못해 규칙이 발동하지 않았습니다. 회피 행동은 보행 검사로 판정하지 않고 장면 채점에 맡깁니다.
- 오경보 6건은 모두 복수 행동 묶음에서 나왔습니다. 여러 규칙이 동시에 성립하면 엔진이 목록 순서에 따라 고르기 때문에 순서만 바꿔도 보행이 달라집니다. 이 입력들은 허용오차에 순서 잡음을 포함해야 합니다(engine_outputs_v2는 포함).
- 개인 규칙으로 대기·휴식했다가 조건이 끝난 뒤 다시 걸은 보행자가 있는 입력은 6시간 기준으로 시나리오별 70·61·54입니다.
- 이 검증은 검사기의 판별력을 본 것이고, K의 해석 정확도가 아닙니다.
