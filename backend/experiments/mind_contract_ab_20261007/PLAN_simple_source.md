# 짧은 원문 해석 진단 — 2026-10-08

## 왜 실행하는가

D9는 원문을 한국어 카드로 정리하는 첫 단계부터 16개 중 12개가 실패했다. 뒤쪽 실행 계약이나 보행 엔진만 고쳐서는 이 실패를 해결할 수 없다. 긴 계약을 제외한 짧은 문답에서도 부정·시작 조건·종료 조건·장소 한정을 보존하는지 먼저 확인한다.

## 실행 범위

- 직접 작성한 간단한 문답 4개: 기다림, 통증 시 휴식, 특정 장소의 소음 회피, 앞선 말 정정과 미관찰.
- Thinking 켬/끔 × 각 2반복, 최대 16회. 실패도 포함하며 자동 재시도 없음, 동시 2회.
- 두 조건 모두 temperature=1.0, top_p=0.95, presence_penalty=0.0, repetition_penalty=1.0, 출력 상한 8,192토큰. 출력 합계 상한 131,072토큰, 입력 호출당 최대 40,000바이트.
- 짧은 JSON 네 필드만 요구하고 API response_format 제약은 사용하지 않는다. 이전 장문의 행동 후보와 점수를 직접 비교하지 않는다.
- 새 지도·RAG 검색·임베딩·Mi:dm·GPU 학습 호출 없음. 기존 원격 컨테이너에서 독립 요청만 보내며 운영 앱 설정은 변경하지 않는다.
- 공용 usage_events.jsonl에 시작/종료, 실패, 토큰을 기록한다. 단가·실청구액·지원 차수 미확인. 2026-10-08 사용자 반복 개선 지속 승인 범위.

## 판정과 후속

조건 누락, 종료 조건 반전, 장소 한정 누락, 미관찰 행동 생성은 실패다. 배열 순서만 다른 것은 동등하게 본다. 정답·장면·점수는 요청에 넣지 않으며 정답은 이 진단의 작성자 기준이다. 임상 전문가 정답이나 독립 평가가 아니다.

기본 조건에서도 실패가 많으면 입력 계약 확장보다 엔드포인트·생성 설정을 먼저 진단한다. 성공한다면 복합 조건과 실제 온보딩 원문으로 단계적으로 확장한다. 이 작은 진단을 통과해도 개인 행동 재현이나 배포 성공으로 판정하지 않는다. 다음 단계는 결과를 확인한 후 정하며 자동 승격하지 않는다.
