# D8: 조건 해석의 부담을 줄인 출력 계약

## 관찰과 가설

D6는 64장면 중 48개가 기존 참조와 일치했고, 16개 최종 출력 중 2개는
자정을 넘는 시간대를 불가능한 AND 조건으로 표현했다. D7 원문 재검토
중간 결과에서도 참/거짓 반전과 맞았던 해석의 퇴행이 나타났다.
같은 긴 프롬프트에 재검토를 추가하는 것만으로 해결되지 않는다.

D8은 프롬프트를 새로 간결하게 정리하고, 하루 시각은 시작·끝 숫자의
구간으로 받는다. 자정 통과 여부는 코드가 수학적으로 펼친다.
K는 여전히 원문의 숫자·상황·행동을 해석한다. 보호자 단어를 코드로
분류하거나, 사례 ID에 맞춰 규칙을 패치하지 않는다.

## 분리 비교

D8과 D8plain의 원문·프롬프트·출력 스키마·컴파일러·샘플링은 같다.
오직 API의 response_format 제약 유무만 다르다. 두 조건 모두 같은
최종 JSON 검증을 거치며, 잘못된 응답을 파서가 고쳐서 성공으로 세지 않는다.

- 후보마다 같은 개발 입력 8개×2반복 =16회. 형식 실패만 추가 수정 1회.
- 후보당 최대32회, 둘 합계 최대64회. 한 후보씩, 동시2회.
- 호출당 출력16,384토큰, 입력40,000바이트. 총 출력 상한1,048,576토큰.
- 실패도 원장에 기록. 통신 자동 재시도 없음. 단가·청구액·지원 차수 미확인.
- 사용자 2026-10-08 같은 목표 반복 개선 계속 실행 지시로 승인.
- 신규 지도·임베딩·GPU 학습·배포 없음.

## 검증

시간 구간 컴파일러는 자정 전후·종료 경계·동행 조건을 별도로 검사한다.
모델 응답은 기존 참조64장면, 조건 반례, 같은 KINTEX 보행으로 확인한다.
P08 원문의 계속 걷기와 참조의 이견은 별도 기록하며 기존 점수를 바꾸지 않는다.
쉬운 사례만 고르거나 이전에 실패한 응답을 분모에서 빼지 않는다.
어느 결과든 실제 치매환자의 경로 정확도나 임상 검증으로 부르지 않는다.

## 설정 조사

[LG AI Research 모델 안내](https://huggingface.co/LGAI-EXAONE/K-EXAONE-236B-A23B/blob/main/README.md)의
temperature1.0·top_p0.95·Thinking 설정을 사용한다. D6 저장 응답에 실제
reasoning 필드가 존재하므로 단순히 Thinking이 꺼진 것으로 설명할 수 없다.
내용은 복제하지 않고 필드 유무와 길이만 확인했다.

[FriendliAI 공식 설명](https://friendli.ai/blog/structured-output)은 스키마 제약과
올바른 의미 생성이 별개임을 설명한다. 이번 비교는 이 서비스에서의 실제
영향을 측정하려는 것이며, 제공자 문제라고 미리 단정하지 않는다.
