# 후보 D 계획 (2026-10-07, 실행 전 고정)

## 왜 D인가

c_dev8(후보 C, temperature 1.0)은 19/64로 dev8보다 나빴습니다. 생각 반복 붕괴는 16건 중 1건으로 줄었지만, 모델이 자유 문자열을 정확히 쓰지 못했습니다.

- 인용문 불일치: 최종 기준 8건, 첫 응답 7건. 단어를 빼거나 어미를 바꿨고, 숫자도 바꿨습니다("이백팔십" → "이백오십").
- 조건식 손상: 연산자가 빠진 `is_walking (…)`, 사실 이름에 한글이 섞인 `거리_since_rest_m`
- 걷는 중이면 항상 쉬는 무의미한 휴식 단위 추가(P05)
- 수정 요청 13회 중 최종 유효로 바뀐 것은 2건뿐입니다.

## D가 바꾸는 것 (C 대비)

1. 근거: 코드가 답변을 문장 끝 부호로 나눠 문장 ID(N1.s2 등)를 붙입니다. 모델은 문장 ID만 고르며, ID는 스키마 허용값입니다. 모든 문장이 적어도 한 단위에 배정돼야 합니다(고정 규칙으로 덮인 문답 제외).
2. 조건: "분기 목록 × (참 사실, 거짓 사실, 숫자 비교)" 구조이며, 사실 이름·연산자는 스키마 허용값입니다. 코드가 기존 조건식으로 바꿔 같은 AST 컴파일러로 확인합니다.
3. is_walking 외의 사실이 없는 행동 조건을 거절합니다.
4. 생성 설정(1.0/0.95/16,384), `response_format`, 수정 요청 1회는 C와 같습니다.
