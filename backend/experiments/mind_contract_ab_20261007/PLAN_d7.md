# D7: 원문 재검토가 실제 조건 누락을 줄이는가

## 원인과 변경

D6 도중 형식 검사를 통과했지만 행동 하나가 빠지거나 발동 조건이 누락된
응답이 확인됐다. 형식 검사가 실패할 때만 수정 요청을 보내면 이 오류는
수정 기회가 없다. D7은 D6의 완성 응답 16개 모두를 원문과 함께 다시 읽는다.
형식·컴파일러·입력·평가 정답·보행엔진은 그대로다. 사람이 검토한 결과가 아니다.

## 동결한 비교와 사용량

- D6와 같은 개발 실패 사례 8개 × 2반복. 최초 응답을 임의로 고르지 않는다.
- D6 최종 응답을 원문과 함께 검토하는 K-EXAONE 16회.
- 받은 검토 응답이 검증 실패한 때만 수정 1회. 최대 32회, 동시 2회.
- 호출당 출력 16,384토큰, 입력 40,000바이트. 출력 상한 524,288토큰.
- 통신 오류 자동 재시도 없음. 기존 원장에 실패 포함 기록.
- 단가·실청구액·지원 차수 미확인. 기존 지도·출처만 이용.
- 2026-10-08 같은 목표 반복 실험에 대한 사용자 계속 실행 지시로 승인.

모델에 보내는 것은 보호자 원문, 질문 맥락, 등록 장소, 저장 초기 해석,
기존 초안뿐이다. 평가 정답·장면·점수·오답 진단은 보내지 않는다.
초안 해시와 요청·코드·데이터 해시를 보존한다.

## 판정

기존 정답으로 채점한 64장면 결과를 D6와 나란히 보존한다. 조건 탐색과
실제 KINTEX 보행도 비교하며, 맞았던 출력이 나빠진 경우를 따로 센다.
새 검토의 첫 응답과 형식 수정 후 응답을 구별한다. 최종 평가나 배포 판정이 아니다.

원문에 실제 관찰된 '계속 걷기'가 있는데 기존 정답은 이를 제외한 사례가 있다.
그 경우 기존 점수를 바꾸지 않고 원문 보존 관점의 이견을 별도 기록한다.
원문 충실성을 희생해 이전 정답에 맞추는 수정은 채택하지 않는다.
