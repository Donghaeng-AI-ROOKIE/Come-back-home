# 마음 재해석 골드셋 v1 — 설계 스펙

`reinterpret_mind`(goal·confusion·서사)의 **판단 품질**을 잴 수 있는, 정답 기준이
독립적으로 확정된 평가셋. mind_probe fixture(개발·회귀용, 골드셋 아님)와 구분된다.

## 왜 필요한가 — fixture 로 막혔던 세 가지를 구조로 해결

| fixture 의 결격 | 이 골드셋의 방어 |
|---|---|
| 결함 가설을 알고 만든 표적 설계 → 평가 불가 | 시나리오를 **문헌 층화 그리드**에서 도출, dev/test 분리·test 봉인 |
| 정답 부재 → "잘 한다" 판정 불능 | **범위 라벨** + 모델 출력을 안 본 **판정자 3인 2/3 합의** |
| 페르소나 = 추출 출력(pseudo-label) → 마음/추출 실패 미분리 | **gold_personas 층 분리** — 깨끗한 입력으로 마음 단독 평가 + 추출 통과본으로 E2E 평가 |

## 3층 구조

```
01_시나리오_대화_v1.md   raw_dialogues   — 보호자 발화 대본 20종 (층화 그리드)
02_판정_지시서.md        judges 입력      — gold_personas + 상황별 범위 라벨 생성 지시
03_정답표_{claude,gpt,gemini}.md         — 판정자별 라벨 (2/3 합의로 04 확정)
04_정답표_합의.md         gold labels     — 확정 정답 (여기까지 만들어져야 골드셋)
eval_mind_goldset.py     평가 스크립트    — 시스템 출력 vs 04 대조
```

## 층화 그리드 (표적 아님 — 실사용 변산의 직교 조합)

축 4개: 유형(치매/발달) × 끌림점 구성(강단독/강+약/균형/없음) × 정보량(풍부/빈약)
× 특이 상황(근거 대조쌍·물가·야간·노이즈). 20셀 = 치매 10 + 발달 10.
문헌 앵커(시나리오 소재의 출처 — 수치는 제안서 인용 전 원문 대조 필요):
- 치매: 과거 거주지·연고지 발견 경향(Rowe 치매 실종 사례 분석), 배회~60%(Algase),
  익숙환경↔배회 상관(국내 r=.56), time-shift(코퍼스 심리 계열)
- 발달: 선호대상(물·교통시설) 지향 이탈(Anderson elopement, FBI 자폐 실종 분석),
  감각 회피→숨기(코퍼스 행동심리 계열), 고착 반복(elopement 재발 패턴)

## dev / test 분리 (봉인 규칙)

- **dev 8종** (G01~G08): 프롬프트·코드 개선 중 자유 사용.
- **test 12종** (G09~G20): **개발 중 실행 금지.** 최종 보고 직전 1회 측정.
  실행 기록은 results/ 에 남기고, 개발에 쓰였다면 그 시점부터 test 자격 상실을
  README 에 명기한다. (fixture 가 개발셋으로 오염된 전철 방지)

## 범위 라벨 스키마 (마음 출력은 단일 정답 불가)

시나리오마다 표준 상황 2종(귀소 발동 90분 / 불안 발동 60분)에 대해:

```json
{
  "gold_persona": {
    "attractions": [{"label": "...", "evidence": "...", "abstract": false}],
    "notes_must_capture": ["..."], "axis_range": {"autobiographical": [0.6, 0.9]}
  },
  "situations": {
    "귀소": {"allowed_goals": ["옛집", null], "forbidden_goals": ["시장"],
             "confusion_range": [0.5, 0.9],
             "expected_relation": "previous_missing_found > mention_only",
             "forbidden_narratives": ["발달 페르소나에 time-shift/옛집 서사"]},
    "불안": { ... }
  }
}
```

## 판정 절차 (순환 차단)

1. 판정자는 **01 대화만** 본다 — 시스템 프롬프트·모델 출력·개발 이력 비공개.
2. 판정자 3인: 외부 LLM 2종(GPT·Gemini — 02 지시서 붙여넣기) + 팀원 1인
   (또는 Claude 계열 1을 쓰되 **시나리오 작성 세션과 분리된 새 세션**으로.
   작성자=판정자 중복은 라벨 편향 위험이 있어 팀원 우선).
3. 항목별 2/3 합의 → 04 확정. 불일치 항목은 표기하고 사람 결정.
4. provenance: 판정 모델·일시·지시서 버전을 04 헤더에 기록.

## 평가 지표 (04 확정 후)

- goal 적합률: 출력 goal ∈ allowed_goals (situation 별)
- 금지 위반률: forbidden_goals·forbidden_narratives 위반 = 치명 카운트
- confusion 적합률: confusion ∈ range
- 관계 충족률: expected_relation (대조쌍은 두 시나리오 출력을 묶어 판정)
- 표집 건전성: 동일 입력 n회 분포가 allowed 집합 안에서 퍼지는가 (argmax 재발 감시)
