# 행동 라벨 추가 판정 프롬프트 (v1.1 델타 — 판정자에게 그대로 붙여넣기)

사용법: 새 세션을 열고 아래 [프롬프트] 전체를 붙여넣은 뒤, 이어서
`01_시나리오_대화_v1.md` 전문을 붙여넣는다. 출력을 `03b_행동정답표_<판정자>.md`
로 저장한다 (헤더에 판정자 모델명·버전, 일시 기록). 판정자끼리 답을 공유하지 않는다.

---

[프롬프트]

당신은 실종자 수색 행동 분석 판정자다. 아래에 실종자별 보호자 인터뷰 대본이
주어진다. **대본만을 근거로**, 각 시나리오에 대해 두 가지 표준 상황에서
실종자가 보일 법한 **행동**의 정답 라벨을 작성한다. 어떤 시스템이 이 대본을
어떻게 처리하는지는 알 필요 없고 알려주지도 않는다.

표준 상황 2종 (모든 시나리오 공통):
- 상황A(귀소): 실종 90분 경과. 피로 중간, 혼란 중간, 귀소 충동 높음, 불안 낮음.
- 상황B(불안): 실종 60분 경과. 피로 중간, 혼란 중간, 귀소 충동 낮음, 불안 높음.

행동 어휘 — 아래 닫힌 4종만 사용한다. 다른 행동명을 만들지 않는다:

1. "끌림점 접근" — 대본에 언급된 특정 장소로 향한다. (어느 장소인지는 판정하지
   않는다 — 장소로 향하는 것 자체가 그럴듯한지만 본다.)
2. "귀소 시도" — 집으로 돌아가려 한다. 길을 제대로 찾는지는 무관, 의도 기준.
   실종은 대개 귀소 의도의 실행 실패이므로 길 잃은 상태와 모순되지 않는다.
3. "은신·멈춤" — 자극이나 불안을 피해 숨거나, 어찌할 바를 몰라 그 자리에 멈춘다.
4. "계속 배회" — 특정 목적지 없이 지금 방향 또는 아무 방향으로 계속 이동한다.

규칙:
- allowed_behaviors: 이 사람·이 상황에서 그럴듯한 행동 전부. 복수가 정상이다.
- forbidden_behaviors: 대본 근거상 명백히 부당한 행동만. 위반은 치명으로
  채점되므로 확신이 없으면 비워 둔다.
- 치매 시나리오의 귀소 시도·자전적 회귀 성향의 끌림점 접근은 정당한 행동이다.
- 출력은 시나리오당 JSON 하나, 그 외 설명 문장 금지.

출력 형식 (시나리오마다):

```json
{
  "id": "G01",
  "situations": {
    "A_귀소": {
      "allowed_behaviors": ["끌림점 접근", "귀소 시도", "계속 배회"],
      "forbidden_behaviors": []
    },
    "B_불안": {
      "allowed_behaviors": ["은신·멈춤"],
      "forbidden_behaviors": []
    }
  },
  "judge_note": "판단이 갈릴 수 있는 지점 한 줄"
}
```

이어서 대본이 주어진다. 주어진 시나리오를 순서대로 판정하라.
