# 마음 골드셋 — 판정 지시서 (판정자용, v1.1)

당신은 실종자 수색 행동 분석 판정자다. 아래에 보호자 인터뷰 대본이 주어진다.
**대본만을 근거로** 각 시나리오의 정답 라벨을 작성한다. 어떤 시스템·모델이 이
대본을 어떻게 처리하는지는 알 필요도 없고 알려주지도 않는다.

## 입력

`01_시나리오_대화_v1.md`의 시나리오 N개. 각 시나리오는 실종자 1명에 대한 보호자
답변 목록이며, 표준 상황 2종이 공통 적용된다:
- **상황A(귀소)**: 실종 90분 경과, 피로 중간·혼란 중간·귀소 충동 높음·불안 낮음
- **상황B(불안)**: 실종 60분 경과, 피로 중간·혼란 중간·귀소 충동 낮음·불안 높음

## 출력 — 시나리오마다 JSON 하나

```json
{
  "id": "G01",
  "gold_persona": {
    "attractions": [
      {"label": "청량리 수산시장", "evidence": "previous_missing_found", "abstract": false}
    ],
    "abstract_preferences": ["(장소가 아닌 선호·회피 성향, 없으면 [])"],
    "notes_must_capture": ["새벽마다 시장 나가려 함", "과거 발견 2회 모두 수산시장"],
    "axis_expectation": {"autobiographical_destination_pull": [0.6, 0.9]}
  },
  "situations": {
    "A_귀소": {
      "allowed_goals": ["청량리 수산시장", null],
      "forbidden_goals": [],
      "confusion_range": [0.5, 0.9],
      "expected_relation": "previous_missing_found 라벨이 있으면 최우선",
      "forbidden_narratives": ["대본에 없는 장소·사실"]
    },
    "B_불안": { "...같은 형식..." : "..." }
  },
  "judge_notes": "판단이 갈릴 수 있는 지점 한 줄"
}
```

## 규칙

1. **장소 vs 추상 구분**: 좌표를 찍을 수 있는 실제 장소만 `attractions`.
   "조용한 곳", "물" 같은 성향은 `abstract_preferences`로 분리한다.
   단, 추상 성향이 구체 장소로 연결되면(예: "조용한 데 → 아파트 지하주차장")
   그 구체 장소를 attractions 에 넣는다.
2. **evidence 는 셋 중 하나**: `previous_missing_found`(과거 실종 때 실제 발견) >
   `caregiver_report`(보호자가 반복 지향을 직접 관찰) > `mention_only`(언급만).
   대본의 표현 강도로 판단한다. 발견 사실이 명시되면 반드시 최상위.
3. **allowed_goals**: 그 상황에서 타당한 목표들의 집합. null(방향 유지)이 타당하면
   포함한다. 정보가 빈약해 어떤 목표도 근거가 없으면 `[null]` 만 남긴다.
4. **forbidden_goals**: 대본 근거상 명백히 부당한 목표(예: 언급만 된 약한 장소가
   강한 발견 이력 장소를 제치는 것이 부당하면 그 약한 장소를 A상황 forbidden 에).
   확신이 없으면 비워 둔다 — forbidden 은 위반=치명으로 채점되므로 보수적으로.
5. **confusion_range**: 상황·대본(중증도, 야간, 정보량)을 반영한 타당 구간.
   0(명료)~1(극심), 0.05 단위 불필요 — [하한, 상한]이면 된다.
6. **expected_relation**: 이 시나리오가 검증하는 순서 관계를 자연어 한 줄로
   (예: "발견 이력 장소 > 언급만 장소", "대조쌍 강 케이스가 약 케이스보다 해당
   장소 선택이 우세해야"). 없으면 빈 문자열.
7. **forbidden_narratives**: 나오면 안 되는 서사 유형. 최소한 다음을 검토한다 —
   대본에 없는 장소·사실 창작, 빈약 시나리오에서 근거 없는 단정.
8. **정당한 서사**: 치매 시나리오의 자전적 회귀(옛 직장·고향)는 정당하다.
9. 출력은 시나리오당 JSON 하나, 그 외 설명 문장 금지.

## v1.1 확장 — 행동 라벨 (2026-07-29 추가)

목적지 라벨만으로는 "숨는다·멈춘다·집을 찾아 헤맨다·그냥 계속 걷는다" 같은
비목적지 행동을 채점할 수 없다(실측: 모델의 마음 발화에 이런 행동이 다수
등장하나 전부 '목적지 없음'으로 뭉개짐). 각 상황에 **행동 라벨**을 추가한다.

행동 어휘 (닫힌 4종 — 이 밖의 행동명 금지):

- `끌림점 접근`: 등록된 특정 장소로 향한다. 어느 장소가 타당한지는
  allowed_goals 가 담당하므로 여기서는 "장소로 향하는 것 자체"의 타당성만 본다.
- `귀소 시도`: 집으로 돌아가려 한다. 길을 제대로 찾는지는 무관 — 의도 기준.
  (실종은 대개 귀소 의도의 실행 실패이므로, 길을 잃은 상태와 모순되지 않는다.)
- `은신·멈춤`: 자극·불안을 피해 숨거나, 어찌할 바를 몰라 그 자리에 멈춘다.
- `계속 배회`: 특정 목적지 없이 지금 방향 또는 아무 방향으로 계속 이동한다.

각 상황 JSON 에 두 필드를 추가한다:

```json
"allowed_behaviors": ["귀소 시도", "계속 배회"],
"forbidden_behaviors": []
```

규칙 (goal 라벨과 같은 철학):
- allowed 는 이 사람·이 상황에서 그럴듯한 행동 **전부** (복수 허용이 정상).
- forbidden 은 대본 근거상 **명백히 부당**한 행동만. 위반=치명으로 채점되므로
  확신 없으면 비워 둔다. (예: 보호자가 "무서우면 그 자리에 주저앉는다"고 한
  사람이 불안 상황에서 활발히 멀리 이동 — 이런 명백한 모순만.)
- 근거는 01 대본과 상황(게이지 수치)뿐. 규칙 8(정당한 서사)은 행동에도 적용된다
  — 치매 시나리오의 귀소 시도는 정당하다.

판정 일시를 기록한다. 다른 판정자의 답을 보지 않는다.
