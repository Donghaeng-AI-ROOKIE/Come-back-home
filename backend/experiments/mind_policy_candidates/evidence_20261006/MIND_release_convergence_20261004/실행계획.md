# 배포 판정까지의 후속 개선 계획

시작 기준: PR #265, 2d6af78. 작업 브랜치: codex/mind-release-convergence-20261004.

## 이번 순서

1. 6시간 계속 보행의 소비처와 분 단위 사이 관측 변경을 먼저 재현하고 수정한다. 실제 KINTEX 저장 지도만 사용한다.
2. 기존 피로 곡선의 휴식 소비를 일반 기준으로 연결하되, 명시적으로 선택된 개인 행동을 덮지 않는다. 분당 발동·5분 휴식·회복 0.4는 연구용 가정이며 민감도 2/5/10분을 비교한다. 기존 코드는 도로 간선당 확률 및 발견거리 감소여서, 새 시간 모델과 동등한 것으로 주장하지 않는다.
3. K가 조건 프로그램을 생성하는 현 후보를 한 차례 더 단순한 지시로 비교한다. 형식은 현재 compact13과 동일해 행동 소비처 차이를 혼합하지 않는다. 영문 출력 지시와 한글 원문, 직접 관찰/능력/권고 구분, 초기 출력 뒤 원문 대조를 사용한다. 이 변경은 프롬프트/Thinking/온도를 합친 후보 전체의 비교다.
4. 후보가 형식뿐 아니라 기다림 종료·개인 휴식·장소 AND/OR·능력과 행동 구별을 통과해야 별도 평가로 확대한다. 실패하면 같은 테스트를 성공할 때까지 재추출하지 않고 다른 계약/상황별 행동 판단 방식으로 전환한다.
5. 제품 API 연결, 재시작 복구, 동시 사건 부하, 지도·환경 레이어·개인정보 삭제를 확인한다. 모델 출력 검증과 운영 검증은 별도 판정한다.

## 현존 개발 범위의 잔여분

기존 MIND_completion_20261004 계획은 K 최대128회(개발80/별도평가48). 공용 원장 확인 시 개발62/평가48로 총110회 사용, 개발18회가 남았다.
이번 비교는 같은 8개 개발 개인의 draft/review 각1회, 최대16회. 먼저 E1/W1 4회를 확인하고 실패 종류에 따라 남은12회의 조건을 기록한다. 전체128회·개발80회 안에서만 실행하고 실패도 상한에 포함한다. 자동 재시도 없음, 동시2, 입력40,000UTF-8바이트 이하·출력4,096토큰 이하. 최대 신규출력65,536토큰. 단가·실청구액·지원 차수는 미확인.
새 SAR·Mi:dm·임베딩·지도·GPU학습 호출 없음. 기존 저장 원문·초기해석·SAR수치·KINTEX지도 사용. 이 비교의 마음 입력에는 저장된 연구 발췌가 없으며 RAG 추가효과 실험이라고 부르지 않는다. 기존 Upstage 인덱스는 변경하지 않는다.
요청 전 공용 원장 시작 이벤트, 응답/실패 종료 이벤트 및 원격 영수증을 보존한다. 이 계획은 새 무제한 호출 승인이 아니며 잔여 범위를 넘기지 않는다.

## 완료 판정에 쓰는 기준

- 개인 의미: 원문 조건·부정·우선순위·정정·공간 범위·종료조건이 보존되고, 근거 없는 행동을 추가하지 않을 것. 구조 성공과 별도 집계.
- 실행: 멈춤/휴식/이동·도착/인지·시간·질량 보존, 같은 난수의 재시작 동등성, 개인 간 누출 없는 캐시. 코드 필수 불변식 실패0.
- 시간: 1/2/4/6시간 연속 상태를 이어 계산. 기다리는 개인은 동일 지도 허용. 단순 지도 차이를 정확도로 부르지 않음.
- 운영: 고정된 후보 버전에서 실제 배포 설정·장애 처리·복구·부하 검증 후 판정. 합성 평가 수치를 실환자 예측 정확도로 부르지 않음.
- 현재 없는 실제 실종 경로·독립 돌봄 검토는 미확보로 기록. 외부 근거를 만들거나 검증 기준을 결과에 맞춰 낮추지 않음.

## 문헌 확인

- https://aging.jmir.org/2024/1/e53020 : 시설 보행의 구간/중단 분석. 현재 초록·검색 발췌 확인, 본문 접근 제한. 야외 실종자의 보편적 5분 휴식 근거로 쓰지 않는다.
- https://pubmed.ncbi.nlm.nih.gov/31874572/ : 재가 알츠하이머병 5명의 야외 관찰. 멈춰 살피기와 익숙한 경로 등은 개인 전략 검토 근거이며 반응확률 수치가 아니다.
- https://pmc.ncbi.nlm.nih.gov/articles/PMC10002302/ : 시설 거주자35명의 소리 환경 반응이 개인·친숙함·상황에 따라 달랐음. 야외 모두 회피 규칙으로 일반화하지 않는다.

## 개발 비교 중 변경 기록

compact16 파일럿 4회: 형식2/2이나 E1의 능력→행동 변환·장소 범위 확대가 남아, 계획한 나머지6개×2회는 보류했다. 같은 두 개발 사례에 현재 규칙이 실제로 선택하는 가상 행동 결과를 덧붙이는 후속 검토 최대2회를 사용한다. 이는 추가 독립 평가가 아니라 개발 반복이다. 40분 규칙의 실제 발동 시점, 등록 장소 밖 같은 유형에서의 발동 등을 코드로 계산하며 보호자 문장을 키워드로 해석하지 않는다. 기존 전체128/개발80 범위 안에서, 현재누적114회 다음2회이며 입력4만바이트·출력4096·동시2·자동재시도없음·비용미확인 기록을 유지한다.

실행효과 재검토 2회도 정책이 그대로 유지됐다. 총116회(개발68/평가48) 다음의 잔여 개발12회는 전체 프로그램 생성 대신 현재 장면의 개인 반응 선택으로 비교한다. 같은3명·6장면×Thinking 켬/끔으로12회이며 신규 개인/독립 평가가 아니다. 같은 원문·장면·메뉴·온도를 사용하고 Thinking과 출력 상한만 다르다. 비Thinking4096, Thinking12000, 합계최대96576출력토큰, 입력4만바이트, 동시2, 재시도없음. 원래128/개발80 상한을 넘기지 않는다. 사전 고정한 합성 정답은 모델 요청에서 제외한다. RAG 발췌가 없는 개발 입력으로 연구지식 추가효과는 판정하지 않는다. 단가·실청구액·지원차수미확인 기록 유지. 이 후보가 통과해도 현재장면→행동의 개발 파일럿만 통과하며 저장 정책·실시간예산·실환자 예측·배포승인을 뜻하지 않는다.
