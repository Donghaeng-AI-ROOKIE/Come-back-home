# 마음 판단 검토지 — 합성32명,64장면

모델 응답과 AI 정답을 가린 검토용 문서. 실제 환자 자료가 아니며 검토가 완료됐다는 뜻이 아님.

각 장면에서 원문이 뒷받침하는 행동, 부족한 정보, 잘못 일반화하면 안 되는 조건을 적는다. 명시된 행동이 실제 치매인의 모든 행동을 대표하는지도 별도로 검토한다. 이 문서는 외부에 전송하지 않았다.
