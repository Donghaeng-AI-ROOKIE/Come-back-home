# 개인 마음 판단과 연속 보행 — 후속 개선 결과

2026-10-04~05 · PR #265 후속 · 운영 배포 없음

**현재 후보의 배포 판정은 보류다.** 이번에는 모델을 18회 더 호출하고 보행 코드의 실제 오류를 수정했다. 코드 검사는 통과했지만, 모델은 특정 장소에서만 관찰한 반응을 다른 장소로 넓히거나 보행 능력을 실제 계속 걷는 반응으로 해석했다. 테스트를 통과하도록 정답이나 판정 기준을 바꾸지 않았고, 실패 응답도 보존했다.

## 무엇을 위해 다시 시험했나

목표는 보호자가 온보딩한 그 치매 어르신의 특성이 현재 환경·시간·상태에 따라 실제 보행으로 나타나는 것이다. 이번 범위는 (1) 원문에서 개인 행동을 해석하는 마음 후보, (2) 해석된 행동을 실행하는 연속 보행, (3) 중간 실패 시 정상 예측을 보존하는 연결 코드다. 초기 온보딩 해석 모델의 새로운 성능 평가나 SAR 제거 실험은 아니다.

기존 K-EXAONE 초기 해석과 SAR-EXAONE 사건 수치 기준을 유지했다. 새 조건 프로그램 후보는 `RELEASE_QUALIFIED=False`이며 운영에서 활성화하지 않았다. 마음 모델의 K API 배포 별칭 아래 실제 가중치 리비전은 독립적으로 확인하지 않았으므로 특정 가중치 버전의 우월성으로 소개하지 않는다.

6장면의 결과는 작은 개발 비교다. 새 환자6명이나 독립 평가6명으로 세지 않는다. Thinking과 출력 상한이 함께 다르므로 Thinking만의 인과 효과를 분리한 시험도 아니다. 공개 설명까지 독립 사람이 채점한 결과가 아니다.

현재 장면 비교의 공급자 요청 경과 시간 중앙값은 Thinking끔 약1.36초, 켬 약76.02초였고, 켬 최댓값은 약179.47초였다. 켬의12,000토큰 종료는 최종 답변이 비어 있어 실패로 집계했다. 켬이 행동을 한 건 더 맞혔다고 바로 실시간 경로에 넣을 수 있는 결과는 아니다.

### 실제 실패의 의미

**특정 장소의 관찰을 모든 장소로 넓힘**

원문: “푸른시장 입구에서만 직접 봤어요. … 다른 시장에서 어떨지는 전혀 몰라요.”
현재 장면: 시끄럽고 혼잡한 다른 시장.
Thinking끔 최종 명령: `avoid_market`.
공개 설명: “현재 장면도 사람이 붐비고 시끄러운 미등록 다른 시장 환경이므로 동일한 회피 반응이 성립한다.”

원문이 모른다고 한 부분을 개인의 확정된 반응으로 채운 오류다. Thinking켬은 이 장면에서 `unknown`을 선택했다.

**보행 능력을 현재 행동의 근거로 바꿈**

원문: “평소 연속으로 사십 분 정도는 걸으세요.”
현재 장면: 연속45분 보행. 이후 반응은 원문에 없음.
Thinking켬 최종 명령: `walk`.
공개 설명: “현재45분 보행 중이나 '평소' 표현으로 지속 보행이 지원됨.”

얼마나 걸을 수 있는지와 그 뒤에도 계속 걷는지는 다른 정보다. Thinking끔은 이 장면에서 판단을 유보했다. 두 후보 중 각 장면의 성공만 고른 조합을 새로운 성공률로 만들지 않았다.

**휴식 조건을 무시함**

원문: “오 분 정도, 삼백 미터쯤 걸으면 앉아서 쉬어야 해요.”
현재 장면: 연속6.25분·300m 보행, 통증 확인.
Thinking끔은 `walk`, 켬은 `rest`를 선택했다. 끔의 공개 설명은 원문의 ‘1시간 연속 보행 불가’를 근거로 현재 보행을 허용했다. 이는 기준 하나를 잘못 적용한 의미 오류다.

## 보행과 복구 코드에서 실제로 고친 것

| 재현한 문제 | 수정 | 확인한 범위 |
|---|---|---|
| 개인 휴식 규칙이 없으면 피로가 쌓여도 일반 휴식이 소비되지 않음 | 기존 피로 곡선을 분당 평가하는 연구용 일반 휴식 연결 | 높은 피로에서 휴식 발생, 명시된 개인 행동과의 우선순위, 재시작 난수·시계 동일성 |
| 관측이 분 중간에 바뀌어도 다음 정수 분까지 이전 행동 유지 | 보행을 관측 시작·종료 시각에서 나누어 재평가 | 가족 도착·환경 관측이0.25분에 바뀌면 정확히 그 시점에 대기 해제 |
| 일부 보행자만 실패한 예측이 마지막 정상 체크포인트를 덮어씀 | 미해결 확률이 있는 결과는 체크포인트 미확정 |1/6 미해결을 보존하고 이전 정상 상태 유지. 실패 전 체크포인트에서 다시 시도 가능 |

전체 backend **1,451개 통과, 2개 skip, 하위 테스트7개 통과**. 수정 전 실패를 먼저 재현했고, 수정 후 관련44개와 전체 회귀를 확인했다. 숫자는 서로 중복되는 코드 검사이며 모델 정확도 표본으로 합산하지 않는다. [전체 검사 기록](backend_tests.xml).

기존 PR #265의 원본 결과와 소스 해시를 덮어쓰지 않았다. 과거 증거 검증기는 지정한 로컬 Git 커밋의 구현을 대조할 수 있게 했다. 이것은 과거 보행 성능을 새 코드로 재실행했다는 뜻이 아니다.

## 다음 단계와 배포 판정

1. 기존 우수 후보와 원문·현재 사실을 간결하게 전달하는 후보를 동일 입력으로 비교. source_scene 후보는 준비했지만 아직 호출하지 않음.
2. 개발에서 통과한 후보만 새 합성32명·64장면·2반복으로 평가. 원문·정답은 호출 전에 파일로 보존했고, 독립 검토용 빈 양식도 만들었으나 사람 검토는 아직0명.
3. 선정 모델의 응답을 실제 KINTEX 보행에 연결해 조건 변경·휴식·대기·도착·재출발과1/2/4/6시간을 검증. 현재 장면 답변을 모든 미래 장면에 재사용하지 않음.
4. 고정 후보에서 실제 Mac mini 동시 사건·복구·지연·지역 환경 레이어를 확인한 뒤 운영 판정. 실제 환자 경로·독립 돌봄 검토 없이 임상/실종 위치 정확도나 발견율 향상을 주장하지 않음.

새 평가 자료는 직접 원문→마음 행동 시험이다. 새32명에 대해 Mi:dm과 초기 K 모델을 재호출한 전체 온보딩 시험이 아니다. 자료 감사에서 휴식·대기·목적지 출발 부족을 확인해, 호출 전 v2에서 휴식5·대기6·출발3장면으로 보완했다. 이전 v1은 미실행 상태로 보존했으며 각 행동의 표본은 여전히 작다. [새 평가 v2 명세](next_evaluation_v2_manifest.json). 준비한 자료 수가 늘었다는 것만으로 배포 근거가 늘어난 것은 아니다.

현재 상태는 **보행 코드의 오류 수정·회귀 통과 / 개인 마음 판단 미통과 / 새 평가 미실행 / 운영 교체 미실행**이다. [다음 비교의 범위와 진행 조건](다음_비교계획.md).


## 2026-10-05 후속 실행과 시간지도 재검토

위18회 결과는 원래128회 묶음을 마친 시점의 기록이다. 이후 사용자가 새192회(개발64·통과 후보 평가128)를 승인했다. `../MIND_source_scene_20261005`에서 원문·현재 상황 입력을 비교한32회를 완료했고, 두 후보 모두 행동 제약8/16으로 다음 평가 진입 기준을 충족하지 못했다. 형식은 기존 입력12/16·원문 중심 입력8/16이었다. 나머지 개발32회도 완료했다. 짧은 지시·구조화 출력 후보는 Thinking끔 행동9/16, 켬7/16이며 어떤 후보도 확대 평가 기준을 통과하지 못했다. 별도128회는 미실행이다. [후속64회 결과](../MIND_source_scene_20261005/결과보고서.md).

사용자가 지적한 시간별 지도를 별도로 재검토했다. 원자료 분포는 다르지만 당시 개인 보행의 휴식이0분이고 방향 혼란 계수의 영향이 컸다. 확률 갱신의 작동과 실제 치매 행동 재현을 구분한 [전문기관·연구 및 코드 대조](시간별_지도_현실성_재검토.md)를 추가했다. 새 지도를 취득하거나 원래 결과 파일을 수정하지 않았다.
