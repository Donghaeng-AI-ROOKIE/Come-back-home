## 이번 결과로 바꿀 점

조건 프로그램 생성(compact16)은 장소 범위와 능력/행동 구분을 잃었다. 실행 결과를 제시한 같은 모델의 재검토도 바꾸지 못했다. 현재 장면 선택은 6장면에서 Thinking끔3통과/켬4통과로 배포 기준에 못 미쳤다. Thinking 켬만으로 해결됐다고 주장하지 않는다.

- 기준선: 기존 separate_motion_and_goal 후보와 최신 situated Thinking 후보. 서로 다른 과거 점수를 직접 비교하지 않고 같은 원문·현재 사실을 새로 입력한다.
- 입력 비교: source_scene 후보는 보호자 질문/답변 전부를 그대로 보존하고 저장된 초기 요약만 제외한다. 현재 동작·목표 기억·연속 보행·누적 보행·경과 시각을 한국어 항목으로 구분한다. 조건 프로그램을 새로 만들거나 보호자 단어를 직접 행동으로 치환하지 않는다.
- 출력 간소화 후보: 필요할 때 같은 메뉴·증거 ID를 유지하면서 자유 설명을 분리한다. 형식 개선을 개인 의미 개선으로 계산하지 않는다. 재검토가 원문을 바꾸거나 정답을 전달하지 못하도록 한다.
- 같은 후보를 실패 사례에 반복 재추출해 성공한 것만 고르지 않는다. 모든 시도·실패·사용량을 보존한다.

## 제안하는 한 묶음

개발에서 8장면의 두 반복이 모두 개인 조건을 보존하고 치명적 근거 없는 행동 추가가 없어야 별도 평가로 확대한다. 통과 후보가 없으면 나머지 평가 호출을 소비하지 않고 원인과 다음 변경을 기록한다. 호출 상한 도달 후 추가 호출하지 않는다. GPU 재학습은 준비된 2,160행의 다양성/보행 행동 커버리지부터 오프라인 감사하며 이 묶음에는 포함하지 않는다.

## 평가 기준과 해석

- 관찰/권고/타인 행동/능력/목표 발언 구분, 부정과 정정, 특정 장소 범위, AND/OR, 미확인, 가족 도착, 휴식 후 재출발, 좌표 도착과 인지 구분.
- 동일 환경의 다른 개인과 같은 개인의 다른 환경을 함께 검사. 정답은 요청 본문에 포함하지 않음.
- 합성 행동 제약≥95%, 개인 쌍 양쪽 정답≥95%, 반복 일치≥95%를 내부 진행 기준으로 사용. 명시적 거부 무시·관측 발명·장소 범위 확대·능력→의무 행동 등 중대 오류는0. 표본을 바꿔 기준을 낮추지 않음.
- 이 수치는 임상적인 실종 예측 정확도 기준이 아니다. AI가 작성한 합성 정답이며 독립 돌봄 경험자 판정이 별도로 필요함.
- 선정 결과는 명령별 소비처, KINTEX 실제 보행, 1/2/4/6시간 상태, 환경 반전·관측 만료, 저장/재시작/동시 사건까지 연결 검증. 단일 장면에서 맞은 응답을 같은 사람의 모든 미래 장면에 재사용하지 않음.
- 관측 부족·판단 유보·모델 실패를 환자 정지나 확률0으로 처리하지 않음. 불확실한 경우 일반 기준 사용 여부와 미해결량을 출력에 남김.
- 최종 운영 판정은 개인 의미·보행 실행·서비스 운영 검사를 각각 통과한 뒤 내림. 실제 환자 경로 정확도·발견율 향상을 이 결과로 주장하지 않음.

## 즉시 검토 가능한 준비물

- source_scene.py: 보호자 원문을 전부 보존하는 입력 표현 후보. import나 요청 생성은 API를 호출하지 않음.
- situated_inputs.json / situated_manifest.json: 이번6장면 원문·현재 사실·사전 정답·해시. 새 평가는 이 사례들과 분리해야 함.
- 같은 입력을 다시 쓰는 개발과 새 평가를 같은 정확도 표에 합산하지 않음.

새32명·64장면의 v1에서 휴식3·대기3·출발1장면으로 편중된 것을 확인해, 모델 호출 전에 v2로 보완했다. v2는 휴식5·대기6·출발3장면이며 호출 상한128회는 같다. v1/v2와 변경 이유·해시를 모두 보존한다. 어떤 모델 결과도 보지 않은 변경이며 실제 환자 자료가 아니다. 새 평가에는 보호자 원문만 있고 초기 해석은 비어 있으므로 새 온보딩 전체의 정확도와 구분한다.
