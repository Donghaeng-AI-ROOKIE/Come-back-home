# 시간·개인 행동 실행기 고도화

## 목적과 범위

온보딩된 치매인의 초기 특성과 근거가 있는 조건별 행동을 실제 보행에 이어 붙인다. 시간마다 지도가 다르게 보이는 것 자체를 목표로 하지 않는다. 기다리는 사람은 같은 위치에 남을 수 있지만, 걷는 사람의 시간이 발견거리 상한 때문에 멈추어서는 안 된다.

이번 작업은 기존 KINTEX 지도와 저장된 합성 입력을 사용하는 로컬 코드 수정·검증이다. 모델·임베딩·지도 API, GPU 학습, 배포는 하지 않는다. 앞선 K 개발 64회는 소진됐고 별도 평가 128회는 통과 후보가 없어 실행하지 않았다. K 후보의 배포 자격을 임의로 변경하지 않는다.

## 수정 가설

1. 개인 행동 실행과 statistical을 같은 연속 보행 시계로 계산한다. 두 경로 모두 같은 초기 개인 정보·도로·피로 모델을 사용한다. statistical은 조건별 개인 마음 정책과 갱신된 마음 상태를 적용하지 않는 대조 경로다. 과거의 종료거리 재표집 방식과 달라짐을 명시한다.
2. 방향 산포에 쓰는 0~1 상태와 제한 없이 누적되는 혼란 게이지를 분리한다. 기존 MindState의 방향 상태 또는 기존 미관측 기본값 0.5를 사용한다. 누적 게이지는 조건 평가에 남긴다. 새 임상 계수나 임의의 시간별 반경을 만들지 않는다.
3. 목적지 추구·회피 중에도 신체적 휴식이 가능하도록 한다. 피로·통증 등 신체 조건에 대한 명시적인 walk 정책은 존중한다. 일반적인 이동 의도를 무제한 보행 능력으로 처리하지 않는다. 휴식은 목적지를 삭제하지 않고, 끝나면 현재 조건을 다시 평가한다. 휴식 시간·발동 곡선은 기존의 잠정 가정이며 임상적으로 보정됐다고 주장하지 않는다.
4. 두 경로의 체크포인트를 함께 확정한다. 한쪽이라도 지도 밖 확률이 생기면 직전 정상 지도와 상태를 유지한다. 미리보기는 실시간 상태를 바꾸지 않는다.

## 검증

- 수정 전 실패를 보이는 회귀 테스트: statistical 시간 갱신, 두 상태의 원자적 저장, 분할/연속 실행 일치, 누적 혼란에 의한 방향 포화, 목적지 추구 중 휴식·재개.
- KINTEX 도로 위 여러 합성 인물/조건·난수에서 1/2/4/6시간을 계산한다. 실제 관측으로 제공하지 않은 소음·혼잡·인지는 미확인으로 유지한다.
- 이동·휴식·대기 시간 합, 도로 밖 미해결 질량, 재개 일치, 개인 조건의 대비 효과를 기록한다. 지도 반경 증가나 이동거리 감소를 정확도 향상으로 해석하지 않는다.
- 전체 backend 회귀 테스트. 실종 경로 정답·돌봄 경험자 독립 판독·운영 부하 검증은 별도 미확보 근거로 명시한다.
