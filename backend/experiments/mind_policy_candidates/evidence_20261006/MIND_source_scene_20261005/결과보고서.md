# 원문·현재 상황의 마음 해석 비교 결과

2026-10-05. K-EXAONE 신규64회 완료. 새32명 평가는0회. 후보 교체·서비스 배포 없음.

## 목적과 범위

온보딩한 사람의 개인 조건을 현재 장면에서 올바른 행동으로 바꾸는지 확인했다. 이전 조건 프로그램 생성의 오류를 피하려고 현재 장면의 행동 선택을 시험했고, 이번에는 입력 정리와 출력 제약을 비교했다. 목표는 JSON 형식을 맞추는 데 그치지 않고, 다른 장소로 반응을 확대하지 않는지, 이미 가족이 도착했을 때 기다림 조건을 해제하는지, 보행 능력과 행동을 구분하는지 확인하는 것이다.

기존 합성3명에서8개 장면을 만들고 후보별2회 반복했다. 이는 새로운 환자64명이 아니다. 보호자 원문과 사전 행동 기준은 모델 호출 전에 동결했다. 새32명·64장면의 별도 평가 자료는 호출하지 않았다. 독립 돌봄 경험자나 임상 전문가가 채점한 자료가 아니다.

실행 계약에는 JSON 문법 외에 status와 명령의 일관성, 실제 원문 ID, 허용 명령 검사 등이 들어간다. 따라서 JSON 객체16개를 만들었어도 supported와 baseline을 함께 출력한1개는 실행 계약에서 탈락했다. 형식 개선을 개인 행동 해석 개선으로 계산하지 않는다.

어떤 후보도 개발 단계의16/16 행동 조건 보존 기준을 통과하지 못했다. 성공한 장면만 후보별로 골라 합친 점수를 만들지 않았고, 남은128회의 별도 평가도 시작하지 않았다. 프로젝트 내부의 개발 기준이며 임상 배포 정확도 기준이 아니다.

## 실제 오류와 관찰

- 가족이 이미 있는 장면인데 “가족이 올 때까지 기다림”을 다시 선택했다. 조건의 해제를 잘못 읽었다.
- 휴식이 필요한 시점에 도달했다고 설명하고도 현재 걷고 있다는 이유로 휴식을 선택하지 않았다. 현재 동작과 다음 동작을 혼동했다.
- “피하지 않았다”를 “계속 걷는다”로 바꾸거나 보행 가능 시간을 현재 걷기의 근거로 사용했다. 원문에 없는 행동을 보탰다.
- 원문 중심 후보에서는 행동 라벨은 맞았지만 확인된 거짓을 미확인으로 설명한 응답도 있었다. 행동 명령 정답과 공개 근거의 사실 정확성도 분리해서 보아야 한다.

W1의 “오 분 정도, 삼백 미터쯤 걸으면 앉아서 쉬어야 해요”는 기능상 휴식 필요의 진술이다. 독립 평가에서는 실제 관찰된 휴식, 보호자의 권고, 기능 한계를 구분해 판정해야 한다. 원문의 자연어가 임상적 행동 정답을 자동으로 제공하지는 않는다. 이번 사전 점수는 유지하며, 이 한계를 숨기고 환자 정확도로 소개하지 않는다.

응답 공개 자료는 `development/` 및 `structured_recovered/`의 `response.public.json`에 있다. 내부 reasoning 원문은 공개 결과에서 제외했다. 사전 장면은 `development_inputs.json`, 상세 판정은 `final_summary.json`, 첫 비교의 공개 설명 대조는 `development_failure_audit.json`에 보존했다.

## 조건과 자원

공통 모델 요청 별칭은 `depmkuykpfon9lg`이며 원격환경의 기존 K-EXAONE 설정을 사용했다. 별칭만으로 기반 가중치 리비전을 독립 검증했다고 주장하지 않는다. temperature0.2·top_p0.95·max_tokens12,000, 동시2회, 입력40,000바이트 이하. 새 GPU 학습·SAR·Mi:dm·RAG 검색·임베딩·지도 호출은 없다. 이번 마음 입력에는 RAG 발췌를 넣지 않아 RAG의 효과를 평가한 실험도 아니다.

마지막 두 후보는 같은 입력·프롬프트·JSON Schema·출력 상한에서 Thinking 설정만 달랐다. 앞의 입력 비교에서 뒤의 짧은 지시 후보로 갈 때는 프롬프트와 출력 제약이 함께 바뀌었으므로 각 요소의 인과 효과를 분리하지 않는다.

64회 모두 시작·종료 이벤트를 대조했다. 공급자 응답64개 중50개는stop,14개는출력 한도 종료였다. 공급자 보고 입력94,918·출력266,242·총361,160토큰. 단가·청구액·지원 차수·GPU 청구시간은 미확인이다. 실패나 크레딧 사용을0원으로 적지 않았다.

두 번째 묶음의 첫 로컬 전송은 샌드박스 SSH 권한으로 막혔다. Mac mini의 해당32개 작업 실행 표식·이벤트·응답이 모두0임을 읽기 전용으로 확인했다. 같은 요청 본문과 attempt ID를 유지해 최초 원격 제출을 완료했고, 원격 배타적 실행 표식으로 중복 제출을 막았다. 초기 전송 실패는 `structured/`, 실제 최초 모델 응답은 `structured_recovered/`에 각각 보존했다. 모델 재호출은0회이며 시작64·종료64의 로컬/원격 event ID 지문이 일치한다.

## 시간별 지도 질문과의 관계

이번 K 비교는 현재 장면의 개인 해석이다. 지도 현실성은 별도로 [원래 시간 지도·전문기관 자료·보행 코드 대조](../MIND_release_convergence_20261004/시간별_지도_현실성_재검토.md)에 정리했다. 원래 지도는 완전히 같지는 않지만, statistical 채널의4→6시간 분포가 동일했고 개인 보행에는 휴식0분·방향 혼란 계수의 강한 영향이 있었다. 모델 출력 개선만으로 이 엔진 문제가 해결됐다고 할 수 없다.

다음 수정은 개인의 지속적인 길찾기 특성, 변화하는 피로·불안, 보호자가 말한 기능 한계를 구분해 각 소비처를 확인하는 데 초점을 둔다. 후보가 개발 기준을 통과하기 전에는 별도128회를 소모하거나 운영 후보로 연결하지 않는다. 실제 환자 경로 정확도와 발견율은 이번 합성 자료로 주장하지 않는다.
