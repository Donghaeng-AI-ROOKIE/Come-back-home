# 개인 행동 시뮬레이션 완성 검증

사용자 요청: 이전에 정리한 ① 개인 정보 전달 ② 도착 후 행동 ③ 정보 부족 처리 ④ 연속 시간별 제품 연결 ⑤ 새 사례·운영 규모 평가 전부 진행.

## 실행 범위

- 별도 개발 브랜치에서 구현·회귀·합성 입력 평가·KINTEX OSMnx 보행 평가. 운영 배포는 통과 결과가 있을 때 별도 판단하며 이번 작업 중 임의 배포하지 않는다.
- 개인별 행동 조건 해석 후보 개발 및 검증: K-EXAONE 신규 최대 128회(개발/보완 최대 80, 별도 평가 최대 48). 실패·빈 응답·검토 호출 포함, 자동 재시도 없음. 호출당 입력 UTF-8 40,000바이트·출력 12,000토큰, 동시 최대 2. 전체 출력 상한 1,536,000토큰. 실제 usage·오류·사용 기간 기록. 단가·실청구액·지원 차수 미확인.
- 기존 원문·저장된 K 초기 해석·SAR prior와 KINTEX 지도 캐시 재사용. 신규 SAR·Mi:dm·임베딩·GPU 학습 없음. 새 지도 필요 시 KINTEX 동일 중심의 보행망 외부 HTTP 요청 최대 2회까지 별도 기록한다. 자동 재시도/다른 지역 대체 없음.
- 사용자가 다섯 작업 전체의 실행을 지시했으므로 이 범위에서 구현과 검증을 진행한다. 원장 기록은 모든 외부 호출 전에 연결한다.

## 설계 원칙

- 보호자 문장의 행동·조건·범위 해석은 K가 수행. 단어 포함 여부로 개인 행동을 정하는 코드는 만들지 않음.
- K의 해석은 원문 ID와 정확한 인용을 갖는 제한된 행동 조건으로 저장. 코드가 조건의 참/거짓/미확인과 시뮬레이션 시간을 평가.
- 좌표 도착과 본인의 인식을 구분. 오래된 관측을 최신으로 바꾸지 않음. 입력이 바뀌면 해석 캐시 무효화.
- 확인되지 않은 조건의 후속 행동은 가능한 분기로 유지. 분기 가중치의 가정·미보정 상태를 결과에 명시하며 LLM 자신감을 확률로 쓰지 않음.
- 1시간마다 이전 상태를 이어가고, 휴식·대기·이동 시간의 합과 도로 위 위치를 보존. 모델/API 장애를 환자의 정지로 바꾸지 않음.
- 기존 통계 prior·발견거리와 새 연속 행동 모델의 역할을 분리. 상한을 무작정 늘리거나 6시간 내내 걷게 강제하지 않음.

## 판정

1. 현재 정보 전달 회귀 + 오래된 관측/정정/버전 변경/개인 간 누출 검사.
2. 도착·인식·체류·재출발, 휴식 재개, 조건 해제, 미확인 분기 검사.
3. 개발에 사용하지 않은 합성 온보딩 24개와 다중 장면 평가. 모델 의미는 사전 작성한 기대 제약으로 평가하며 실제 환자/독립 사람 평가로 표현하지 않음.
4. 실제 KINTEX 도로에서 개인 차이와 조건 차이의 효과, 같은 seed의 시간 분할/연속 실행 일치, 1/2/4/6시간 결과·확률 질량·지도 경계 검사.
5. 운영 설정의 보행자 수로 시간·메모리·호출량 측정, 제품 API 연결 검사. 연구용 출력 성공을 서비스 연결 성공으로 대체하지 않음.

완료 판정은 기술적 연결과 별도 합성 평가 통과에 한정. 실제 실종 경로 예측 정확도는 이 실험으로 입증하지 않는다. 미통과 항목은 숨기지 않는다.
