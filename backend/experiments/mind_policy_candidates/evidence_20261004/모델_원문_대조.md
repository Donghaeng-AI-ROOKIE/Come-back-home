# 보호자 원문과 모델 최종 출력 대조

합성 사례다. 내부 추론은 포함하지 않는다. 추론 표식 뒤 최종 부분만 추출한다. 코드가 행동 명령을 수정한 결과가 아니다.

## holdout_01

원문

> 질문: 직접 관찰한 반응과 조건을 알려주세요.
> 답변: 길을 잃었다는 것을 스스로 알면 그 자리에 서서 가족을 기다려요. 가족이 오기 전까지는 안 움직여요.

### 최초 응답

종료 상태: stop

```json
{
  "rules": [
    {
      "id": "wait_lost_no_family",
      "action": "wait",
      "when": {
        "lost_awareness": true,
        "family_present": false
      },
      "target": null,
      "feature": null,
      "places": [],
      "minutes": null,
      "supersedes": [],
      "notes": [
        "N0"
      ]
    }
  ],
  "unused_note_ids": []
}
```
