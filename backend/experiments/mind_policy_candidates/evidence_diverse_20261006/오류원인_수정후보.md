# 확대 비교에서 드러난 수정 지점

이 문서는 고정된 비교 결과를 바꾸지 않는 원인 분석이다. 아래 수정을 적용한 성능은 아직 측정하지 않았다. 진행 중인 후보·프롬프트·정답·채점 기준은 그대로 유지한다.

## 1. 요약에는 있지만 실행 규칙에서 사라짐

- P05 / Thinking 끔 / 첫 응답: ‘8분 또는 450m 후 휴식’ 원문을 넣었지만 `rules=[]`가 나왔다. 두 번째 응답은 동일 원문에서 정확한 휴식 규칙을 만들었다.
- 동일한 중심 출발점·시드17·100보행자에서 첫 응답은 개인 휴식 규칙 적용 시간이 0분, 두 번째는 평균 약135.63분이었다. 6시간 누적 보행 거리는 각각 약15.71km·10.72km였다. **출발점에서의 반경이 아닌 길을 따라 걸은 거리 합계**다. 이 거리 자체가 임상적으로 타당하다는 주장은 아니다.
- P25 / Thinking 끔 / 두 번째 응답은 8~9시 대기를 요약하면서도 ‘명령 실행이나 반복적 행동 패턴은 명시되지 않았다’며 규칙을 비웠다. 입력에 없는 추가 요건을 적용한 것으로 보인다.
- 개선 후보: 원문별 ‘실제로 관찰한 반응 / 신체적 필요 / 비행동 정보’의 판정을 명시하고, 반응으로 판정한 근거 ID가 규칙에서 빠졌다면 누락으로 표시한다. 코드가 단어를 보고 행동을 만들어 메우는 방식은 사용하지 않는다. 의미 판정 자체가 틀릴 수 있으므로 이 누락 검사는 단독 성능 근거가 아니다.

## 2. 방향이 있는 이동을 그냥 걷기로 바꿈

- P14 / Thinking 켬 / 두 번째 응답은 요약에 “When target_recognized is true, the person walks towards 느티공원.”이라고 썼다.
- 실제 출력은 `command="walk"`, `condition="target_recognized"`, `place_labels=["느티공원"]`였다. 목적지 선택 명령 `seek_0`를 만들지 않았다.
- 이 계약에서 `place_labels`는 **명령을 적용하는 장소 범위**다. 목표 장소가 아니다. 따라서 공원으로 향하는 이동이 ‘공원 가까이에서 걷기’로 달라졌다. 이는 JSON 형식 검증으로 찾을 수 없는 의미 오류다.
- 개선 후보: 목적지와 적용 장소를 서로 다른 의미로 명시하고, 행동 명령별 설명을 프롬프트·스키마에 추가한다. `walk=목적지 새 지정 없이 걷기`, `seek=특정 목표로 이동`을 구분한다. 기존 코드가 JSON을 정상 소비하더라도 이러한 해석 오류는 남는다.

## 3. 출력 미완료와 겉포맷 오류를 분리

- Thinking 켬 일부 응답은 `finish_reason=length`로 끝났다. 온전한 최종 JSON이 없으므로 성공으로 복구하지 않는다.
- 일부 완료 응답은 온전한 JSON 앞에 `.` 또는 짧은 문자가 붙어 현재 파서가 거부했다.
- `diagnose_completion.py`는 `stop` 응답에서 짧은 잔여 문자와 완전한 단일 JSON 객체만 있는 경우를 오프라인으로 분리한다. 여러 후보 객체·잘린 출력·스키마 오류는 허용하지 않는다. 원본 성적을 수정하거나 이 파서를 제품에 적용하지 않았다.
- 개선 후보: 엄격한 JSON 경계 처리는 별도 공학 수정으로 검증할 수 있다. 하지만 미완료 출력과 행동 누락까지 해결했다고 주장하면 안 된다. Thinking 종료·출력 예산 문제는 별도 후보 비교가 필요하다.

## 4. 과거 관찰과 현재 의도

- 현재 프롬프트에는 초기 해석에서 재사용한 `SOURCE_PRECEDENCE`가 들어 있다. 이 중 ‘과거 사건이면 현재 의도로 해석하지 않는다’는 원칙은 현재 목적지를 단정하지 않도록 하는 데 필요하다.
- 한편 마음모델의 규칙은 과거 관찰에서 얻은 조건부 반응을 보존하는 작업이다. 과거 반응을 모두 버리면 사람의 특성이 사라진다.
- 이 둘의 혼동이 규칙 누락에 기여했는지는 **가설**이다. 이번에는 해당 문장을 바꾸지 않았으므로 원인이라고 확정할 수 없다. 후속에서는 ‘현재 의도 단정 금지’와 ‘과거 관찰의 조건부 반응 보존’을 구분한 후보를 같은 원문으로 비교해야 한다.

## 5. 걷기 결과와 근거 보존은 별도

P21에서 개인의 ‘계속 걷기’가 빠져 baseline이 선택돼도 일반 이동 prior가 걷기를 만들 수 있다. 이때 규칙 보존은 실패했지만 보행자가 멈췄다고 보고하면 틀리다. 반대로 P05처럼 휴식 규칙 누락이 실제 휴식·거리 차이로 이어지는 사례도 있다. 따라서 원문 해석 점수와 보행 실행 점수를 함께 제시한다.
