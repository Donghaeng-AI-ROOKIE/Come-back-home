# 후속 개선·인계 문서

2026-10-06 작성한 인계 ZIP의 문서·증강 초안을 보존했다. 신규 실험 계획이며 실행 결과가 아니다.

- [개선 계획](마음모델_다음개선계획.md)
- [증강 설계](데이터_증강_설계.md)
- [다음 AI 프롬프트](다음_AI_인계프롬프트.md)

문서의 ZIP 상대경로는 당시 패키지 기준이다. 저장소에서는 입력·응답·채점은 상위 폴더, 코드는 `backend/app/` 및 `backend/experiments/mind_policy_candidates/`, 증강은 이 폴더의 `augmentation/`에 있다. 오프라인 검증은 backend에서 `python -m experiments.mind_policy_candidates.verify_diverse_evidence`로 실행한다.

원래 로컬 홈 경로·원격 주소는 공개본에서 치환했다. 새 실행 시 현재 환경을 확인한다. 416호출 계획과12개 증강 초안은 미실행·미검토이며 과거 승인 파일은 새 실행 승인이 아니다.

전체 ZIP은 작성자에게 전달된 로컬 인계물이며 저장소에 중복 첨부하지 않았다. ZIP에는 큰 지도와 코드 사본도 있다. 이 PR에는 지도 취득 명세·해시를 남겼고, 저장 보행 결과 검증은 지도 재취득 없이 가능하다.
