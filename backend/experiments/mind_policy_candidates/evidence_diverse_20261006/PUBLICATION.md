# 공개 자료와 원본의 관계

이 폴더는 완료한 `MIND_diverse_comparison_20261006`의 후속 PR 공개본이다. 입력32명·장면128개·요청/공개 최종 응답128회·전체512판정·공간384칸을 보존했다. 성공 출력만 고르지 않았다.

- `comparison/`: 모델 입력·공개 최종 응답·실패·컴파일 정책. 내부 Thinking 원문 없음.
- `spatial_index.json`:384칸의 상태·개인 조건 검사·6시간 지표.
- `spatial_records.tar.gz`:384공간 원자료와 당시 실행 manifest. 압축으로 원본 내용을 버리지 않음.
- `spatial_archive_manifest.json`:압축 내부 원본/공개본 해시.
- `spatial_examples/`:본문에서 설명한4개 기록을 직접 열람 가능.
- `source_snapshot/`:당시 후보·평가·보행 소스. 원래 실행 스크립트는 보존용이며 자동 재실행하지 않음.
- `handoff/`:다음 개선·증강 계획과12개 검토 전 초안. 신규 실험·학습·배포를 수행한 자료가 아님.

개인 로컬 절대경로·원격 주소만 치환했다. 원문·모델 응답·판정은 바꾸지 않았다. 원본/공개본 해시를 구분한다. 합성 입력의 `guardian_original` 태그는 시험 계약의 출처 구분이며 실제 보호자 자료라는 뜻이 아니다.

별도 평가64회는 단계 기준 미달로 미실행이다. 승인 파일은 과거 범위 증거이며 새로운 후보 호출을 승인하지 않는다. `RELEASE_QUALIFIED=False`를 유지한다.

새 결과가 나오기 전까지 이 폴더를 덮지 말고 새로운 버전·실험 폴더를 사용한다.
