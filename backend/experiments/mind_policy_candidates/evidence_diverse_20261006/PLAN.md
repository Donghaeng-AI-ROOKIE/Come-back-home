# 최신 마음모델 확대 비교 계획

2026-10-06 · 개발 16판정 반복 대신 새 인물·상황·공간 확대

## 바뀌는 기준 단위

- 기존: 합성 3명, 8장면, 각 2응답으로 16판정.
- 새 비교: **새 합성 32프로필 × 4장면 × 2응답 = 설정당 256판정**.
- 최신 `condition-program-v4`의 Thinking 켬/끔을 동일 입력으로 비교: **K 호출 128회, 행동 판정 512건**.
- 프로필은 8개 행동군별 4개다. 이름만 바꾼 증강이 아니라 관찰 근거, 발동·종료 조건, 장소 범위, 수치·단위·미관찰 여부를 달리했다. 동일 계열·짝지은 반례가 있으므로 512판정을 독립 환자 512명처럼 계산하지 않는다.
- 기존 추가 6회 계획은 이번 확대 요청으로 대체한다. 3명 자료에서 15/16을 얻을 때까지 반복하는 방식으로 돌아가지 않는다.

## 다양성

| 행동군 | 서로 구별할 내용 |
|---|---|
| 환경 | AND/OR, 장소 이름/유형, 소음/혼잡, 타인 사례 |
| 신체적 휴식 | 시간/거리, 능력/필요, 통증/피로, 이미 휴식 중 |
| 기다림 | 길 잃음 인지/불안/가족 부재, 가족 도착, 단순 권고 |
| 목적지 | 발언/실제 출발, 인지/물리적 도착, 시간 조건 |
| 외부 상태 | 비/어둠/소음, 명시 관측/미관측, 시각과의 구분 |
| 원문 충실성 | 정정, 부정, 다른 가족의 사례, 짧은 답과 질문 문맥 |
| 시간 | 오전 경계, 자정 통과, 실제 보행 시간과 시계 시각 |
| 복합 반응 | 휴식+대기, 회피+휴식, 우선순위가 없는 동시 반응 |

한 프로필마다 4장면을 미리 고정했다. 시작 조건만 맞히는 것을 막기 위해 비발동·해제·경계·미관측 장면을 포함한다. 모든 자료는 연구자가 작성하고 읽은 **합성 기대 행동**이며 실제 환자 사례·전문가 평가가 아니다. 기대 행동과 원문이 임상적으로 타당한지는 별도 검토 대상이다.

`profiles.json`만 K 입력에 쓴다. `scenes.json`의 정답·장면과 `reference_policies.NOT_MODEL_INPUT.json`은 K에 전달하지 않는다. 수기 참조 정책은 문항과 채점기의 내부 일관성을 점검하는 자료이며 모델 성능으로 집계하지 않는다.

## 고정 비교와 판정

1. 최신 v4 코드·프롬프트를 고정한다. 두 설정의 차이는 `enable_thinking`이다. 비교 중 결과에 맞춰 후보를 수정하지 않는다.
2. 각 인물의 설정·반복 순서를 고정된 난수로 섞는다. 같은 장면을 맞힌 응답만 선택하지 않는다.
3. 출력 실패·빈 응답·한도 소진은 모두 실패로 포함한다. 유효한 응답도 행동 의미를 따로 검사한다.
4. 설정별 **231/256 이상(90%)**, 행동군별 **26/32 이상(80%)**, 실제 반응이 요구되는 장면 **76/84 이상(90%)**, 응답 계약 통과 **61/64 이상(95%)**을 진행 기준으로 둔다. 비발동 장면이 많은 점을 이용해 실제 반응을 누락하고도 높은 전체 점수를 얻는 것을 막는다. 이는 프로젝트 내부 단계 기준이며 배포·임상 정확도 기준이 아니다.
5. 미관측으로 인해 두 행동이 가능한 장면은 `unknown`과 사전 지정한 가능 행동 집합을 맞혀야 한다. 모든 장면에 `unknown`을 내서 통과할 수 없다. 완전히 관측된 비발동 장면은 `baseline`이어야 한다.
6. 인물별·행동군별·반복별·출력 실패를 공개한다. 같은 프로필의 반복/장면은 상관된 관측이므로 독립 이항 표본처럼 오차 범위를 주장하지 않는다.
7. 둘 다 통과하면 행동군의 최저 성적, 전체 행동 성적, 출력 완료율 순으로 선택한다. 동률이면 실제 기록된 생성량·소요 시간을 보고 선택 이유를 남긴다. 둘 다 미달이면 선택하지 않는다.
8. 선택 후보를 고정한 뒤 기존 미사용 별도 32명×2장면×2응답, 64호출·128판정을 수행한다. 기존 기준 116/128 이상 유지. 비교 자료와 합산해 성적을 높이지 않는다. 이 별도 파일도 개발자가 이전에 작성·읽은 합성 자료이므로 독립 임상 평가라고 부르지 않는다.

## 공간과 시간 검증

현재 기본은 기존 사용자 지정인 **고양 KINTEX 캐시 내 6개 출발 구역**이다. 중심 도로 분기와 북서·북동·서·동·남쪽 도로를 정해 동일 정책을 여러 지형에 둔다. 약 0~1km 범위의 도로상 지점을 사용하고, 실제 전시장 출입구라고 부르지 않는다. 다른 지역까지 뜻했는지는 사용자에게 별도로 확인 중이며 새 지도 호출은 이번 범위에 넣지 않았다.

지도는 2026-10-04 취득 OSMnx 2.1.0 캐시, SHA-256 `953d2bca91fe7388011e9ca161dc576c3c79366c578ed314d7cc8deea677db92`를 검증한다. 출발 노드·좌표·주변 분기 수·등록 목적지의 합성 배치를 `sites.json`에 보존한다. 실제 도로를 사용하되 시설 배치와 소음·혼잡·가족 도착·비·어둠은 **합성 관측**이다.

실호출 응답을 바꾸지 않고 기존 보행 엔진에 전달한다. 우선 행동군별 대표 1명(8명) × 2설정 × 2응답 × 6구역 × 2보행 시드 = **384개 집단**, 각 100보행자에서 1·2·4·6시간 상태를 이어 계산하는 오프라인 진단으로 설계한다. 모델 해석이 틀린 응답도 유효하면 진단임을 표시해 관찰하고, 형식 실패는 실행 불가로 기록한다. 이 진단의 반복·보행자·지도 칸을 사람 수나 모델 호출 수로 더하지 않는다.

행동 선택 오류와 엔진 전달 오류를 구분한다. 기다림 해제·휴식과 재보행·거리/시간 경계·회피 방향·목적지 인지·미관측 분기·확률 질량·체크포인트를 본다. 시간별 지도가 달라진다는 것만으로 정확하다고 판단하지 않고, 계속 기다려야 하는 조건이면 동일 위치를 허용한다. 먼저 기존 최신 저장 응답으로 6구역의 재생 경로를 확인하는 것은 신규 API 호출 없이 가능하다.

실험 시간대는 문항에 따른 현지 시각을 사용한다. 실제 동선 정답이 없으므로 발견 위치 정확도나 실제 치매 행동 재현 성공률로 보고하지 않는다. 새 GPU 학습·모델 튜닝·배포는 하지 않는다.

## 외부 호출 범위와 비용

- 신규 비교: K-EXAONE **최대 128회**(32프로필×2설정×2반복).
- 비교 통과 후 기존 미사용 별도 평가: K-EXAONE **최대 64회**. 이전 실험의 평가 원장과 합쳐 이 64회 한도를 유지한다.
- 합계 최대 **192회**. 실패·빈 응답 포함, 모델 자동 재시도 없음, 동시 최대 2회.
- 호출당 입력 최대 40,000 UTF-8 바이트, 출력 12,000토큰. 비교 출력 상한 1,536,000토큰, 별도 평가 포함 전체 상한 2,304,000토큰. 실제 입력·생성량은 응답 usage로 기록한다.
- 단가·실청구액·지원 차수 미확인(null). 미확인을 0원으로 쓰지 않는다.
- 새 SAR·Mi:dm·RAG 검색·임베딩·지도·GPU 학습·배포 없음. 오프라인 재생은 로컬 CPU로 수행한다.
- 공용 원장과 원격 원장에 시작/종료/실패를 남기고 event_id로 대조한다. 키·원문·주소는 비용 원장에 넣지 않는다.

이 범위는 이후 사용자의 **“승인”**으로 확정되었다. 실행 승인은 `authorization.json`에, 기존 별도 평가 64회의 이전 기록은 `previous_authorization_before_transfer.json`에 보존했다. 위 조건과 판정 기준은 비교 시작 뒤 바꾸지 않는다. 루트 AGENTS.md의 승인·비용 기록 규정에 따라 실행한다.
