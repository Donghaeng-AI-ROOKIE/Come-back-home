# 보고서4.1용 이번 실험 사용량

전체 연구지원 실적이 아닌 이번 확대 비교의 사용량이다.

| 차수 | 구분 | 활용자원 | 활용 규모 |
|---|---|---|---|
| 미확인 | 생성형 AI API (국내) | K-EXAONE API | 2026-10-06 사용(1일),128호출. 입력 218,096토큰·생성 383,341토큰, 합계 601,437토큰 |

단가·실청구액·지원 차수 미확인. 실패 호출도 포함. 기존 KINTEX 지도 캐시를 재사용했고 신규 GPU 학습·SAR·Mi:dm·RAG·임베딩·지도 호출은 없다. `usage_summary.json`과 `ledger_reconciliation.json`에서 근거를 확인할 수 있다.
