# 검증 요청 — 실종자 제보 신뢰도 판정 "정답표" 70개 타당성 검토

## 배경

치매·지적장애인 실종자 수색 앱에서, 시민 제보(자유텍스트)를 받아 신뢰도 p를 계산하고
아래 규칙으로 판정합니다.

```
p = (개연성 × w1 + 구체성 × w2) / (w1 + w2)   # 가중평균, 재정규화
판정: p < 0.2 → 파기(discard, 허위/스팸 취급)
      0.2 ≤ p < 0.8 → layer1(약한 베이지안 갱신만)
      p ≥ 0.8 AND 위치·시각 둘 다 특정됨 → layer2(새 탐색 기준점으로 확정, 재수색 트리거)
      p ≥ 0.8 이지만 위치·시각 불특정 → layer2 자격 없음 → layer1
```

- **개연성**: "이 시간 동안 이 거리를 이동 가능한가"를 물리 공식(exp 감쇠)으로 계산. 텍스트
  내용과 무관 — 좌표·경과시간으로만 결정됩니다.
- **구체성**: 제보 텍스트가 장소·시각·외모 3요소를 얼마나 구체적으로 담았는지 상(0.9)/
  중(0.6)/하(0.3) 3등급.
- layer1의 실제 갱신식은 `p·L + (1-p)`입니다 — p가 낮을수록 거의 무의미(중립)에 가까운
  갱신이 됩니다. **discard와 layer1의 실질적 차이는 "완전히 버리느냐 vs 거의 안 쓰지만
  살려두느냐"**입니다.

## 지금 검증받고 싶은 것

아래 70개는 실험용으로 만든 시나리오입니다. 각각 (제보 텍스트, 구체성 등급, 개연성 값,
위치·시각 특정 여부)가 주어져 있고, **최종 판정(discard/layer1/layer2)은 사람이 정해야
하는 정책 판단**이라 제가(AI가) 초안을 달았습니다. 이 초안이 타당한지 비판적으로 검토해
주세요.

### 제가 쓴 판단 원칙 4가지

1. **discard는 "허위/스팸"용이지 "물리적으로 빠듯하지만 진술이 조리 있는" 제보용이 아니다**
   — 저신뢰 신호도 누적되면 유의미해질 수 있어서(설계자의 명시적 원칙), 어지간하면 discard
   보다 layer1을 기본값으로 뒀습니다.
2. **서술이 구체적이거나(상) 물리적 일치가 거의 완벽하면(개연성 0.9+) layer2를 기본값으로
   뒀습니다** — 개연성 기준(v_max)이 문헌 기반 보수적 추정치라, 살짝 벗어나는 정도는 실제
   변동 범위 안일 수 있다고 봤습니다.
3. **"확신에 찬 어조 + 실질 내용(장소·시각·외모) 없음" 조합은 의심 신호로 봤습니다** —
   특히 이미 신뢰도가 가장 낮은 구간(구체성 하 + 개연성 낮음)에서 이 패턴이 겹치면 discard로
   낮췄습니다.
4. **"제보 속 인물이 여러 명이라 누가 실종자인지 특정 안 됨"은 서술이 모호한 것과는 다른
   위험으로 봤습니다** — 특히 layer2(새 탐색 기준점 확정)로 갈 때는, 대상이 안 정해지면
   물리적 일치가 아무리 좋아도 절반은 틀린 사람 기준일 수 있어서 layer1로 낮췄습니다.

  다른 판정을 준 경우)

- 반대로 제가 **과도하게 의심한** 곳이 있나요? (정상적인 제보인데 제가 discard/하향한 경우)
