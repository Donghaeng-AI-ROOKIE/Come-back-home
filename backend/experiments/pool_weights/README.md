# P1-6 — α-pool · topdown 가중 · 전환기준 재검증

실험 상세 설계안(0724 분업) [대흠] 몫. 선행조건이던 [서영] P1-2(전부 도보, PR #70)
머지 후의 코드 상태에서 세 상수군을 재검증한다:
`alpha_pool [0.7, 0.3]`(pipeline.py) · `0.6·ring + 0.4·bump, σ=0.3km`(topdown.py) ·
`pool_mode 전환 tips ≥ 3`(pipeline.py).

## 방법

- 치매 78세+끌림점 시나리오, 경과 3h, bottom-up(agent, LLM 스텁)/statistical 300워커,
  seed {42,43,44} 평균, 정릉 3km 캐시 도로망.
- **α 효과 순수 분리**: bu/stat 시뮬은 seed당 1회만 돌리고 α만 바꿔 재결합.
- **topdown은 파라미터화 복제본으로 스윕** — 현행 파라미터(0.6, 0.3) 재현
  최대오차 0.00e+00 검증 후 사용(복제 드리프트 없음).

## 결과 (results/pool_weights.md 전문)

| 상수 | 판정 | 근거 |
|---|---|---|
| α-pool 0.7/0.3 | **유지** | α 0.5~0.9 전 구간에서 coverage80 15→14.7셀, 끌림점 질량 ±0.005, JS ≤0.004 — 스텁 조건에서 사실상 둔감 |
| topdown 0.6/0.4 | **유지** | ring_w↑ 면 끌림점 질량 단조 감소(0.051→0.042), 0.6은 링 우위를 지키면서 범프를 살리는 중앙 균형점 |
| 끌림점 σ 0.3km | **유지** | σ가 끌림점 질량의 주 노브(0.2: 0.041 → 0.5: 0.050). 0.3은 H3 셀(변 174m) 기준 범프 반경 2~3셀로 격자 해상도와 정합 |
| 전환기준 tips≥3 | **유지** | log_linear 전환 시 coverage80 **35.6% 축소**(15→9.7셀) 실측 — 제보 1~2건 단계 발동이면 오제보 1건이 수색 범위를 이만큼 잘라내는 위험 |

## 핵심 발견

- **α 둔감성은 스텁의 산물이다.** 현재 bu(agent)의 마음 재해석이 스텁이라 bu와 stat
  분포가 유사해 α가 결과를 거의 못 바꾼다. 실 EXAONE prior가 붙어 bu가 개인화되면
  α 재측정이 필요 — **α 튜닝은 EXAONE 서빙(P2-1) 이후에 해야 의미가 있다.**
- topdown의 범프 질량이 전체의 4~6%에 그치는 것은 bump가 `(ring+ε)`에 곱해지는
  구조 때문(링이 죽는 원거리에선 범프도 죽음) — 의도된 "링 우위" 설계의 결과다.
