# P1-4 — road/env strength 노브 그리드서치

실험 상세 설계안(0724 분업) [대흠] 몫. `road_preference_strength`·`env_response_strength`
(config.py, 기본 둘 다 1.0)가 실제로 무엇을 얼마나 움직이는지 측정하고 기본값을 판정한다.

## 방법

- statistical 모드 300워커, 스윕은 seed {42,43,44} 평균(최소~최대 병기), 경과 3h,
  정릉 3km 캐시 도로망 — LLM 호출 0회, 비용 0, 재현 가능.
- 두 노브는 소비 메커니즘이 독립(도로=치매 한정 갈림길 지수 / env=사정거리 내 배수)이라
  1-D 스윕 {0, 0.5, 1.0, 1.5, 2.0} × 효과 지표 + 3×3 코너 그리드 × 상식 지표(sim_testset 밴드).
- 셀 분류: 소속 노드 인접 에지의 `_ROAD_PREFERENCE` 평균 <0.95 기피 / >1.05 선호.
  수변 셀 = `water_m` ≤ 사정거리(100m) 노드 보유 셀. 정릉 3km: 기피 5 / 선호 394 / 수변 93.

## 결과 (results/gauge_ablation.md 전문)

| 판정 | 근거 |
|---|---|
| 도로 노브: **작동·단조** | 치매 기피셀 질량 0.042→0.018 (−58%), 선호셀 0.891→0.931 단조 증가 |
| 도로 노브: **적용범위 정확** | ID는 전 스윕에서 지표 완전 불변(코드 경로 자체가 없음) — 치매 한정 설계 검증 |
| env 노브: **전역 효과 미약** | 수변셀 질량 0.044→0.052(+0.8%p), seed 범위(0.04~0.073) 중첩 — 노이즈 구분 불가 |
| 안전성: **거리 캘리브레이션 불침** | dist_ratio 전 조건 0.3008 고정 — 노브가 Koester 거리 분포를 오염하지 않음 |
| 상식 지표: **전 그리드 통과** | 3×3 전 조합 시간 단조성 O, 1h dist_ratio 밴드(0.2~1.5) 내 |

## 권고

1. **두 노브 모두 기본 1.0 유지.** 효과 방향이 검증됐고 거리 캘리브레이션을 건드리지 않아
   켜둬도 안전하다. ablation 서사(끔↔강조 대비)는 0↔2로 시연.
2. 도로 노브의 전역 효과가 작은 것은 정릉 3km 도보 그래프에 간선 성격 셀이 5개뿐인
   구조적 천장 때문 — 노브 결함이 아니다. 간선이 많은 지역에서 재측정 여지.
3. env 노브의 국소 효과(PR #56 실측: 800m 픽스처 ±10%p)와 전역 무효과의 간극은
   사정거리(수변 100m) 국소 소비 구조에서 온다. **개인화 기여 증명은 노브 증폭이 아니라
   V2 per-person hit@거리 평가(제안서 P0)로 재는 것이 맞다.**
