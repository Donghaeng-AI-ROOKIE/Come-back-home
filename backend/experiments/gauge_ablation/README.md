# P1-4 — road/env strength 노브 그리드서치

실험 상세 설계안(0724 분업) [대흠] 몫. `road_preference_strength`·`env_response_strength`
(config.py, 기본 둘 다 1.0)가 실제로 무엇을 얼마나 움직이는지 측정하고 기본값을 판정한다.

## 방법

- statistical 모드 300워커, 스윕은 seed {42,43,44} 평균(최소~최대 병기), 경과 3h,
  정릉 3km 캐시 도로망 — LLM 호출 0회, 비용 0, 재현 가능.
- 두 노브는 소비 메커니즘이 독립(도로=치매 한정 갈림길 지수 / env=사정거리 내 배수)이라
  1-D 스윕 {0, 0.5, 1.0, 1.5, 2.0} × 효과 지표 + 3×3 코너 그리드 × 상식 지표(sim_testset 밴드).
- 셀 분류: 소속 노드 인접 에지의 `_ROAD_PREFERENCE` 평균 <0.95 기피 / >1.05 선호.
  수변 셀 = `water_m` ≤ 사정거리(100m) 노드 보유 셀. 정릉 3km: 기피 5 / 선호 394 / 수변 93.

## 결과 (results/gauge_ablation.md 전문)

| 판정 | 근거 |
|---|---|
| 도로 노브: **작동·단조** | 치매 기피셀 질량 0.042→0.018 (−58%), 선호셀 0.891→0.931 단조 증가 |
| 도로 노브: **적용범위 정확** | ID는 전 스윕에서 지표 완전 불변(코드 경로 자체가 없음) — 치매 한정 설계 검증 |
| env 노브: **전역 효과 미약** | 수변셀 질량 0.044→0.052(+0.8%p), seed 범위(0.04~0.073) 중첩 — 노이즈 구분 불가 |
| 안전성: **거리 캘리브레이션 불침** | dist_ratio 전 조건 0.3008 고정 — 노브가 Koester 거리 분포를 오염하지 않음 |
| 상식 지표: **전 그리드 통과** | 3×3 전 조합 시간 단조성 O, 1h dist_ratio 밴드(0.2~1.5) 내 |

## 권고

1. **두 노브 모두 기본 1.0 유지.** 효과 방향이 검증됐고 거리 캘리브레이션을 건드리지 않아
   켜둬도 안전하다. ablation 서사(끔↔강조 대비)는 0↔2로 시연.
2. 도로 노브의 전역 효과가 작은 것은 정릉 3km 도보 그래프에 간선 성격 셀이 5개뿐인
   구조적 천장 때문 — 노브 결함이 아니다. 간선이 많은 지역에서 재측정 여지.
3. env 노브의 국소 효과(PR #56 실측: 800m 픽스처 ±10%p)와 전역 무효과의 간극은
   사정거리(수변 100m) 국소 소비 구조에서 온다. **개인화 기여 증명은 노브 증폭이 아니라
   V2 per-person hit@거리 평가(제안서 P0)로 재는 것이 맞다.**

# P2-3 축소판 — 게이지 상수 민감도 (LLM 실호출 0회)

원래 P2-3(게이지 그리드서치)는 P2-2와 동일 사유로 재정의: 정답 좌표 부재로
최적화 목적함수를 만들 수 없다(순환논법). `sweep_gauge_sensitivity.py` 가
GaugeConfig 잠정값 3종(theta_mind·k_h1·theta_f)의 민감도만 판별했다.
마음 재해석은 무변경 fake 패치(발동 계측만, HTTP 0).

## ⚠ 2026-08-04 재측정 — `mind_fired` 수정 반영

`gauges.Gauges.mind_fired` 의 **순서 편향을 제거**해 이 실험을 다시 돌렸다.
종전 구현은 (귀소, 불안) 순으로 검사하고 먼저 걸리면 즉시 반환했는데, H 는
집떠난시간에 정비례해 자라므로 경과가 길수록 항상 H 가 먼저 걸렸고 **불안은 검사
기회조차 얻지 못했다.** 발동 판정 자체가 바뀌었으므로 07-31 수치는 그대로 쓸 수 없다.

읽는 법 세 가지.

1. **theta_f 가 완전 동일한 것이 이 재측정의 대조군이다.** 피로 게이지는 마음 발동과
   무관하므로 안 변하는 것이 맞고, 그래서 나머지 변화가 수정 때문임이 보증된다.
2. **발동 수는 거의 안 변했다(±6).** 순서 편향 제거는 발동 횟수가 아니라 **어느 게이지
   이름이 붙는가**를 바꿨다. 예상과 일치한다.
3. **coverage80 은 대체로 +1~3 늘었다.** 귀소 편중이 풀려 워커가 과거 거주지 한 곳으로
   덜 몰린 결과다. 다만 seed 변동(±3~7) 안이다.

**판정은 바뀌지 않는다** — 아래 표와 결론 그대로다.

## 결론

게이지 상수는 발동 빈도는 움직이나 **최종 POA 에는 전달되지 않는다** —
budget 상한 + 풀 표집 구조가 발동 수 요동을 흡수(P2-1 budget 스윕의
"실발동 6/10/2 요동에도 POA 불변"과 동일 그림). 그리드서치 종결 논리 이중화:
(1) 원리 — 목적함수 불가, (2) 실측 — 목적함수가 있어도 반응할 대상이 없음.

한계: fake 마음이라 발동→목적지 전환 경로의 효과는 미포함 — 그 경로는
P2-1 budget 스윕이 커버, 결론 동일.

⚠ 다만 **fake 마음의 한계가 08-04 에 실제로 드러났다.** 이 스크립트의 fake 는
`sanitize_mind({})` 로 무변경(혼란도·목적지·행동 전부 현행 유지)이라, 구조상 POA 를
움직일 수 없다. 따라서 "게이지 상수가 POA 에 전달되지 않는다"는 이 실험의 결론은
**게이지→발동 동역학까지만** 말하고, "마음이 POA 를 못 움직인다"로 확장해 읽으면
안 된다. 실 LLM(dem3)으로 채널을 켜고 잰 결과는 `experiments/alert_cells/` 에 있고,
거기서는 목적지 전환·행동 매핑이 알림 셀 수를 실제로 움직였다(4h 15.8 → 13.5).
