# 공개 설명 검토 기준 — 생성 결과를 읽기 전에 고정

이 개발 16개는 이미 기존 후보 분석에 사용했다. 정답을 새로 바꾸지 않으며 독립 평가로 취급하지 않는다. 아래 검토는 Codex의 입력 대조이며 독립 사람 평가가 아니다.

| 사례 | 행동과 함께 설명에 보존돼야 하는 정보 |
|---|---|
| D01-1 | 소음 회피보다 높은 피로의 휴식 우선. 소음 때문에 쉬는 것으로 원인 변경 금지 |
| D01-2 | 낮은 피로와 확인된 공원 소음 → 공원 회피 |
| D01-3 | 낮은 피로·소음 없음 확인 → 이동 유지 |
| D01-4 | 낮은 피로이나 소음 미확인 → 추가 정보. 조용함으로 변환 금지 |
| D02-1 | 일몰 확인 → B. 낮이라고 서술하지 않기 |
| D02-2 | 일몰 이후 B 도착 확인 → 대기 |
| D02-3 | 낮의 목적은 원문에 없음 → 개인 일과 추가 확인 |
| D02-4 | 19시지만 일몰 관측 미확인 → 일몰을 시간만으로 단정하지 않기 |
| D03-1 | 기다려 달라는 부탁과 이후 미관찰 → 실제 대기 성향 확정 불가 |
| D03-2 | 수락 답변과 이후 미관찰 → 실제 대기 성향 확정 불가 |
| D03-3 | 방향 상실 때 반복 관찰한 대기 → 대기 |
| D03-4 | 최근 목적지 없는 탐색이 과거 대기를 정정 → roam |
| D04-1 | 소음 확인·가족 부재 확인 → 시장 회피 |
| D04-2 | 소음 있지만 가족이 함께라는 예외 → 이동. 혼잡 부재로 설명 금지 |
| D04-3 | 소음 없음 확인 → 혼자여도 이동. 혼잡 여부는 미확인 |
| D04-4 | 소음 있으나 가족 동행 미확인 → 추가 확인. 가족 없음으로 변환 금지 |

평가자는 원문·현재 상태·출력 전체를 읽어 설명 일치/모순/근거 부족을 기록한다. 특정 단어 포함 여부만으로 정답을 매기지 않는다. 행동 일치와 설명 일치는 각각 기록하고 둘 다 맞아야 종합 성공으로 센다. 원문에 없는 환경·동행·목적지·시점을 사실로 만드는 경우를 별도 기록한다.
