# P2-2 실험A — EXAONE prior 반경 μ 보정폭 폭주 임계

실험 상세 설계안(0724 분업) [대흠] 몫 P2-2 중 **LLM 없이 지금 가능한 부분**.
`guardrail.RADIUS_MU_ADJUST`(상/중/하 → μ±0.4, 중앙값 ×1.49/×0.67)의 상한 근거를
실측으로 뒷받침한다. 등급 매핑 자체의 최적화(실험 B)는 정답 골드셋이 필요해
EXAONE 서빙(P2-1) 이후.

## 방법

μ 보정폭 dμ ∈ ±0.8 스윕 × statistical 300워커 × seed {42,43,44} 평균, 경과 3h,
정릉 3km 캐시 도로망. 지표 = dist_ratio(상식 밴드 0.2~1.5) · coverage80(알림 타겟
크기) · P1-3 동적 로딩 반경(부하 상호작용).

## 결과 (results/mu_adjust.md 전문)

| 판정 | 근거 |
|---|---|
| **+방향 폭주는 상한이 흡수** | dμ ≥ -0.2 전 구간 dist_ratio 0.521 포화 — 그래프 경계·물리 상한(v_max×t)이 원거리 질량을 자름. 가드레일 ±0.4 + 로딩 상한 6km가 이중 안전판으로 실동작 |
| **실질 위험은 −방향(과잉 확신)** | coverage80 기준 14셀(dμ=0) → 13.3(−0.4, −5%) → 10(−0.6) → 8.3(−0.8, **−41%**) — 알림 타겟이 급격히 좁아져 오확신 위험. 축소 가속은 −0.6부터 |
| **±0.4 유지** | −방향 가속 구간 직전에서 멈추고, +방향은 ×1.49로 로딩 반경 상호작용(5→6km)까지 감안해 안전 |
| 전 구간 밴드 내 | dμ ±0.8에서도 dist_ratio 밴드(0.2~1.5) 유지 — 폭주의 실체는 거리비가 아니라 **타겟 셀 수(coverage)의 붕괴/팽창**임을 확인 |

## 함의

- "폭주 임계"의 올바른 감시 지표는 dist_ratio가 아니라 **coverage80** — 평가
  하네스(P2-2 본체)에서 알림 전략 비교 시 이 지표를 쓸 것.
- P1-3 동적 로딩 반경이 μ 보정과 상호작용(dμ=+0.4 → 6km 로딩)함을 실측 —
  가드레일이 로딩 부하의 상한도 겸한다.
