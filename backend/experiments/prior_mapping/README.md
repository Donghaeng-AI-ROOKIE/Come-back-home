# P2-2 — EXAONE prior 매핑: 실험A(μ 폭주 임계) + 실험B(상수 민감도)

실험 상세 설계안(0724 분업) [대흠] 몫 P2-2 중 **LLM 없이 지금 가능한 부분**.
`guardrail.RADIUS_MU_ADJUST`(상/중/하 → μ±0.4, 중앙값 ×1.49/×0.67)의 상한 근거를
실측으로 뒷받침한다. 등급 매핑 자체의 최적화(실험 B)는 정답 골드셋이 필요해
EXAONE 서빙(P2-1) 이후.

## 방법

μ 보정폭 dμ ∈ ±0.8 스윕 × statistical 300워커 × seed {42,43,44} 평균, 경과 3h,
정릉 3km 캐시 도로망. 지표 = dist_ratio(상식 밴드 0.2~1.5) · coverage80(알림 타겟
크기) · P1-3 동적 로딩 반경(부하 상호작용).

## 결과 (results/mu_adjust.md 전문)

| 판정 | 근거 |
|---|---|
| **+방향 폭주는 상한이 흡수** | dμ ≥ -0.2 전 구간 dist_ratio 0.521 포화 — 그래프 경계·물리 상한(v_max×t)이 원거리 질량을 자름. 가드레일 ±0.4 + 로딩 상한 6km가 이중 안전판으로 실동작 |
| **실질 위험은 −방향(과잉 확신)** | coverage80 기준 14셀(dμ=0) → 13.3(−0.4, −5%) → 10(−0.6) → 8.3(−0.8, **−41%**) — 알림 타겟이 급격히 좁아져 오확신 위험. 축소 가속은 −0.6부터 |
| **±0.4 유지** | −방향 가속 구간 직전에서 멈추고, +방향은 ×1.49로 로딩 반경 상호작용(5→6km)까지 감안해 안전 |
| 전 구간 밴드 내 | dμ ±0.8에서도 dist_ratio 밴드(0.2~1.5) 유지 — 폭주의 실체는 거리비가 아니라 **타겟 셀 수(coverage)의 붕괴/팽창**임을 확인 |

## 함의

- "폭주 임계"의 올바른 감시 지표는 dist_ratio가 아니라 **coverage80** — 평가
  하네스(P2-2 본체)에서 알림 전략 비교 시 이 지표를 쓸 것.
- P1-3 동적 로딩 반경이 μ 보정과 상호작용(dμ=+0.4 → 6km 로딩)함을 실측 —
  가드레일이 로딩 부하의 상한도 겸한다.

## 재현

```bash
cd backend
.venv/bin/python experiments/prior_mapping/run_mu_adjust.py
```

# 실험B — 상수 민감도 점검 (2026-07-31, LLM 0회)

`sweep_sensitivity.py` — EPSILON / LEVEL_WEIGHTS / ATTRACTION_CAP 을 독립 스윙,
해석층(가드레일 통과 후 분포)과 실측층(MC POA, seed 3개 평균)의 이중 판정.
정답 좌표가 없으므로 최적값 탐색이 아니라 "살아있는 손잡이인가"만 판별
(순환논법 회피 — 최적화는 불가함을 명시).

## 판정 (results/sensitivity.md 전문)

| 상수 | 판정 | 근거 |
|---|---|---|
| `EPSILON` 0.02 | **살아있음 — 현행 유지** | pull 격차 0.566(ε.005)→0.329(ε.1) 단조 감소, seed 변동(≤0.06)의 4~9배. ε=0.02는 P(seek) 0.909로 극단 개인화를 거의 보존하면서 다양성 floor 확보 — 스윕 구간의 균형점 |
| `LEVEL_WEIGHTS` 3:2:1 | **POA 층에서 무효 — 튜닝 대상 아님(YAGNI)** | 배분(해석층)은 0.5→0.6으로 움직이나 POA 지표는 d_top 0.609→0.571(이동 0.038) vs seed 변동 0.013~0.058 — 노이즈에 묻힘. 5:2:1이면 w_top이 cap(0.6)에 닿아 그 이상은 cap이 흡수 |
| `ATTRACTION_CAP` 0.6 | **살아있음 — 현행 유지, 하한 근거 신규 발견** | 0.4~0.6 구간에서 d_top 0.64→0.557(seed 변동의 2~3배). **cap=0.4에서 순위 역전 실측**: 초과분 재분배로 2등(시장 0.462)이 캡된 1등(옛집 0.4)을 추월 — cap을 낮추면 평탄화가 아니라 근거 순위 파괴. 0.7+는 이 시나리오 비캡 최대(0.675) 아래라 불활성 |

## 함의

- 튜닝 여지가 있는 손잡이는 EPSILON·CAP 2개뿐이고, 둘 다 현행값이 스윕 구간에서
  방어 가능한 위치다. LEVEL_WEIGHTS 미세조정 논의는 근거 없음(POA 무효).
- CAP 의 실질 제약: **순위 보존 하한**(이 구성 기준 >0.46)과 독식 방지 상한 사이 —
  0.6은 그 안. 골드셋(서영 P2-1)이 생겨도 이 구조적 제약은 유효.
