# 온보딩 → 마음 판단 → KINTEX 보행 → 시간별 지도 검증

## 목적
온보딩된 개인의 근거와 현재 관측이 행동 결정에 보존되고, 같은 명령이 실제 경로·휴식·회피와 시간별 위치 분포로 이어지는지 검사한다. 실제 실종 경로가 없어 발견 정확도·임상 타당성은 판정하지 않는다.

## 고정 범위
- 현재 develop을 마음모델 PR #262 브랜치에 병합한 별도 로컬 브랜치 사용. 운영 변경·머지·배포 없음.
- 저장된 실제 K 개인 해석 8개와 보호자 합성 원문 재사용. 사전등록 모델 신규 호출 없음.
- 새 마음모델 K-EXAONE 실호출 최대 96회: 8명 × 연속 세션 최대 12회. 실패·빈 응답 포함, 자동 재시도 없음. 출력 호출당 최대 12,000토큰(총 1,152,000), 입력 UTF-8 요청 32,768바이트 사전 상한(토큰은 공급자 usage로 기록). 동시성 최대 2.
- 이전 사용자의 이 세션 반복 실행·재승인 생략 지시에 따라 준비. 실제 호출 전 원장 기록, 범위 초과 금지.
- 단가·실청구액·지원 차수 미확인(null). GPU 학습·SAR·Mi:dm·임베딩·지도 신규 호출 0회.
- KINTEX 기존 OSMnx 캐시만 사용. 합성 장소 재배치와 소음·혼잡 관측은 명시적 테스트 입력이며 실제 KINTEX 환경이라고 표현하지 않음.
- 새 요청은 이동 결과에 따라 생성. 저장 응답은 같은 요청에 한해서만 재현하며 변경된 시각·피로·목표·관측에 재사용하지 않음.

## 단계
1. 기존 서비스 경로와 연구 실행기 역할 비교. 보행 시간·휴식·대기 계측 및 유보 시 가짜 시간 진행 방지.
2. 같은 개인·같은 seed를 1/2/4/6시간 분할 실행과 한 번 실행으로 비교. 관측 변화·회피·휴식 재개·지도 질량 보존 검사.
3. 실제 앞단 저장 해석이 현재 fingerprint 검증을 통과하는지, 개인 원문과 조건이 마음 요청에 들어가는지 검사.
4. 실제 모델 판단을 매번 갱신된 엔진 상태에서 받아 연속 실행. 유보·형식 실패·예산 소진이면 미해결로 기록하고 이후 시간 지도에 정지 인물로 넣지 않음.
5. 명령 전달률과 개인 의미 정확도를 분리. 성공한 일부만 분모에서 남기지 않고 원래 워커 수에 대한 미해결 질량을 함께 출력.

## 판정 원칙
코드 회귀 통과는 실제 환자 행동 정확도가 아니다. 고정 응답 시뮬레이션은 엔진 검사이며 실모델 결과와 별도 집계. 통계의 발견 이탈거리를 이동 시간으로 오인하지 않고, 기존 수치 기준선 교체 정당성을 별도로 남긴다. 현실에 필요한 조건이 입력에 없으면 성공으로 강제하지 않는다.
