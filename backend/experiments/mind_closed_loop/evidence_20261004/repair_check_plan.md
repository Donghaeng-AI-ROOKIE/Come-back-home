# 관측 기록 보존 수정의 실호출 확인

기존 총 96회·개인별 12회 범위 중 H_wait_1의 남은 1회만 사용한다. 새 데이터나 새 원문은 사용하지 않는다. 이전 진단이 종료된 275분 시점의 모든 입력은 그대로 두고, 최근 행동 8개에 밀려 빠진 원래 관측만 원래 시각으로 복원한다. 비교 전후 다른 입력 필드가 일치하는지 코드로 확인한다.

- 대상: 같은 K-EXAONE Thinking, 최대 1회, 출력 12,000토큰, 자동 재시도 없음.
- 모델 원문·토큰·오류는 동일 공용 원장과 로컬 공개 응답 파일에 기록.
- 단가·실청구액·지원 차수 미확인. 신규 GPU·SAR·Mi:dm·지도·RAG 검색 없음.
- 다시 6시간을 검증하는 실험이 아님. 해당 장면에서 새 응답을 받아 1분 실행하는 국소 수정 확인.
- 오래된 관측을 현재 관측으로 바꾸지 않음. 해석 시 관측의 나이를 보존하며, 실제 환경에서 그 상태가 계속 유지됐는지는 별도 미확인.
