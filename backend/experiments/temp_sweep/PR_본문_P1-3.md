## 리뷰 포인트

**① 온도를 정확도가 아니라 결정성으로 골랐습니다**

측정하려던 효과가 측정 오차보다 작았습니다. 같은 설정을 그대로 두 번 돌린 대조군에서 수집률이 61% → 67%, 축이 47% → 54% 로 움직였는데, 온도 0.0 ↔ 0.4 의 차이는 2%p 였습니다. **재실행 노이즈가 온도 효과의 3배**입니다.

반면 결정성은 또렷했습니다 — 같은 입력 5회 완전일치가 `0.0 = 100% / 0.2 = 87% / 0.4 = 27%`. 추출은 정확도를 잃지 않고 결정성을 얻습니다.

> 앞으로 이 하네스로 설정 간 차이를 읽을 때는 **대조군 재실행을 반드시 같이** 돌려야 합니다.

**② ⚠️ Mini 가 시민이 말하지 않은 시각을 지어냅니다 (이 PR 에서 안 고침)**

온도 문제가 아니라 T=0.0 에서 반복 재현되는 결정론적 동작입니다. "편의점 앞에 계셨어요" → `time_text="30분 전"`. 골드셋 전수로 **시각 미언급 26건 중 20건(77%)** 에서 시각을 만들어냅니다.

영향: 시각 되묻기 게이트가 영구히 죽고, 시공간 개연성(신뢰도 p 가중 0.40)이 오염되며, 층2 재예측의 출발 시각이 틀립니다.

운영 코드 변경이라 온도 확정과 섞으면 나중에 성능 변화의 원인을 못 가려서 **후속 PR 로 뺐습니다.** 처방은 프롬프트 강화가 아니라 `time_text` 원문 대조 강등 가드입니다(축 채점의 "원문 인용 강제 + 코드 검증"과 같은 구조).

**③ 반증된 가설 하나**

"작문 온도를 낮추면 질문이 반복된다"는 틀렸습니다. 0.0 / 0.2 / 0.4 에서 중복질문이 4.75 / 4.75 / 4.79 로 동일했습니다. 중복 4.8건의 원인은 온도가 아니라 재질문 로직입니다. 자연스러움은 이 하네스로 못 재므로 **근거 없이 값을 바꾸지 않고** 작문 온도는 유지했습니다.

**④ 4파전 결과가 교차 재현됐습니다**

Mini 재측정(서버 vLLM, T=0.0)이 7/29 4파전(Colab T4 + HF transformers)과 균형 75.0 vs 76.4 · 필드추출 86.2 vs 86.1 · 상 89 vs 89 · 중 53 vs 53 으로 겹칩니다. 4파전 수치의 대외 인용 근거이고, 동시에 **KT 발급 엔드포인트가 HF Mini 와 다른 모델**이라는 확증입니다(같은 조건에서 균형 49% 대 75%).
