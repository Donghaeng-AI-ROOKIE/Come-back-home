## 해석 한계

- 합성 인물·합성 정답이다. 정답과 입력이 작성자의 행동 가정을 공유한다. 실제 환자의 행동 정확도, 실제 발견율·구조 시간, 시민 반응을 입증하지 않는다. 사례 작성·검토도 AI가 했고 사람 전문가 검토는 없다.
- 새 36명은 이전 실험(E01–E40)과 같은 생성기·문장 틀·네 유형을 쓴다. main 개발에 쓰인 E세트와 인물은 다르지만 유형은 겹친다. 정답 파일이 공유되므로 이 세트를 이후 개발의 보지 않은 평가 세트로 다시 쓰면 안 된다.
- B는 개인 정책이 없어 main이 기존 보행을 고른다. 따라서 D−B는 "같은 앱에서 보호자 답변을 넣었을 때의 효과"이며, 해석 효과와 보행 엔진 차이가 함께 들어 있다.
- 운영 결함(별도 보고): UTC 서버에서 보행 엔진 시계가 9시간 늦다. 이번 실행은 운영과 같은 조건으로 재현했다.
- 알림 면적은 실제 발송 수가 아니며 실제 푸시는 보내지 않았다. 본선 코드·기존 경보 행정구역 근사와의 비교는 이번에 다시 하지 않았다(EFFICIENCY_KINTEX_v1 참조).
