# goal 채널 라벨 의존성 규명 — 교차·교체·분해 프로브 (2026-08-07)

`probe_label_overfit.py` + `probe_label_swap.py` 산출. 실 EXAONE 실호출
(맥미니 게이트웨이, `exaone-mind-dem3`, 총 약 400콜).

## 배경 — 왜 시작했나

페르소나 감도 프로브(08-06)에서 4개 페르소나 중 데모 라벨을 쓴 A만 goal 을
골랐다(12/15 vs 0/15×3). "튜닝 모델이 데모 라벨을 외웠다"는 가설로 조사를 시작했다.

## 1차: 진술 × 라벨 교차 (모델 3종 × 4셀 × 15콜)

goal 선택률:

| 모델 | 데모 라벨 | 비데모 라벨 |
|---|---|---|
| exaone-base (튜닝 전) | 1, 1 /15 | 0, 1 /15 |
| exaone-mind-dem3 (운영) | **11, 15** /15 | 1, 0 /15 |
| exaone-mind-v5 (구) | **9, 15** /15 | 0, 0 /15 |

- 진술(보호자 노트)을 바꿔도 goal 선택은 변하지 않는다 — **라벨이 결정**.
- 원본은 어떤 라벨에도 goal 을 안 고른다 → 고르는 **정책 자체가 튜닝 산물**.

## 3차: 라벨 1개 교체 + 통제 + 분해 (10셀 × 15콜, 진술·게이지·가중치 고정)

진술 = "매일 아침 시장에 가서 사람들과 이야기한다" (시장 라벨이 진술 정합 목표).

| 시장 라벨 (파트너 고정) | goal 선택 | 비고 |
|---|---|---|
| **정릉시장** | **14~15/15** | 파트너가 옛집이든 경로당이든 동일 |
| **정릉 시장** (공백 삽입) | **15/15** | 형태 변형에도 유지 |
| **정릉슈퍼** (가상, 시장 아님) | **12/15** | ⚠ 진술은 "시장"인데 슈퍼를 고름 |
| 재래시장 (학습 어휘 그대로) | 4/15 | |
| 남대문시장 (전국구 유명) | 3/15 | 유명세 가설 기각 |
| 청량리 경동시장 (골드셋 어휘) | 0~1/15 | |
| 망원시장 | 0/15 | 실존·유명(관광지)인데도 0 |
| 성북시장 (인접 지명) | 0/15 | 접두 특이성의 대조군 |

## 판정

1. **원인 = "정릉" 접두 두 글자.** 시장 여부·실존 여부·유명세·학습 어휘 여부와
   전부 무관하다. 진술 정합까지 깨면서(정릉슈퍼) 고른다.
2. 그 접두는 어느 튜닝 코퍼스에도 없다(정릉 0 / 성북 0 / 망원 0 전 파일). 그리고
   서로 다른 코퍼스로 튜닝된 v5·dem3 가 같은 반응을 보인다. 남는 설명은
   **베이스 모델 사전지식과 튜닝된 goal 정책의 상호작용** — 튜닝은 "근거가 충분하면
   골라라"는 정책을 열었고, 어떤 문자열이 그 문턱을 넘는지는 베이스가 정한다.
   왜 하필 정릉인지는 베이스 사전학습 내부라 여기서 더 분해할 수 없다.
3. **일반 사용자 관점의 실효 결론**: 임의 라벨의 goal 선택률은 0~4/15(≈ 진술
   무관)다. 학습 정답의 51.2%가 goal=null 이라 null 규율이 지배한다 — 이것
   자체는 의도된 학습(지식 침범 해독)의 결과다.

## 실무 함의

- **시연 착시 주의.** 데모 케이스(정릉동·정릉시장)는 우연히 이상 반응 구간에
  놓여 있어, 시연에서 보이는 goal 개인화는 실사용자가 받는 동작이 아니다.
  제안서·발표에서 goal 채널을 개인화 근거로 인용하지 않는다.
- **개인화의 실증 근거는 behavior 축.** 교차 프로브에서 진술을 바꾸면 behavior
  분포는 실제로 갈렸다(옛집지향 진술 → 끌림점 접근 14/15, 시장단골 진술 →
  귀소 8/배회 6). goal 이 아니라 이쪽을 인용한다.
- **재튜닝 원칙에 추가**: 현행 코퍼스의 goal 라벨은 전부 일반 명사라
  "고유명사 라벨을 읽고 고르는" 일반화가 학습된 적이 없다. 재튜닝 시
  (a) 라벨 풀에 실존형 고유명사(지명+시설 조합)를 다양하게 포함하고
  (b) 학습에 안 쓴 고유명사 라벨로 goal 선택 홀드아웃 평가를 만든다.
