# 마음모델 배포 검증 결과

검증일: 2026-09-30 · 대상: K-EXAONE API `separate_motion_and_goal` 고정 후보

## 판정

**현재 후보를 운영 마음모델로 교체할 수 없다.** 176회 실호출을 완료했으며, 보호자 원문에 없는 조건을 추가하거나 확인된 관측을 반대로 읽는 오류가 재현됐다. 실행 가능한 JSON을 만드는 것과 온보딩된 그 사람의 행동을 보존하는 것은 서로 다른 검사다. 이번에는 후자를 배포 판정에 포함했다.

새로 준비한 2,160개 학습 행으로 LoRA를 재학습한 결과가 아니다. **이번 신규 학습은 0회**이며 현재 K 프롬프트·입력·출력 계약을 고정해 평가했다. 운영 모델과 설정은 변경하지 않았다. 이 결과를 기존 SAR-EXAONE 마음모델의 점수나 K의 우월성으로 해석할 수 없다.

## 무엇을 얼마나 검사했나

개인 대비에서 관측이 모두 알려진 상황은 38/40, 관련 관측에 미확인이 있는 상황은 34/40이었다. 자연어 검사에서 관계없는 미확인 관측을 추가한 전후에 같은 명령을 고른 것은 15/20쌍, 양쪽 모두 정답인 것은 15/20쌍이었다.

16건의 설명 평가는 **저장된 앞단 해석을 받은 마음모델의 새 응답**에 대한 검사다. 온보딩 해석 모델 자체를 새로 호출해 채점한 것이 아니다. Codex가 원문·입력·최종 응답을 대조한 비맹검 검토이며, 독립 보호자·돌봄 경험자·임상 전문가의 평가가 아니다. 나머지 160건은 명령 비교 및 오류 사례 검토이며 전체 설명의 의미 정확도 점수는 산출하지 않았다. 모든 프로필은 합성이고 실제 치매 환자의 경로 정확도를 측정하지 않았다. 같은 프로필의 조건 변형을 독립 환자 수로 세지 않는다.

각 상황은 1회 호출했다. 관련 없는 관측 추가 전후의 차이에는 확률적 출력 변동도 섞일 수 있으므로 추가 문구가 차이를 일으켰다고 단정하지 않는다. 이 검사는 치매 심리·행동 모사의 충분성을 증명하는 검사가 아니라, 알려진 개인 정보를 왜곡하지 않는지 보는 최소 기능 검사다. 이번 결과만으로 도메인 지식이나 RAG의 추가 효과도 판정하지 않는다.

## 평가 자료 자체에서 발견한 문제

개인 대비 자료 중 두 프로필은 “두 조건일 때만 계속 이동”이라고 한 뒤 “조건이 아니어도 계속 이동”이라고 설명해 문장이 모호했다. 해당 프로필 4상황은 맞힌 사례까지 모두 제외한 보조 집계를 함께 남겼다. 제외 후 **70/76 (92.1%)**로, 사전에 정한 95%에도 미달한다. 원래 동결된 점수와 정답은 수정하지 않았다.

같은 문구 문제가 학습 분할의 3프로필·81행에도 있어 신규 학습 전 수정해야 한다. 2,160개 행은 다양한 독립 실환자 사례가 아니라 합성 상태와 문장 증강을 포함한 규모다. 이번 평가 실패를 보고 수정하면 이 평가 자료는 이후 회귀 검사에 사용할 수 있지만, 새로운 후보의 최종 미사용 평가 자료라고 다시 주장할 수 없다.

## 시뮬레이션 연결과 시간별 갱신은 어디까지 확인했나

```mermaid
flowchart LR
    A[보호자 원문과 저장된 K 개인 해석] --> B[현재 관측·목표·상태]
    B --> C[K 마음모델 실호출]
    C --> D[명령·근거·개인 특성 보존 검사]
    D --> E[KINTEX 실행기 1회 소비 검사]
    E -. 남은 검증 .-> F[상태 변화와 재호출·응답 재사용]
    F -. 남은 검증 .-> G[1·2·4·6시간 확률지도]
```

실제 K 응답 16개는 같은 사실 조건에서 실행기에 한 번씩 전달됐다. 휴식·대기는 첫 1분의 이동이 멈추고, 목적지 변경·유지는 명령대로 반영됐다. 잘못 선택한 명령도 그대로 실행되므로 **16/16 전달 성공이 16/16 행동 정확도를 뜻하지 않는다.** 검사 좌표와 실행기 페르소나는 명령 전달 확인을 위한 합성 배치이며 원래 개인 전체의 동역학 검증이 아니다.

`defer`는 모델의 판단 유보다. 치매 어르신이 실제로 멈춰 기다린다는 뜻이 아니다. 이번 진단에서는 유보 4건을 종료했으므로, 운영에서 불확실성을 어떻게 보존하고 보행·분포를 이어 갈지는 별도 구현·검증이 필요하다.

KINTEX OSMnx 도로망에서 명령 전달은 확인했지만 이번 캐시에 환경별 거리 정보가 없어 시장 회피가 실제로 시장에서 멀어지는 방향인지 검증하지 못했다. 운영 코드에는 환경 레이어를 붙이는 구현이 존재한다. 이 캐시의 자료 미부착을 제품 전체에 환경 구현이 없다는 뜻으로 확대하지 않는다. OSM 장소 분류만으로 실시간 소음·혼잡을 알 수 있는 것도 아니다.

실모델을 연결한 1·2·4·6시간 연속 행동·확률지도 검사는 아직 수행하지 않았다. 운영의 호출 예산 5회와 소진 후 응답 재사용이 새로운 개인 조건·환경·피로 상태를 보존하는지도 이 후보에서 검증되지 않았다. 코드 검사에 포함된 고정 응답의 시간 연속성 검사를 이 실모델 검증으로 대신하지 않았다.

## 배포 기준 적용

실행 전에 정한 확대 조건은 형식 실패·중대 의미 오류 없음, 개인 대비 명령·서로 다른 개인 쌍·자연어 명령 각각 95% 이상, 앞단 허용 명령 전부 충족이었다. 95%는 이 프로젝트의 합성 검사 진행 기준이며 임상적으로 정립된 배포 기준이나 실제 경로 정확도 보증이 아니다.

현재는 이 조건을 통과하지 못해 **나머지 280회는 실행하지 않았다.** 176회는 계획한 진단을 끝까지 완료했으며, 360개 합성 평가 전체를 완료하거나 통과한 것으로 계산하지 않았다. 그 이상의 배포 조건인 운영 연결·실시간 상태 변화·유보·응답 재사용·시간별 지도 검증도 남아 있다.

맥미니 운영 컨테이너를 읽기 전용으로 확인한 결과, 현재는 `mind_contract=v2`, `mind_call_budget=5`인 기존 `reinterpret_mind` 경로다. 이번 후보와 실험용 `WalkingSession`은 운영 경로에 연결되어 있지 않다. 이번 검증에서 운영 교체·서비스 재시작은 하지 않았다.

## 다음 개선의 순서

1. **상태와 근거를 분리해 전달·검증한다.** 실종 후 경과 시간, 실제 이동 시간, 연속 이동 시간, 마지막 휴식과 재개, 현재 목표, 현재 이동 방식을 각각 보존한다. 원문·과거 습관·현재 관측·모델 추정을 섞지 않는다.
2. **개인 의미 해석의 실패를 고친다.** 원문에 없는 강도 기준, 관측의 참·거짓·미확인 반전, 목표 기억 때문에 회피가 사라지는 문제를 개발 회귀 사례로 고정한다. 단어→행동 매핑으로 대신하지 않고, 자연어 의미 해석 결과가 어느 원문과 관측에 기대는지 검사한다.
3. **학습·평가 자료를 정리한 뒤 후보를 비교한다.** 모호한 81개 학습 행을 새 버전에서 수정하고, 독립 개인·조건 조합·대화 형식·시간 이력을 늘린다. LoRA를 학습한다면 EXAONE 기반 후보를 K 후보와 같은 미사용 평가에서 비교한다. K-EXAONE API 자체를 LoRA 학습한 것으로 기록하지 않는다.
4. **마음모델 통과 후 실제 엔진을 연결한다.** 유보가 환자의 정지로 변하지 않도록 분포 처리 정책을 정하고, 호출 예산 소진 시 현재 조건과 맞지 않는 답변 재사용을 막는다. KINTEX 환경 거리를 부착하고 실모델 응답이 회피 방향·휴식·재출발에 영향을 주는지 확인한다.
5. **마지막에 시간별 지도를 검증한다.** 동일한 개인의 목표·피로·휴식·환경 이력이 이어진 상태에서 1·2·4·6시간을 비교한다. 단순히 시간이 다르니 경로가 달라졌다는 것보다, 알려진 개인 조건과 상태 변화 때문에 행동과 분포가 달라지는지를 평가한다.
