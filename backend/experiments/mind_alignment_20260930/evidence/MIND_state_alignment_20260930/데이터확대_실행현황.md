# 마음모델 데이터 확대: 수량보다 개인차와 독립 평가

작성: 2026-09-30. 기존의 16/16은 작은 진단 묶음의 결과이며, 도입 당위성을 단독으로 뒷받침하지 않는다. 반복 호출·문장 증강·실제 사람의 수를 따로 보고한다.

## 현재 만든 자료

| 분할 | 개인 설정 | 서로 묶인 대비 계열 | 상황 원형 | 표현 증강 포함 행 수 |
|---|---:|---:|---:|---:|
| 학습 후보 |80|40|720|2,160|
| 개발 |20|10|180|180|
| 별도 합성 평가 |40|20|360|360|
| 별도 자연어 스트레스 |20|20|80|80|

모두 AI가 작성한 합성 자료다. 실제 환자·새 보호자 면담·임상 검토는 0건이다. ‘2,160명의 치매 환자 행동을 학습’했다고 표현할 수 없다. 학습도 아직 실행하지 않았다. 현재 학습 후보는 `personal_contrasts_v5/`다. v4의 개인 원문·정답·행 수를 그대로 두고, 학습 피로 수치와 피로 발언의 고정 동반 관계만 제거했다. 개발·평가는 v3·v4와 바이트 단위로 같다.

자연어 스트레스는 `natural_stress_v1/`에 20개 서사 × 4개 장면으로 별도 보존했다. 부탁·약속·다른 사람의 이야기·과거 직업·정정을 포함하며 학습 원문과 정확히 같은 문장은 없다. AI가 작성한 합성 보호자 발화이므로 실제 보호자 면담 20건으로 세지 않는다. 명령·출처와 원문 중복 검사는 했지만 모델 실호출과 독립 검토는 아직 하지 않았다.

두 인물은 **현재 관측이 완전히 같고 보호자 원문만 다르다.** 예를 들어 같은 피로 발언에 한 사람은 앉고 다른 사람은 계속 걷는 설정이다. 개인 반응을 읽지 않고 상황만 보는 모델은 이 자료의 모든 정답을 맞힐 수 없다. 그 대비쌍, 시간·상황 변형, 표현 증강은 모두 같은 분할에 묶었다.

각 인물은 두 관측의 참·거짓·미확인 9가지 조합을 갖는다. 단일 조건, AND, OR, 예외, 우선순위, 보호자 정정, 최신 관측을 다룬다. 학습에는 현재 이동 유지·휴식·대기·목적지 변경·목표 없는 보행·환경 회피·판단 유보가 들어 있다.

원형 720개에 두 가지 표현을 더해 1,440개를 추가했다. 질문과 답변, 부정, 예외와 설명 순서를 바꾸되 정답·관측·개인 설정은 유지한다. 이 증강은 고정 문법과 표현 목록을 사용하므로 실제 보호자의 자유로운 대화 다양성을 모두 확보한 것은 아니다.

## 자료를 만드는 중에 고친 점

첫 초안 1,920개는 ‘소음→회피’, ‘피로→휴식’ 대응이 고정돼 있었다. 수량이 늘어도 개인차를 배우기 어려워 학습에 사용하지 않았다. 다음 초안은 분할별 행동 종류가 빠지는 문제가 있어 선행 관측 종류를 균형 있게 배치했다. 수정본은 분할 사이 원문·개인·대비 계열 중복, 관측 경로와 값, 명령·출처 계약 검사를 통과했다. 검토에서 탈락한 버전은 삭제하거나 성공 자료에 합산하지 않았다.

기존 96개 자료도 무조건 합치지 않는다. 길을 잃었다는 관측과 스스로 길을 잃었다고 말한 관측, 일반 동행과 가족 동행의 차이를 다시 확인해야 한다. 모호한 정답을 대량 복제하면 성능이 오히려 나빠질 수 있다.

## 행 수로 해결되지 않는 학습 범위

학습 2,160행 전부의 직전 행동은 `seek`, 경과 시간은 60분이다. 저장된 앞단 K 개인 해석과 연구 발췌는 들어 있지 않다. 따라서 이 자료의 정확한 용도는 **개인 조건과 현재 관측을 연결하는 해석 학습**이다. 휴식 후 재개, 회피 유지·해제, 시간에 따른 내부 상태 변화, 실제 앞단 해석 인수까지 완성한 전체 마음모델 학습 자료라고 부르면 안 된다.

v4에서는 피로 발언 true/false/null에 엔진 피로 수치 0.9/0.1/0.5가 고정적으로 따라오는 문제가 있었다. v5는 같은 개인 대비쌍·표현 변형에 같은 수치를 주되, 장면 ID의 해시로 피로 수치를 분산시켜 각 발언 관측값에 낮음·중간·높음 수치가 모두 나오게 했다. 개인 원문, 명시적 관측과 정답은 바꾸지 않았다. 이 수치 조작은 임상적으로 보정된 피로 모델이 아니라, 수치 하나만 보고 발언을 추정하지 못하도록 만든 학습용 음성 대조 조건이다.

다음 학습 묶음에는 위 해석 자료와 별개로, 직전 행동·휴식 종료 여부·목표 기억·관측 최신성이 바뀌는 연속 장면을 보강해야 한다. 이미 보존한 실제 앞단 K 출력 8개 합성 프로필·16개 상황은 학습으로 옮기지 않고 연결 평가로 유지한다. 독립 환자 8명이라고 표현하지 않는다.

## 연구 근거의 쓰임

소리 환경에 대한 반응을 다룬 요양시설 관찰 연구는 개인·현재 상태·시간·친숙함에 따라 반응이 달라질 수 있음을 보고한다. 이는 개인 대비와 맥락 평가를 설계한 배경이며, 우리가 만든 각 행동 정답의 직접 실측 근거는 아니다. [Talebzadeh 외, 2023](https://pmc.ncbi.nlm.nih.gov/articles/PMC10002302/)

해당 연구는 기존 프로젝트에서 이미 참고한 자료이고 이번에 본문을 재확인했다. 신규 논문이나 신규 환자 확보로 중복 계산하지 않는다. 논문 참가자를 우리 모델 검토자로 세지 않는다. 다른 두 기존 출처는 이번 직접 열람에서 본문을 받지 못해 새로 검증한 사실을 추가하지 않았다.

## 재학습 비교 방법

우선 현재 입력·명령 계약에서 오류를 고친 뒤 같은 계약으로 학습 파일을 내보낸다. EXAONE 3.5 7.8B Instruct의 LoRA를 학습하며 K-EXAONE API 자체를 튜닝하지 않는다.

첫 학습 비교는 **원형 720개와 표현 증강 포함 2,160개**를 같은 초기 어댑터·토큰 예산·개발 자료에서 비교한다. 자료가 세 배일 때 같은 epoch는 계산량도 달라지므로 ‘같은 계산량에서의 증강 효과’와 ‘더 학습한 효과’를 구분한다. 같은 계산량 비교는 토큰 수를 기준으로 맞추고, epoch별 체크포인트 결과도 별도로 기록한다. 필요 시 fresh/warm 시작점 비교를 뒤따른다. 이 순서로 바꾸는 이유는 한 번에 데이터·초기 가중치·학습량을 모두 바꾸면 개선 원인을 알 수 없기 때문이다.

개발 180개로 후보를 선택하고, 별도 평가 360개는 후보와 판정 기준을 고정한 뒤 사용한다. 실제 앞단 K가 만든 저장 해석을 받는 별도 연결 평가도 유지한다. 원문만 있는 합성 자료를 잘 푼 것으로 온보딩 연결이 완료됐다고 판단하지 않는다.

GPU 실행 전에는 자료의 의미 검토, tokenizer로 입력·정답 잘림 검사, 서버 가용성·메모리·라이브러리·모델/어댑터 해시, 실행 시간·생성량 상한을 기록한다. 현재 운영 서비스와 다른 사람의 작업을 무단 중단하지 않는다. 사용자의 계속 진행 지시에 따라 같은 실험의 승인 질문은 반복하지 않는다.

## 최종적으로 보고할 것

전체 행동 정답률, 개인 대비쌍의 양쪽 동시 정답률, 조건별/행동별 성능, 근거 없는 사실·목적지 생성, 필요한 유보와 불필요한 유보, 의미 보존 표현의 일관성, 반복 안정성을 분리한다. ‘continue만 고르는 기준선’과 개인 원문을 보지 않는 기준선도 함께 표시해 쉬운 답에 편중된 성과를 구별한다.

그다음 통과한 **실제 모델 응답**을 KINTEX 보행 코드에 연결해 휴식·대기·재개·회피·목표 변경과 1·2·4·6시간 상태를 추적한다. 고정 명령으로 엔진 코드만 통과한 결과는 마음모델 정확도로 세지 않는다. 실측 경로가 없는 상태에서 ‘실제 실종자 위치 정확도’를 주장하지 않는다.

현재 상태: 최신 v5 자료 구축·자동 검사와 v2 학습 파일의 EXAONE tokenizer CPU 검사 완료. 같은 개발 40개에서 간결 후보 26/40 → 관측 상태 명시 30/40 → 목표 기억·현재 동작 분리 37/40까지 개선했다. 마지막 후보의 공개 설명까지 검토하면 의미 일치 30개·오류 8개·문구 재검토 2개여서 채택 기준은 아직 미달이다. 별도 합성평가 360개·자연어스트레스 80개는 미실행이다. 새 LoRA 학습·실제 응답의 KINTEX 연결 검증·운영 배포도 아직 완료되지 않았다.
