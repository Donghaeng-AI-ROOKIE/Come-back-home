# 확대 평가 사전 판정 기준

작성: 2026-09-30. `personal_contrasts_v4/evaluation.jsonl`의 모델 응답을 생성하기 전에 작성했다. 360개 합성 상황, 40개 인물 설정, 20개 대비 계열이며 독립 환자 360명의 자료가 아니다. 아래 수치는 임상 표준이 아닌 이번 기술 비교의 내부 진입 기준이다.

## 서로 다른 세 가지 주장

1. 개인 원문·현재 상태에서 행동을 해석하는가: 합성 조건의 정답, 개인 대비, 설명 근거로 검사.
2. 실제 앞단 K 해석을 함께 받아도 정보를 보존하는가: 별도로 보존된 실제 K 응답 8프로필·16상황으로 검사. 이 입력의 관측 정의 모호성부터 고치고 변경 이력을 남긴다.
3. 결정이 보행에 반영되는가: 통과한 실응답과 동일한 조건에서 KINTEX 엔진 상태·경로·시간 변화 추적.

어느 하나의 성공으로 다른 단계를 통과 처리하지 않는다. 실측 환자 경로와 현장 검토는 현재 확보되지 않았으므로 실제 환자 재현 정확도는 여기서 입증하지 않는다.

## 확대 합성 평가의 기술 기준

- 형식·필수 필드·허용 명령·유효 출처 ID 완성 360/360. 실패·빈 응답을 분모에서 빼지 않는다.
- 행동 정답 일치 최소 342/360(95%). 전체 평균과 함께 일곱 조건 유형별 성능을 보고하고 각 유형 90% 이상.
- 두 인물의 정답이 달라지는 88쌍 중 양쪽 동시 정답 최소 84쌍(95% 이상). 한쪽만 맞으면 그 쌍은 실패.
- 미확인 정보 때문에 유보해야 하는 사례와 충분한 정보가 있어 유보하면 안 되는 사례의 정답률 각각 95% 이상.
- 관측 참·거짓·미확인 반전, 원문에 없는 목표 생성, 명시적 개인 반응의 반대 선택, 행동과 공개 설명 충돌 등 중대 오류 0건. 전체 평균이 높아도 중대 오류가 있으면 보완 대상으로 판정.
- 한국어 공개 설명 여부·문장 품질·최신 정정 출처 선택을 별도 집계. 형식 검사로 의미 검토를 대신하지 않는다.

후보와 기준선은 동일 입력·같은 반복 수에서 비교한다. 각 사례의 개선·악화·불변과 유형을 공개한다. 전체 점수만 보고 특정 취약 유형을 감추지 않는다. 95%를 넘으면 실제 서비스가 안전하다는 뜻이 아니다.

현재 파일 기준 `continue`만 출력하면 184/360이다. 개인 반응을 전혀 읽지 않고 같은 관측의 두 인물에게 같은 답만 주는 방식은 88개 대비쌍 때문에 최대 272/360에 제한된다. 후자는 관측별 정답 빈도를 아는 가상의 상한이며 실제 구현 모델의 실측값이 아니다.

## 반복·표현·통계

첫 반복을 후보 간 핵심 비교로 사용한다. 추가 반복은 안정성 표로 분리하며 새로운 사람으로 세지 않는다. 신뢰구간을 계산한다면 20개 대비 계열을 묶어 재표집한다. 같은 사람의 9개 상태나 증강 문장을 독립 표본으로 취급하지 않는다. 20계열이 모든 치매 특성과 모든 온보딩을 대표한다고 주장하지 않는다.

최종 자료를 보고 프롬프트·라벨·학습을 수정하면 이 자료는 회귀 검사로 전환하고, 다음 최종 판정에는 새 계열이 필요하다. 자료 자체의 모호성이 발견되면 원본 결과와 문제 행을 모두 보존하며 특정 후보에 유리한 사후 정답 변경은 하지 않는다.

별도 자연어 스트레스 80개는 `natural_stress_v1/`에 20개 서사 × 4장면으로 초안을 만들었다. 아직 모델 실호출·독립 사람 검토를 하지 않았다. 위 360개와 합산해 검증 완료 실적으로 적지 않는다. 부탁·약속·관찰·정정과 개인별 행동·정보 부족을 구별하는 보완 평가다. 아직 자유 대화의 모든 다양성이나 실제 보호자 언어 분포를 대표하지 않는다.
