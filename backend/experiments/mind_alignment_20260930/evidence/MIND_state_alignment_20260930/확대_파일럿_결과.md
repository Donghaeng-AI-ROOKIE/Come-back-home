# 확대 파일럿 결과: 행동 37/40까지 개선, 의미 오류는 남음

2026-09-30, 20개 합성 인물 설정·10개 대비 계열의 개발 입력 40개를 두 후보로 비교했다. 각 인물에는 필요한 조건이 확인된 상황 1개와 미확인값을 포함한 상황 1개가 있다. 최종 별도 평가 360개는 아직 호출하지 않았다.

| 구성 | 형식 | 행동 정답 | 조건 확인 20개 | 미확인 포함 20개 | 양쪽 행동이 다른 15쌍의 양쪽 동시 정답 |
|---|---:|---:|---:|---:|---:|
| 최신 관측 분리 |40/40|23/40|19/20|4/20|9/15|
| 간결한 개인·상황 프롬프트 |40/40|26/40|20/20|6/20|11/15|

원문 ID 형식은 두 후보 모두 40/40 맞았지만, 맞는 ID를 인용한 것만으로 행동·설명이 정당해지지는 않는다. 전체 공개 설명에 대한 독립 사람 검토는 아직 없다. 행동 기준부터 미달이므로 두 후보 모두 배포 채택 판정은 아니다.

간결한 후보의 공개 설명 40개를 Codex가 비맹검으로 대조한 결과는 의미 일치 23개, 오류 16개, 부재/미확인 문구 재검토 1개다. 행동이 맞았더라도 누적 이동거리 500m를 ‘목적지까지 500m 남음’으로 바꾼 설명은 실패로 기록했다. 독립 사람·임상 평가 결과와 구분한다.

## 무엇을 확인했나

조건이 명확할 때 같은 환경의 다른 개인을 구분하는 능력은 확인됐다. 그러나 행동을 결정하는 데 필요한 조건이 미확인일 때, 이를 ‘그 조건이 없다’고 취급하고 기존 이동을 고르는 오류가 반복됐다. 이 문제는 단순히 JSON 형식을 못 맞추는 문제가 아니다.

실제 공개 응답 예시:

- 개인 설정: 공원에 소음이 있으면 회피, 없으면 기존 이동. 현재 소음은 미확인.
- 모델 출력: `continue`.
- 공개 설명: “공원 소음이 관측되지 않아 원래 이동합니다 및 목표 유지합니다.”
- 문제: 소음이 관측되지 않았다는 사실은 소음이 없다는 관측과 다르다. 두 경우에 행동이 달라지므로 이 기술 진단의 정답은 판단 유보다.

또 다른 예외 사례:

- 개인 설정: 다리가 무겁다고 말하면 휴식하되, 가족이 함께 있으면 이동 유지.
- 현재 상태: 다리 무거움 발언은 확인, 가족 동행은 미확인.
- 모델 출력: `rest`, 설명은 “동행 가족이 없어 잠시 쉬어야 합니다.”
- 문제: 가족이 없다는 사실을 만들어 예외를 배제했다.

판단 유보는 시뮬레이션 속 환자가 멈춰 서야 한다는 뜻이 아니다. 모델이 주어진 정보로 하나의 반응을 확정하지 못한다는 결과다. 실제 보행을 이어가는 정책과 가능성 분기는 이후 엔진 검증에서 별도로 다룬다.

## 중복 명령 문제와 중단 이력

먼저 준비한 비교는 80회 중 12회에서 중단했다. 과거 분기 계약에 적용한 ‘같은 목적지 재설정 명령 제거’가 이번 단일 상황 계약에는 빠져 있었기 때문이다. 남은 68회는 호출하지 않았고, 진행 중 완료된 2개 응답도 회수해 총 12개를 모두 보존했다.

수정은 같은 목적지로 이미 이동 중일 때 중복 `seek` 선택지만 제거한다. 쉬거나 기다린 뒤 다시 출발하는 명령과 다른 목적지로 바꾸는 명령은 보존한다. 개인 원문 단어로 행동을 정해 주거나 오답을 정답으로 바꾼 것이 아니다. 관련 15개 로컬 검사를 통과한 뒤 위 80회 비교를 새로 실행했다. 중단 전후 점수를 하나의 성공률로 합치지 않는다.

## 다음 개선

원문과 관측값은 그대로 두고 참·거짓·미확인의 의미와 가능한 값의 범위를 더 명확히 보여주는 후보를 별도 개발 40회로 비교한다. 원문의 행동 정답이나 제작용 규칙은 입력에 넣지 않는다. 최종 평가 자료는 계속 보존한다.

### 추가 40회 완료 결과

관측의 참·거짓·미확인을 명시한 후보는 행동 30/40, 형식 39/40이었다. 미확인 상황은 6/20에서 15/20으로 나아졌지만, 조건이 모두 확인된 상황은 20/20에서 15/20으로 떨어졌다. 개인 행동이 달라지는 15쌍의 양쪽 동시 정답도 11/15에서 10/15로 줄었다. **전체 점수 상승만으로 이 후보를 채택하지 않는다.**

공개 설명을 Codex가 비맹검 대조한 결과는 의미 일치 27개, 오류 12개, 문구 재검토 1개다. 이 가운데 명령이 맞아도 미확인 조건을 없다고 설명하거나 판단 유보를 환자의 대기 행동처럼 설명한 경우는 실패로 남겼다. 한 응답은 공개 설명 400자 제한을 넘었으며 검증기에서 거절됐다. 출력 한도 소진은 아니고 내용 길이 계약 위반이다.

다음 개선의 핵심은 필요한 유보를 늘리면서 이미 맞던 개인 반응과 행동 실행 의미를 보존하는 것이다. 재학습 자료도 확인된 조건과 미확인 조건을 함께 포함해야 한다. 데이터 수를 늘린 효과는 별도 평가에서 확인하며, 이번 개발 40개를 외워 맞히는 것으로 도입을 정당화하지 않는다.

확대 학습 후보에는 이 실패 유형을 포함한 2,160행이 있다. EXAONE tokenizer CPU 검사에서 2,160행 전부 잘림 없이 통과했고 최대 길이는 1,858토큰이었다. 이것은 학습 준비 검사이며 재학습 성능 결과가 아니다.

## 목표 기억과 현재 동작을 구분한 추가 40회

목적지를 기억한다는 것과 지금 그 목적지로 계속 걷는다는 것을 혼동하지 않도록 명령 설명을 수정했다. 휴식·대기·회피는 목표 기억을 유지하면서 현재 동작을 바꿀 수 있다. 허용 명령·개인 원문·관측·정답을 바꾸지 않고, 명령의 실제 `goal_operation`과 동작 효과를 입력에 함께 보여 줬다. 관련 로컬 검사 19개를 통과했다.

| 구성 | 형식 | 행동 정답 | 조건 확인 20개 | 미확인 포함 20개 | 다른 개인 반응 15쌍의 양쪽 동시 정답 |
|---|---:|---:|---:|---:|---:|
| 간결한 후보 |40/40|26/40|20/20|6/20|11/15|
| 관측 상태 명시 |39/40|30/40|15/20|15/20|10/15|
| 목표 기억·현재 동작 분리 |40/40|37/40|19/20|18/20|13/15|

같은 개발 입력에서 간결한 후보보다 13개 개선·2개 악화·25개 동일했다. 10개 합성 대비 계열을 묶은 bootstrap에서 차이는 +27.5%p, 95% 구간은 +12.5~+40%p다. 반복 수정에 사용한 개발 자료이고 입력당 한 번 생성했으므로, 새로운 사람에 대한 최종 성능이나 반복 안정성으로 해석하지 않는다.

**명령 37/40이 의미까지 맞은 37건이라는 뜻은 아니다.** 공개 설명 전체를 Codex가 비맹검 검토한 결과 의미 일치 30개, 오류 8개, 문구 재검토 2개였다. 독립 사람·임상 평가가 아니다. 명령은 맞았으나 설명에서 다음 문제가 남았다.

- `defer`를 환자가 대기한다는 행동으로 표현.
- 미확인 발언을 조건 불성립으로 바꿔 설명.
- 원문의 목표 없는 보행을 근거 없는 순환 이동으로 표현.
- 실제 기억한 목표 A를 B로 바꾸거나, 가족 동행을 동거 조건으로 바꿔 설명.

명령 자체의 오답 3개는 미확인 소음을 없다고 판단한 경우, 확인된 숲길 소음을 미확인이라고 판단한 경우, 소음 유무와 관계없이 같은 반응인 사람에게 불필요하게 유보한 경우다. 개선은 확인했지만 명확한 조건 1개 회귀와 의미 오류 때문에 채택 기준은 아직 통과하지 못했다. 최종 별도 평가 360개와 자연어 80개는 사용하지 않았다.
