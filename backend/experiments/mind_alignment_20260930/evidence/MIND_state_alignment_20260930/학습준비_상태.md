# 확대 재학습 준비 상태

## 완료

- 합성 개인 대비 40계열·80프로필·720상황, 표현 증강 포함 학습 후보 2,160행.
- 별도 개발 180행·평가 360행. 같은 계열/개인/관측 대비/원문이 분할을 넘지 않는지 검사.
- 학습과 개발만 `training_export_v1/`로 변환. 최종 평가 자료는 서버 학습 폴더에 전송하지 않음.
- EXAONE 3.5 7.8B Instruct의 기존 tokenizer로 CPU 검사. 모델 forward·학습 0회.

| 파일 | 행 수 | 입력+정답 총 토큰 | 정답 토큰 | 최대 길이 |
|---|---:|---:|---:|---:|
| 원형 학습 |720|1,124,850|47,697|1,835|
| 증강 포함 학습 |2,160|3,403,800|143,091|1,858|
| 개발 |180|284,870|11,723|1,819|

검사 상한은 8,192토큰이며 잘림·누락 0건. 이 토큰은 CPU tokenizer가 센 학습 자료 길이로, 유료 API 사용 토큰에 합산하지 않는다.

## 현재 실행 조건

2026-09-30 16:35 KST 확인 시 NVIDIA A100-SXM4-80GB 한 장에 두 vLLM 프로세스가 각각 7,904MiB·70,342MiB를 점유하고 여유 메모리는 2,893MiB였다. 사용률 0%는 메모리가 비어 있다는 뜻이 아니다. 기존 베이스 모델과 이전 어댑터 파일은 존재했다. 프로세스를 중단하거나 GPU 메모리 설정을 바꾸지 않았다.

새 학습의 자료·모델·토큰 예산·GPU 실행 상한을 확정하고, 기존 서빙의 복구 가능한 실행 방식을 확인한 뒤 진행해야 한다. 이번 파일럿은 GPU를 사용하지 않는 K API 비교다. 이전의 서비스 중단·복구가 성공했다는 기록을 현재 실행 상태 검증으로 대신하지 않는다.

`training_export_v1`의 프롬프트는 간결한 후보와 중복 제거 명령 계약이다. 후속 후보를 채택하면 새 export 버전과 해시를 만들어 tokenizer 검사를 다시 한다. 예전 프롬프트로 학습한 뒤 새 프롬프트 성능으로 소개하지 않는다.

## 학습 전에 추가로 판단할 것

- 합성 원문과 정답의 기술적 의미 검토는 임상적 개연성 검토와 구분.
- 기존 96개 자료는 발언/인식 관측과 일반/가족 동행 구분을 다시 점검하기 전 무조건 합치지 않음.
- 현재 합성 자료의 `continue` 비중과 드문 행동을 공개하고 매크로 지표·개인 대비 지표로 편중을 감시.
- 먼저 원형 720개와 증강 2,160개의 효과를 같은 초기 가중치·비슷한 처리 토큰 수로 비교. fresh/warm 비교는 그다음 별도 실험으로 분리.
- 미확인 처리까지 개발 기준을 통과한 후보만 별도 평가·실제 앞단 출력 연결·KINTEX 실행으로 진행.

## 마지막 자료 수정과 v2 검사

피로 발언과 피로 proxy의 고정 동반 관계를 제거한 `personal_contrasts_v5/`를 추가했다. 행 수는 2,160개로 같으며 개인 원문·관측·정답·별도 개발/평가 파일은 보존했다. 명령 안내에서도 목표 기억 유지와 현재의 이동 동작을 분리했다.

수정 데이터와 명령 안내를 `training_export_v2/`로 새로 내보내고, 서버의 별도 폴더에서 CPU tokenizer 검사를 완료했다. 기존 v1 자료와 검사 결과는 이력으로 보존한다. v2도 아직 채택하거나 GPU에서 학습한 모델은 아니다.

| 파일 | 행 수 | 입력+정답 총 토큰 | 정답 토큰 | 최대 길이 |
|---|---:|---:|---:|---:|
| 원형 학습 |720|1,758,318|47,697|2,701|
| 증강 포함 학습 |2,160|5,304,204|143,091|2,724|
| 개발 |180|442,184|11,723|2,676|

v2 전 행 검사 통과, 잘림·정답 누락 0건. 원형 6 epoch와 증강 2 epoch는 정답 토큰 노출 286,182개로 같으며, 입력 포함 총 노출은 각각 10,549,908토큰과 10,608,408토큰으로 약 0.55% 차이다. 이것은 학습 예산 산정이며 실행 사용량·청구액이 아니다.

추가 범위 검사에서 모든 직전 행동이 seek, 경과 시간이 60분이고 앞단 K 해석이 비어 있다는 한계도 확인했다. 이 자료는 개인 조건 해석을 위한 한 구성요소다. 전체 마음모델 완성용 데이터라고 소개하지 않는다. 새 LoRA 학습은 실행하지 않았다.
