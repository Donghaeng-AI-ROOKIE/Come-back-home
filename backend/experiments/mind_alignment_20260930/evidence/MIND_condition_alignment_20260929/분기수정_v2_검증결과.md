# 분기 수정 후보 v2: 개선 불확정, 출력 형식 지시 누락 확인

2026-09-29. 승인한8개상황×2반복16회를 모두 실행했다. **이 수정본은 이전 후보보다 전체 결과가 낮아 채택하지 않는다.** 기존에 맞던 공원 행동은 유지됐지만, 시장 사례에서 출력 미완성과 의미 오류가 발생했다. 운영 교체나 배포는 하지 않았다.

## 바꾼 내용과 확인된 점

같은 목적지로 이미 이동 중일 때 중복 목적지 설정 선택지를 제외하고, 관측 시각과 관측 후 경과시간을 함께 명시하고, 분기별 가정값을 한국어로 풀어 적었다. 개인 원문과 기존 판정 기준은 유지했다.

소음 미확인 공원 상황에서 두 반복 모두 소음 없음→이동 유지, 소음 있음→공원 회피를 선택했다. 이전 후보의 continue/seek 혼동은 이번에는 관찰되지 않았다. 다만 중복 명령 선택지 제한 효과와 모델의 해석 능력 향상을 분리해야 한다.

## 새로 드러난 실패

### 출력 문제: 추론만 길어진 것이 아니라 공백을 반복

D04-1첫반복은 최종 content21071자 중20944자가 공백이었다. D04-4첫반복도23015자 중22465자가 공백이었다. 둘 다 JSON을 시작한 뒤 공백·줄바꿈을 반복하다12,000토큰에서length종료했고 JSON이 완성되지 않았다. 첫 분기의 부분 응답을 수선해서 사용하지 않았다.

[Friendli 공식 API 문서](https://friendli.ai/docs/openapi/dedicated/inference/chat-completions)는 response_format과 별개로 원하는 출력 형식을 system/user 메시지에서 명시해야 하며, 누락하면 공백 등이 계속 생성될 수 있다고 설명한다. 코드를 대조하니 단일선택 프롬프트에는 JSON출력 지시가 있었으나, 분기 프롬프트로 교체하면서 명시적인 완전한 JSON객체 반환 지시가 빠졌다. 이는 에이전트가 만든 프롬프트의 누락이다.

이 누락은 이전 분기 후보에도 있었다. 따라서 이것 하나로 v2의 모든 악화가 설명된다고 주장하지 않는다. 공식 안내와 관측 현상에 맞는 원인 후보이며, 지시만 추가한 비교가 필요하다.

### 설명 문제: 피로 값 대신 날짜

D01-1첫반복b3의 명령은rest였지만 설명은 “피로 수준 026-09-28T09:00:00+09:00로 매우 지침”이었다. 입력 피로는0.9였다. 모델 API 최종 원문에서도 같은 오류가 있어 보고서나 변환 코드의 문제는 아니다.

### 개인 조건 문제: 다른 목적지와 근거 없는 혼잡 효과

D04-2첫반복은 한 분기에서 등록 장소B로seek_1을 선택했다. 원문에는 그런 목적지 변경 근거가 없다. 다른 분기에서는 가족 여부 미확인을 혼자라고 판단하는 근거로 썼다.

두 번째 반복에서는 “혼잡은 추가 위험 요소”라며 원문에 없는 회피 반응을 추가했다. 이 합성 개인은 가족 동행 시 소음에도 원래 길을 간다는 조건이며, 단순 집단 추정으로 추가 회피를 확정할 수 없다. 최종 집계가유보로 바뀌어 원래 기대값과도 불일치했다.

## 시험 입력의 모호함도 분리

현재 관측은companion_observation:true이지만, 보호자 원문은가족동행예외다. 동행자의 관계를 명시하는 필드는 없었다. 분기 설명의companion_present는가족이라고 정의했으나 현재 관측 필드와 일관되게 연결되지는 않았다. 모델이 가족인지 모르겠다고 지적한 부분 자체를 오답의 근거로 삼지 않는다.

그래도 다른 목적지를 만들거나 동행자가 있는데 혼자로 간주하거나 혼잡에 따른 개인 반응을 새로 만드는 것은 정당화되지 않는다. 기존 입력·정답을 소급 수정하지 않았고 원래 기준 점수는 보존했다. 다음 자료 버전에서관계정보를명시하면 이는입력개선이며모델단독향상으로세지않는다. 자세한 기록은동행관측_의미범위_점검.md에 남겼다.
