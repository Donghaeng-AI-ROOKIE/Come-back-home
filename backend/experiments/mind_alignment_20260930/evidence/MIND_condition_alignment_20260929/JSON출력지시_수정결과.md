# JSON 출력 지시 수정 대조 결과 — 2026-09-30

## 결론

누락된 JSON 출력 지시를 추가한 뒤 이번 4회는 모두 완전한 JSON을 반환했다. 이전에 공백 반복으로 중단된 두 입력을 포함한 대조에서 형식 개선 신호가 확인됐다. 그러나 개인 행동 해석은 아직 안정적이지 않다. 1회에서 원문에 없는 새 목적지를 선택했으므로 이 후보를 배포 가능한 마음모델로 채택하지 않는다.

## 왜, 무엇을 바꿨나

이전 v2는 최종 JSON을 쓰던 중 공백을 반복해 출력 한도에 도달했다. 프롬프트에 완전한 JSON 객체를 반환하라는 명시 지시가 빠져 있었다. 이번에는 그 지시만 system 메시지에 추가했다. K-EXAONE 배포 모델, 보호자 원문, 개인 요약, 관측, 선택지, JSON Schema, Thinking, temperature=1, top_p=0.95, 출력 한도 12,000은 그대로 유지했다. 4개의 동결 요청을 코드로 대조했다.

합성 인물 1명의 두 상황(혼자임 확인 / 동행 미확인)을 각 2회 실행했다. 여러 가정에 따라 12개의 행동을 평가했다. 실제 환자 데이터나 KINTEX 보행 실험이 아니다. 기존 RAG·GPU·지도 추가 호출은 없었다.

## 같은 두 입력의 이전 결과와 비교

| 항목 | 이전 v2 4회 | JSON 지시 수정 4회 |
|---|---:|---:|
| 완전한 JSON | 2/4 | 4/4 |
| 출력 한도 도달 | 2/4 | 0/4 |
| 호출별 최종 행동·유보 일치 | 2/4 | 3/4 |

수정 후보의 개별 가정별 행동은 고정된 합성 평가 기준과 11/12 일치했다. 두 반복의 모든 행동이 같은 입력은 1/2였다. 샘플이 작고 seed를 고정한 반복 실험이 아니므로 형식 문제가 영구 해결됐거나 모델 자체가 우수해졌다고 단정할 수 없다.

## 실제 출력에서 확인한 점

혼자이고 시장 소음이 있는 상황의 첫 반복은 두 혼잡 가정 모두 `avoid_market`을 선택했다.

> 혼자이고 시장 소음이 있으므로 시장 환경에서 멀어지는 이동

그러나 같은 입력의 두 번째 반복에서는 혼잡이 있다는 가정에서 `seek_1`을 선택했다.

> 시장 소음이 있으나 동행자 없어도 등록 장소 B로 이동 필요

장소 B는 등록 목록에 있을 뿐, 현재 그곳에 가야 한다는 근거가 없다. 보호자는 시장 소음 상황에서 혼자면 돌아간다고 했다. JSON은 올바르지만 개인의 행동을 잘못 해석한 명확한 실패다. 다른 분기의 회피와 새 목적지 선택이 충돌해 서버의 최종 결과도 유보로 바뀌었다. 형식 통과를 개인 행동 정확도로 세지 않아야 하는 사례다.

## 동행 정보의 한계

동행 미확인 사례는 기존 고정 정답에 맞게 혼자라는 가정에서는 회피, 동행 가정에서는 이동 유지를 선택했다. 다만 원문은 가족 동행 예외이고 입력의 관측·가정 이름은 일반 동행이다. 가족 여부가 없는 상태에서 가족 예외를 적용해도 되는지 모호하다.

고정 평가 점수는 수정하지 않았다. 별도 엄격 의미 검토에서는 12개 분기 중 7개는 원문·관측과 일치, 1개는 근거 없는 목적지로 실패, 가족 관계가 빠진 4개는 입력 명확화 필요로 분류했다. 이 평가는 Codex의 비맹검 검토이며 돌봄 경험자 또는 임상 전문가 평가가 아니다.

## 사용량과 실행 증거

- K-EXAONE 4회, 재시도 0회. 입력 9,422토큰, 출력 12,111토큰.
- API 응답 시간 중앙값 약 27.5초, 최대 약 38.1초. 이 값은 앱 전체 예측 지연시간이 아니다.
- 단가·실청구액·지원 차수는 미확인. 공용 원장과 원격 영수증 보존, 누적 87회의 시작·종료 짝 확인.
- 실행 전 자동 승인 검토의 차단이 있었고, 구체 범위를 재제시한 뒤 사용자의 “이어서해줘” 지시를 받아 해당 4회 실행이 허용됐다.
- 신규 실호출 외 GPU 학습·RAG 검색·지도 조회·서비스 중단·배포 없음.

`json_completion/results.jsonl`에는 최종 출력, `json_completion/calls/`에는 원본 응답이 있다. 이 보고서에는 모델의 최종 공개 설명만 사용했다. 비교표는 `json_completion/matched_format_comparison.json`, 고정 행동 평가는 `json_completion/comparison.json`, 별도 의미 평가는 `json_completion/semantic_review.json`에 저장했다.

## 다음 개선

여러 가정 상황을 한 응답에 함께 생성하는 과정에서 조건이 섞이는지 확인한다. 이번 후보와 같은 원문·관측·가정·모델을 사용하되 요청당 가정 하나만 전달하는 후보를 준비했다. 두 입력의 총 6개 가정 × 2반복 = 12회다. 모든 가정의 결과를 모은 뒤 기존 방식으로 합쳐 유보 여부를 판단하며, 누락된 결과는 임의로 채우지 않는다.

이 대조도 가족 관계 누락을 해결하는 실험은 아니다. 먼저 분리 요청의 효과를 확인하고, 동행 관계를 명시하는 새 데이터 버전은 별도 비교한다. 이 작은 개발 대조를 통과하더라도 다양한 인물·시간·환경 사례와 실제 앞단 출력, KINTEX 보행 연결 검증이 남는다.
