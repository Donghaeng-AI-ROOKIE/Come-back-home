# 앞단 개인 해석의 시범 도입 기준 (제안)

이는 공인 임상 기준이나 서비스 정확도 보증이 아니다. 95%는 이 프로젝트의 잠정 목표이며, 아직 이 기준으로 독립 검증한 결과는 없다.

## 측정 대상

보호자가 전달한 정보가 **원문 → K 구조화 → 저장 → 사건별 엔진 입력**까지 유지되는지를 평가한다. 실제 사람이 그 경로로 갔는지의 정확도와 구분한다. JSON 구조 통과율만으로 개인 표현 품질을 판단하지 않는다.

| 항목 | 잠정 기준 | 평가 방법 |
| --- | --- | --- |
| 근거가 있는 개인 특성 보존 | 95% 이상 | 목적지·경로 경험·머무름·방향·거리·환경 조건별 일치율과 근거 누락률을 각각 보고 |
| 위험한 의미 변환 | 독립된 사람·상황 300건에서 0건 | 대기↔계속 이동 반전, 한 장소→유형 전체 확대, 미확인→사실 단정, 조건 탈락을 별도 심사 |
| 기존 SAR 대비 | 전체 악화 없음 + 목표 약점 개선 | 동일 입력의 최종 엔진 입력을 블라인드 비교; 반복 출력·유사 문장은 독립 표본으로 세지 않음 |
| 엔진 전달 | 필수 회귀 테스트 전부 통과 | 해석이 올바르더라도 반경·가중치·조건 적용이 뒤집히면 실패 |
| 운영 흐름 | 신고에 K 완료 대기 없음 | 등록 없음·준비 중·준비 완료·실패·재시작·삭제·수정 시나리오 검증 |

300건에서 오류 0건이어도 오류 확률이 0이라는 뜻은 아니다. 독립·동일 분포라는 가정하에 이항 단측 95% 상한은 1 - 0.05**(1/300), 약 0.994%다. 합성 문장 300개를 기계적으로 변형해 이 표본 수를 채우지 않는다.

전부 unknown으로 출력하면 개인 특성 보존 항목에서 탈락한다. 반대로 근거 없는 과감한 추론도 탈락한다. 같은 사람이 낮/밤 또는 장소별로 다른 행동을 한다면 조건을 포함한 진술 단위가 평가 대상이다.

## 개발 사례와 최종 평가 분리

현재 v41/v43/v44는 개발·회귀 검증이다. 최종 평가에는 프롬프트 수정에 쓰지 않은 잠금 세트를 사용하고, 보호자 표현의 길이·말투·정정·정보 부족·상충을 포함한다. 정답은 구조와 근거를 사람이 검토한 허용 해석 집합으로 만들며, 치매 행동의 임상 타당성은 관련 현장 전문가 검토가 별도로 필요하다. 최종 세트를 보고 수정한 뒤 그 세트 통과를 새 독립 성과로 보고하지 않는다.

## 실서비스의 범위

이 기준 통과는 **앞단의 제한된 시범 적용 후보**를 뜻한다. 실제 실종 경로를 맞히는 성능, 수색 효율, 시민 알림 효과를 입증하지 않는다. 해당 평가는 실제 경로/종료 사례, 동일 면적에서의 위치 포함률, 동일 포함률에서의 수색 면적, 시간대별 누락을 통해 따로 수행해야 한다. 계정·사건 접근 제어 등 서비스 전체의 준비 상태도 별도다.

참고: [NIST AI RMF의 유효성·신뢰성](https://airc.nist.gov/airmf-resources/airmf/3-sec-characteristics/)은 실제 사용 조건을 대표하는 평가셋과 오류의 피해 정도를 함께 고려하도록 한다. 위 95%·300건 수치는 NIST가 정한 값이 아니다.
