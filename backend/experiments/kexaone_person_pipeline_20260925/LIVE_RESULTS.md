# 새 사례 2개 최종 실시간 검증 — 무엇이 실제로 개선됐나

2026-09-25. 사용자 승인 범위: 합성 사례 2개, K 최대 6회, SAR 최대 2회, 자동 재시도 없음. 이 범위로 실행을 완료했다. 운영 배포와 재학습은 수행하지 않았다.

## 판정

**사전에 정한 최종 의미 보존·입력 생성 기준은 2/2 통과했다.** 두 사례 모두 실제 SAR 응답과 K API 응답을 사용했다. JSON 형식 실패 0건, SAR 복귀 0건이었다. 기준과 사례는 호출 전에 저장했으며 해시로 변경 없음을 확인했다.

이 결과는 앞단 해석 후보를 유지할 근거다. 실제 치매 어르신 경로를 더 정확히 맞혔다는 결과나, 어떤 온보딩이든 완벽하게 재현한다는 증거는 아니다. 이번 실행에는 새 OSM 경로 생성이 없다. 기존 OSM 검증과 구분한다.

## 같은 내용을 SAR와 K에 제공

SAR 기존 behavior_notes와 K 원문 근거에 같은 합성 보호자 진술을 넣었다. 잘못된 AI 요약을 일부러 섞지 않았다. 기존 RAG 스냅샷을 재사용했고 새 검색·임베딩 호출은 하지 않았다. 신규 두 사례는 기존 실패 유형을 참고한 새 문장·조합이며, 독립 임상 표본이나 다양한 자연 대화의 무작위 표본은 아니다.

비교 대상은 실제 기존 SAR 경로와 후보 전체다. 모델, 프롬프트, 출력 계약, 검토 횟수가 함께 다르므로 K 모델 자체만의 효과를 분리한 실험은 아니다.

## 사례 1 — 공원에는 가고 싶지만 길은 모르는 사람

보호자는 ‘아침마다 공원에서 친구를 만나야 한다고 말하지만 도착은 확인하지 못함’, ‘이사 온 뒤 공원 길을 이용한 적 없음’, ‘길을 잃은 두 번 모두 누군가 올 때까지 기다림’, ‘평지에서 42분 정도 독립 보행 가능’이라고 설명했다.

SAR는 모든 장소를 단순 언급으로 낮게 처리했고, 시장·복지관의 경험 미확인까지 ‘실제 방문 경험 없음’으로 넓혔다. 또 일반적인 치매 행동을 이유로 경로 추종에 높은 비중을 뒀다.

K 최종 해석은 **공원 의도 있음 / 공원 경로 경험 없음 / 길을 잃으면 기다림 / 방향 선택 미확인 / 생활권 보행 능력**을 동시에 유지했다. 실제 공원 도착·친구 만남을 관찰 사실로 만들지 않았고, 공원 목적을 모든 공원 환경 선호로 바꾸지 않았다.

| 시뮬레이션 입력 | 실제 SAR 기준선 | K 반영 후 |
| --- | ---: | ---: |
| 공원 끌림 가중치 | 0.3333 | 0.4286 |
| 경로 추종 전략 | 0.5000 | 0.1875 |
| 대기 전략 | 0.0556 | 0.1875 |

K의 판단은 원문 근거 ID를 포함해 보존했고, 수치는 기존 엔진 변환 규약으로 만들었다. 위 값은 실측 행동 확률이 아니다. 특히 대기 비중 상승만으로 모든 가상 보행자가 실제 사람처럼 기다린다고 할 수 없다.

## 사례 2 — 낮과 밤의 행동이 다른 사람

보호자는 ‘낮에는 기다림, 밤에는 계속 귀가 길을 찾음’, ‘밤에는 갈림길에서도 같은 방위를 유지’, ‘평지 38분 보행 가능’, ‘붐비고 시끄러운 시장만 회피, 조용하면 회피하지 않음’이라고 설명했다. 실종 시각은 밤 22:15로 고정했다.

SAR 설명에는 원문에 없는 ‘낮에는 보호자 감독 아래 있었음’이 추가됐다. K 첫 핵심 출력도 낮·밤의 차이를 alternating으로 단순화했으므로, 처음부터 완벽한 출력이었다고 보지 않는다. 조건 해석과 최종 원문 재검토는 **현재 밤 조건에서 계속 이동 / 같은 방위 유지 / 생활권 보행 능력**으로 정리했다.

방향 유지 전략 입력은 0.2451 → 0.4902로 바뀌었다. 시장 회피는 `conditional_category + avoid + present`로 출력됐고, 최종 기록에는 `condition=required`로 남았다. 모든 시장을 피하는 입력은 만들지 않았다.

**조건부 시장 회피는 아직 경로에서 실행되지 않는다.** 현재 엔진에 혼잡·소음 조건을 적용하는 소비부가 없어 `unrepresented`에 남겼다. 낮·밤의 선택도 최초 사건 조건을 해석한 것이며, 시뮬레이션 중 날이 밝으면 자동 전환되는 기능을 검증한 것은 아니다.

## 과장 없이 남겨야 할 관찰

- 공원 사례의 조건 응답은 반응이 unknown인 공원·시장에 place_specific/none 보조 표기를 붙였다. 접근·회피 행동을 만들어 주입하지는 않았지만, 보조 범위 필드까지 완벽한 의미 해석으로 판정하지 않는다.
- 정해진 목적지 후보 밖의 목적, 구체적인 기억 경로, 38분·42분의 정확한 지속 시간, 도움을 청하는 방식까지 모두 표현한 것은 아니다.
- 반환된 한국어 최종 요약은 검증된 enum을 코드가 문장으로 표현한 것이다. 별도의 자유서술 모델 답변 품질로 점수화하지 않는다.
- K 검토는 같은 모델의 재검토다. 독립 전문가의 임상 검증을 대신하지 않는다.
- 두 사례는 각각 한 번 실행했다. 말투 변화와 반복 실행 안정성을 일반화할 수 없다.
