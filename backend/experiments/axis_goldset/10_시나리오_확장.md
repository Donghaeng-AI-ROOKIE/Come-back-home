# 확장 시나리오 (골드셋 v1 파일럿) — Claude 작성

형식은 기존 `02_시나리오_대화.md`와 동일(`보호자: … → axis_field` 태그). 평가
스크립트 `eval_axis_goldset.py`가 이 파일과 `11_정답표_v1.md`를 함께 읽는다.

구성: 치매 표준 5 + 발달 표준 5 + 대조쌍 2세트(4명) = 14명.
표준은 저위험/고위험/혼합/중간대로 층화해 각 축이 0.1~0.9를 고루 보게 배치.
대조쌍은 한 축 근거만 저↔고로 바꾸고 나머지는 고정 → 변별·축분리 검증.

보호자: 성함이랑 동네 잘 말씀하시고 경찰이 물어보면 아들 전화번호도 대세요. → communication_approach_vulnerability
챗봇: 길을 헷갈려 하신 적 있나요?
보호자: 낯선 데서만 가끔 헷갈리시는데 표지판 보고 알아서 돌아오세요. → wayfinding_error_recovery_deficit
챗봇: 옛날 살던 곳 얘기 자주 하시나요?
보호자: 옛날 얘기를 하시긴 해도 거길 찾아가려 하신 적은 없어요. → autobiographical_destination_pull
챗봇: 불안해하시면 밖으로 나가려 하세요?
보호자: 좀 답답해하셔도 자리를 뜨거나 나가시진 않아요. → distress_induced_movement_reactivity
