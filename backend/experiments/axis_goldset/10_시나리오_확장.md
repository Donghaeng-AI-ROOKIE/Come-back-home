# D1. 치매 (74세, 초기·활동적 / 전반 저위험)
챗봇: 평소 혼자서 얼마나 다니시나요?
보호자: 매일 약수터까지 왕복 한 시간 넘게 걷고, 시내버스도 노선 아시는 건 혼자 타세요. → mobility_transport_capacity
챗봇: 길 위험한 곳은 잘 피하시나요?
보호자: 신호랑 횡단보도는 꼬박꼬박 지키시고 물가나 공사장은 알아서 피하세요. → hazard_awareness_vulnerability
챗봇: 누가 말을 걸면 어떻게 하세요?
보호자: 성함이랑 동네 잘 말씀하시고 경찰이 물어보면 아들 전화번호도 대세요. → communication_approach_vulnerability
챗봇: 길을 헷갈려 하신 적 있나요?
보호자: 낯선 데서만 가끔 헷갈리시는데 표지판 보고 알아서 돌아오세요. → wayfinding_error_recovery_deficit
챗봇: 옛날 살던 곳 얘기 자주 하시나요?
보호자: 옛날 얘기를 하시긴 해도 거길 찾아가려 하신 적은 없어요. → autobiographical_destination_pull
챗봇: 불안해하시면 밖으로 나가려 하세요?
보호자: 좀 답답해하셔도 자리를 뜨거나 나가시진 않아요. → distress_induced_movement_reactivity

# D2. 치매 (82세, 중증 / 전반 고위험)
챗봇: 평소 이동은 어느 정도 하세요?
보호자: 부축 없이는 몇 걸음 못 걸으시고 집 안에서만 조금 움직이세요. → mobility_transport_capacity
챗봇: 위험한 상황은 알아보세요?
보호자: 차도로 그냥 내려가시고 예전에 도로에서 교통사고 날 뻔한 적도 있어요. → hazard_awareness_vulnerability
챗봇: 낯선 사람이 다가오면요?
보호자: 성함도 못 대시고 모르는 사람이 다가오면 소리 지르고 뿌리치며 도망가려 하세요. → communication_approach_vulnerability
챗봇: 길 찾는 건 어떠세요?
보호자: 집 앞에서도 방향을 못 잡으시고 스스로 돌아오는 건 이제 불가능해요. → wayfinding_error_recovery_deficit
챗봇: 예전 장소를 찾으려 하세요?
보호자: 돌아가신 옛집에 가야 한다며 몇 번이나 나가셨고 지난 실종 때도 옛집 골목에서 찾았어요. → autobiographical_destination_pull
챗봇: 불안하면 어떻게 하세요?
보호자: 밤에 무섭다며 뛰쳐나가신 적이 있고 그렇게 나가서 실종된 적도 있어요. → distress_induced_movement_reactivity

챗봇: 길을 잃으신 적은요?
보호자: 익숙한 동네에서도 가끔 방향을 헷갈려 하시는데 사람들 도움 받으면 돌아오세요. → wayfinding_error_recovery_deficit
