## 대조쌍 검증 포인트 (변별·축분리)

- **DAL vs DAH** — autobiographical_destination_pull만 B→E, 나머지 5축 동일.

## [경계 셀] 사람 재확인 권장 (라벨러끼리 갈릴 만한 곳)

- D2 hazard = E: "교통사고 날 뻔"을 '중대한 위험 경험(E)'으로 봄. 근접사고를 D로 볼 여지 있음(D/E 경계).
- D3 distress = A vs B: "불안해하시긴 해도" 표현을 이동변화 없음(A)으로 봄. 표현 있음(B)으로 볼 여지.
- P2 hazard = E: "차도로 뛰어든 적"을 실제 중대 위험(E)으로 봄. D 여지.
- P4 mobility = C vs D: "익숙한 길 혼자 걷기"만 있고 대중교통 불가 → C. 장시간 보행이면 D 여지.
