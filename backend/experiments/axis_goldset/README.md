## 축 구조 개정 (2026-07-17, 팀원 공식 기준표 반영)

- 공통 3축·치매 3축이 팀 확정본으로 교체됨(`app/phase0/axis_rubric.md`). 발달 4축은 불변.
- **route_environment_familiarity 축 폐지** — 사람이 아니라 (사람,경로) 쌍의 속성이라
  EXAONE 페르소나 채점에서 빼고 장소별 관계 변수(`Persona.route_familiarity`, 스키마만
  선반영)로 분리. 채점 대상은 **치매 6축 / 발달 7축**으로 변경(이전엔 각 7축).

  탐색 반경·방법이 통째로 바뀌는 별개 시나리오라 이 축 척도로 다루지 않기로 함.
