# K-EXAONE 개인 표상 비교 결과

실행일: 2026-09-23. 상태: 승인 범위 내 1차 48회 완료, 사전 판정 기준에 따라 후속 생성·보행 생략. 운영 앱·SAR·보행 코드 변경 없음.

## 결론

이번 네 구성 중 “보호자가 알려준 이 사람의 특성을 보존하고 보행 설정으로 안정적으로 전달한다”는 사전 기준을 통과한 구성은 없었다. 따라서 K-EXAONE 도입이나 SAR 교체를 뒷받침하는 결과는 아니다. K가 개인 정보를 전혀 구분하지 못한 것도 아니다. 시장/공원 관찰에 따라 장소 가중치가 바뀌었고, 머무름/계속 걷기 차이는 staying_put에 일부 반영됐다. 문제는 그 과정에서 없는 개인 행동을 추가하거나 관찰된 이력을 부정하는 출력이 함께 발생했다는 점이다.

RAG를 뺀 B에서도 전략 관련 과거 이력의 과잉 해석이 남았다. RAG 유무만 바꾸면 해결된다고 볼 수 없다. 출처를 표시한 C/D도 충분하지 않았다. 다만 작은 합성 사례 집합의 AI 검토이므로, RAG의 평균 효과나 K의 전반적 성능을 확정하지 않는다.

이번 판정은 형식만의 검사가 아니다. 개인 관찰 보존 → 보행 파라미터 반영 → 실제 도로 위 움직임의 순서 중 앞 단계에서 중단했다. 신규 OSMnx 경로가 없으므로 움직임이 개선됐다고 주장하지 않는다.

## 실제 비교 조건

개발 사례 6개 × 4조건 × 2반복 = 48회. F01은 최근 시장/공원 지향 차이, F05는 헤맬 때 가까이 머무름/계속 걷기 차이, F06은 최근 시장 방향 직접 관찰/최근 방향 미확인 차이다. 모든 사례에 과거 세 장소를 향한 반복 관찰 기록이 있다.

| 조건 | 프롬프트·RAG | 기본 출력 계약 | 코드 처리 후 prior 사용 가능 | 명백한 개인 사실 오류 최소 건수 |
|---|---|---:|---:|---:|
| A | v3 + 기존 RAG | 11/12 | 12/12 | 5/12 |
| B | 같은 v3 + RAG 없음 | 11/12 | 12/12 | 1/12 |
| C | v3 + 개인 기록/문헌 출처 분리 | 10/12 | 11/12 | 2/12 |
| D | 짧은 지시문 + C와 같은 RAG | 11/12 | 12/12 | 3/12 |

오류 건수는 전수 검토 후 명백하다고 판정하고 인용을 남긴 최소 건수다. 독립 평가자가 확인한 오류율이나 조건별 우열의 통계적 추정치가 아니다. B의 1건은 의미 해석에 민감하므로 아래 근거와 재검토 조건을 함께 남겼다. 형식 지표는 기존 파서의 기계적 검사 결과이며, 2~3문장 지시나 근거 설명의 적절성까지 보증하지 않는다.

A/B는 프롬프트가 같고 참고 자료 제공 여부만 다르다. C는 출처 표시와 경계 지시를 함께 바꿨고 D는 지시문을 짧게 바꿨다. 특정 문구 하나의 인과 효과를 분리한 실험은 아니다. RAG 본문·순서·기존 검색 결과는 그대로 재사용했고 신규 검색/임베딩은 없었다. 각 조건 실행 순서를 회전했다.

## 사람을 표현하는 데 무엇이 잘못됐는가

**A — 이미 있는 이력을 없다고 해석.** F01의 N0에는 주민센터를 포함한 세 장소 모두 예전에 여러 차례 향했다고 명시되어 있다. 그런데 네 F01 출력 모두 주민센터의 반복 지향 관찰이 없다고 설명한다. `F01A_A_0.json`의 “주민센터는 언급된 반복 지향이 없어”가 대표적이다. 최근 관찰이 없다는 사실과 과거 관찰 자체가 없다는 사실이 섞였다. `F05B_A_1.json`에는 계속 걷는다는 기록에서 “직진하는 점”도 추가됐다.

**B — 장소 이력을 경로·방향 이력으로 확대.** `F05A_B_0.json`은 “방향 유지나 경로 따름은 과거 이력이 있으나”라고 쓴다. 입력은 익숙한 장소를 향한 과거 관찰과 최근 머무름 관찰이며, 한 방향 유지 또는 익숙한 경로 추적이 관찰됐다는 내용은 없다. 가능성을 추정하는 문장과 과거 사실을 진술하는 문장을 구분해, 기술 검토에서는 개인 이력 추가로 판정했다. RAG 없는 조건도 개인 표상을 무조건 보존하지는 않았다.

이 B 판정은 독립 사람 검토가 필요하다. `F01A_B_0.json`의 “주민센터는 언급만 있고 최근 행동 근거가 없어”도 문제 소지가 있으나, 최근 시점에 한정한 축약으로 해석할 여지가 있어 명백 오류 수에 넣지 않았다. 위 1건을 사람이 가설적 표현으로 재분류하면 B의 hard gate 판정은 달라질 수 있다. 그렇더라도 현재 자료만으로 B가 더 나은 실제 움직임을 만든다고 확정할 수 없고, 후속 실험을 자동 재개하지 않는다.

**C/D — 목적지 미진술과 인식·의도 부재 혼동.** C의 `F05B_C_0.json`은 목적지를 말하지 않았다는 기록을 “특정 목적지를 향한 의도 없이”로 바꿨다. D의 `F05B_D_0.json`은 “현재 정보는 '목적지 인식 없음'”이라고 단정했다. 인식 여부는 입력으로 확인되지 않는다. D는 시장 쪽으로 향했다는 기록을 “시장 방향의 직진 또는 경로 추적이 관찰된 범위”로도 바꿨다. 출처 ID를 붙여도 이런 해석 확장은 사라지지 않았다.

C의 `F05A_C_0.json`은 문자열 내부 따옴표 오류로 기존 파서가 prior를 만들지 못했다. 응답은 finish_reason=stop이므로 토큰 한도로 잘렸다고 볼 근거가 없다. 다른 4개 출력은 코드펜스 또는 전략 합계 문제를 기존 파서/정규화가 처리했으며, 사용 가능으로 남겼다. 실패 출력도 12회 분모에서 빼지 않았다.

## 개인 차이가 수치로 전달된 부분

F01의 모든 사용 가능한 출력에서 최근 관찰된 시장 또는 공원에 상대적으로 높은 장소 가중치가 부여됐다. 장소 지향 정보를 읽는 기능은 일부 작동한다. 하지만 이는 단순한 합성 대조 사례이며 복잡한 개인 정보 해석이나 실제 위치 정확도를 입증하지 않는다.

F05의 최종 코드 처리 후 staying_put 평균은 다음과 같다. 실제 사람이 머무를 확률이 아니라 시뮬레이터에 넘기는 잠정 가중치다.

| 조건 | 가까이 머무름 A | 계속 걷기 B | 주의 |
|---|---:|---:|---|
| A | 0.181 | 0.125 | 각 2출력 |
| B | 0.150 | 0.075 | 각 2출력 |
| C | 0.233 | 0.075 | A는 1출력만 사용 가능, 직접 우열 비교 부적절 |
| D | 0.125 | 0.050 | 각 2출력 |

차이 방향은 기대와 맞지만 값의 크기에 정답을 설정하지 않았다. 머무름 관찰이 있다고 전략값을 무조건 최대화하는 모델을 우수하다고 판정하지 않는다. 코드상 staying_put이 실제 휴식 시간과 같은 개념인지도 별도 문제다.

반복 안정성도 완전하지 않다. B의 F01B landmark_seeking 최종값은 약 0.286과 0.100으로 달랐다. D의 같은 입력 direction_keeping은 0.600과 0.300이다. F06B에서는 선호 차이를 알 수 없다는 동일 입력인데, D가 두 반복 모두 시장·복지관 0.375, 공원 0.250을 부여했다. 반복해서 같은 값을 냈다고 근거에 충실한 것은 아니다.

D가 radius_level을 '상'으로 쓴 출력도 있었으나, 현재 실험의 코드 처리 후 반경 분포는 기존 개인 축 우선 정책에 따라 동일한 mu=0.095, sigma=1.48이다. 설명·원시 등급의 차이와 실제 보행 입력 차이를 구분해야 한다. 이 정책의 타당성은 이번 실험에서 재검증하거나 수정하지 않았다.

## 중단 결정과 다음 수정 방향

사전에 “개인 사실 추가·관찰 반전 한 응답이라도 있거나 12개 prior가 모두 사용 가능하지 않으면 해당 조건을 보행·후속 후보에서 제외”하기로 했다. 이 기준과 위 AI 기술 판정에 따라 네 조건 모두 제외했다. 후속 24회와 신규 OSMnx 재생은 실행하지 않았다. 오류 없는 일부 출력만 골라 좋은 경로를 그려 전체 조건의 성과처럼 제시하지 않았다.

다음에는 문구를 계속 추가하는 것보다 **개인 관찰과 전략을 연결하는 출력 구조**를 먼저 바꾸는 것을 권한다. 아래는 다음 실험의 설계 제안이며 구현·API 호출은 하지 않았다.

1. 같은 K 호출에서 관찰 사실, 시점, 미확인 정보, 행동 가설을 분리해 출력. 각 사실에 원문 N번호와 정확한 발췌를 붙이고, '계속 걷기'와 '직진', '목적지 미진술'과 '목적지 인식 없음'을 다른 항목으로 유지. 과거 이력을 따로 보존. 예전 K 추출→SAR 체인의 실패를 고려해, 사실 정리 단계를 하나 더 거쳤다는 이유만으로 신뢰하지 않음.
2. 각 prior 수정에 어떤 관찰/가설이 연결됐는지 추적 가능하게 출력. 시장 지향은 우선 장소 끌림의 근거로 다루고, 직진 전략을 높이는 근거와 구분. 입력에 없는 경로 관찰을 출력했다면 그대로 통과시키지 않음. 인용 일치 검사는 필요하지만 그것만으로 추론의 타당성이 보장되지는 않음.
3. 코드의 통계 기본값·반경 상한·개인 축 근거는 유지하면서, 관찰이 직접 지지하지 않는 축까지 임의로 바꾸는지 검사. LLM 수치가 “진짜 행동 확률”이라는 전제는 두지 않음. 기존 SAR보다 유리한 수치를 사후에 골라 기준으로 삼지 않음.
4. 결과를 보지 않고 정한 사람 검토 기준과 새 대조 사례를 준비한 뒤, 승인된 소규모 비교부터 진행. 통과하면 동일 OSMnx 도로·개인 입력·시드의 움직임으로 연결. 경로가 그럴듯하다는 평가와 실제 수색 정확도는 계속 구분.

이 제안은 K에 일반적인 치매 행동을 더 많이 말하게 하는 목적이 아니다. 같은 환경에서 **이 사람에 대해 알려진 차이만** 보행에 반영되고, 모르는 부분은 모르는 상태로 남게 하는 목적이다.

## 사용량·검증·한계

- K API 48회, HTTP/빈 응답 실패 0회, 재시도 0회. 사용 불가 JSON 1회도 사용량에 포함.
- 입력 71,736 + 출력 12,389 = 총 84,125토큰. API 보고 usage 기준이며 캐시 토큰을 다시 더하지 않음.
- SAR·임베딩·지도·연결 점검 추가 호출 0회, 신규 OSMnx 보행 0회.
- 원격 프로세스 경과 180.24초, 프로세스 CPU 0.549초. 대기 시간을 포함한 경과시간이며 GPU 시간·총 서버 청구시간이 아님.
- 지원 차수·API 단가·실청구액·외부 GPU 시간 미확인. 비용은 null로 보존하며 0원으로 쓰지 않음.
- 요청 시작/종료 및 자원 세션 총 98개 이벤트를 공용 원장에 event_id 기준 중복 없이 동기화.
- 동결 입력·프롬프트·runner SHA 확인, 48개 응답 ID와 원장 1:1 대응, 모든 요청의 종료 이벤트 확인. 조건 간 개인 입력 동일 확인.
- underlying 모델 revision은 미확인. 동일 K endpoint를 사용했고 별도 버전 조회 호출은 하지 않음.
- 실제 실종 경로 데이터 없음. 같은 작성자가 만든 소수 개발 사례, 반복 2회, AI 평가. 모델 출력의 개인 정보 충실성을 진단한 결과이며 임상적 행동 타당성·발견율·위치 정확도 결과가 아님.
- SAR 신규 호출은 없었으므로 SAR보다 K가 낫거나 못하다는 결론은 내리지 않음. 이전 실험은 배경 자료일 뿐 이번 RAG 효과 비교의 동시 대조군이 아님.

## 파일 안내

- `s1_outputs/`: 48개 원시 요청·응답·기존 코드 처리 후 prior. 합성 입력만 사용.
- `개인표상_검토기록.md`, `s1_review.json`: 전수 검토, 오류 인용, 해석이 애매한 사례.
- `s1_parameter_analysis.json`: 파라미터 평균·반복 차이. 누락 출력 분모 주의.
- `s1_selection.json`: 후보 없음, 후속 호출 금지 결정.
- `usage_events.jsonl`, `usage_summary.json`, `verification.json`: 원장·사용량·완료 검증.
- `run_status.json`: 현재 완료 상태. `manifest.json`과 `실험계획.md`의 실행 전 문구는 동결 명세 증거로 유지.
