# 개인화 알림 실험 v2 — 사전등록

이 문서는 **결과를 생성하기 전에** 확정한 가설·지표·성공 기준이다. 실행 이후
지표를 추가하거나 평가 구간을 바꾸지 않는다. 변경이 필요하면 이 문서를 고친
뒤 별도 커밋으로 남기고, 변경 시점 이전 결과는 폐기한다.

작성: 2026-08-13 / 대상: 본선 제안서 3장 근거

## 1. v1(PR #205)의 방법론적 결함 — 왜 다시 하는가

v1은 "동일 알림 면적에서 개인화(C)가 근거리 구역(D1) 밖 실제 위치를 더 자주
포함한다"를 주장했다. 재검증에서 다음 세 결함을 확인했다.

1. **주 지표가 사후 확정.** 2026-08-11 커밋 시점의 주 지표는 `D2 GTCR@60`
   (전체 층 C−B = +9.5%, 95% CI [−2.6%, 22.6%] — 0 포함)이었다. 유의하지 않은
   결과를 확인한 뒤 08-12 커밋에서 주 지표가 `D1 외부 포함률`로 바뀌었고,
   평가 시점(13개→4개)·정답 경로 구조·비교군·층 정의가 함께 변경됐으며
   신뢰구간 보고가 사라졌다.
2. **D1 경계가 우리 설정값.** `cells_within_k(start, 2)` = h3 res9 k-ring 2
   (19셀, 반경 약 800m)는 서비스 1차 경보 범위로 우리가 정한 미확정
   파라미터다. 평가 구간의 경계를 실험자가 조절할 수 있는 구조였다.
   (세 군에 동일 적용된 것은 116/116 시점에서 확인했다. 군별 편향은 없다.)
3. **주 지표에서 유의성이 나오지 않음.** res8 budget=7 기준 McNemar는
   전체 p=1.00·D1 밖 p=0.25이고, 동일 셀 수로 맞춰 비교하면 A/B/C의 포함률
   차이는 1~2%p로 승자가 면적 구간마다 바뀐다.

따라서 v1의 성능 우위 주장은 철회한다. v2는 아래 가설을 사전등록해 검증한다.

## 2. 가설

v1 데이터를 사후 분석하는 과정에서, **적중 여부와 독립인 예측 특성**에서
조건에 무관하게 일관된 차이를 관측했다. v2는 이를 사전등록 상태로 확증한다.

- **H1 (주가설).** 개인 정보를 주입한 예측(C)은 비개인화 예측(B)보다 확률질량을
  좁은 영역에 집중시킨다. 즉 상위 k셀 누적 질량이 더 크다.
- **H2 (동반가설).** H1의 집중은 정확도 손실을 대가로 하지 않는다. 즉 **동일한
  셀 예산**에서 C의 시간매칭 적중률은 B보다 낮지 않다(비열등).
- **H3 (효율).** H1·H2가 성립하면, 목표 신뢰도를 달성하는 데 필요한 알림 셀
  수가 C에서 더 적다.

H1이 서비스에서 갖는 의미: 알림 대상 셀을 좁힐 수 있다는 것은 곧 무차별
발송을 줄인다는 뜻이다. 다만 H1 단독은 "좁게 틀릴" 가능성을 배제하지 못하므로
H2와 함께 판정한다. **H2가 기각되면 H1이 성립해도 전체 결론은 실패로 본다.**

## 3. 주 지표 (실행 전 확정 — 추가·변경 금지)

| 구분 | 지표 | 정의 | 판정 |
|---|---|---|---|
| 주 | 집중도 | 각 시점 POA의 상위 3셀 누적 확률질량 | C > B, 부호검정 p<0.05 |
| 주 | 동일예산 적중률 | 상위 N셀 선택 시 정답 셀 포함 비율, N ∈ {5,10,15,20,25,30} | 전 구간에서 C ≥ B − 5%p |
| 부 | 효율 곡선 | 셀 수 대비 적중률 곡선 | 기술 통계로 보고 |
| 부 | 예측면 크기 | POA 지지 셀 개수 | 기술 통계로 보고 |

**평가 구간은 전체 시점이다. D1 안팎으로 나누지 않는다.** 층·행동유형별
분해는 보고하되 주 판정에는 쓰지 않는다(사후 절단 방지).

집중도의 k=3은 v1 관측에서 쓴 값을 그대로 승계한다. k=1·5·10 결과도 함께
보고하되 주 판정은 k=3으로 한다.

## 4. 검정 방법

- 같은 시나리오·같은 시점의 C와 B를 **짝지어** 비교한다(페어 설계).
- 집중도: 부호검정(이항 정확검정, 양측).
- 적중률: McNemar(이항 정확검정, 양측).
- 다중비교: 주 지표 2개에 대해 Bonferroni 보정(α = 0.025)을 적용한다.
- 표본이 작아 통계적 유의성이 확보되지 않을 경우, **"유의하지 않음"을 그대로
  보고한다.** 하위 구간을 추가로 탐색해 유의한 절단면을 찾지 않는다.

## 5. 실험 조건

- 페르소나: v1과 동일한 Mi:dm 12슬롯 실등록 10명(`persona_bank_manifest.json`).
  재등록하지 않는다(Mi:dm 호출 비용·재현성).
- 층: `consistent`/`neutral`/`counter` 균등 배치 유지. **결과가 나빠도 층
  비율을 바꾸지 않는다** — 실제 분포를 모르는 상태에서 균등이 중립적 선택이다.
- 정답 경로: v1과 동일하게 개인 정보와 독립적으로 생성(순환논법 방지).
- 비교군:
  - `B_generic_ai` — 나이·유형·집만 제공
  - `C_exaone_personalized` — Mi:dm 12슬롯 원본 Persona
  - `A_distance_only`는 확률 예측이 아니라 거리 감쇠값이므로 **집중도 비교에서
    제외**하고, 적중률 곡선에서만 참조 기준으로 표시한다.
- **공통 D1 예산을 부여하지 않는다.** 각 군은 자기 예측만으로 상위 N셀을
  고른다. v1에서 D1 19셀이 공통으로 들어가 군간 차이를 희석했다.
- 시드·도로망은 B/C 동일, 시나리오마다 순서 반전.

## 6. 성공/실패 판정

- **성공**: H1 유의(p<0.025) **그리고** H2 충족(전 예산 구간에서 C ≥ B − 5%p).
- **부분 성공**: H1만 유의. 이 경우 "예측을 좁히지만 정확도 우위는 미확인"으로
  기술하고, 성능 주장에는 쓰지 않는다.
- **실패**: H1 기각 또는 H2 위반. 이 경우 제안서에서 개인화 성능 주장을 빼고,
  개인화를 구현 사실로만 기술한다.

어느 경우든 결과를 그대로 보고한다. 실패 시 실험을 다시 설계해 유리한 결과를
찾지 않는다.

## 7. 측정하지 않는 것

실제 푸시 전달, 알림 열람, 시민 제보 전환, 실제 실종자 궤적, 발견 성공.
합성 경로 기반 파일럿이므로 현장 효율을 입증하지 않는다.
