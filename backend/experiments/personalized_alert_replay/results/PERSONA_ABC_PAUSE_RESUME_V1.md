# EXAONE 개인화 알림 A/B/C 합성 replay 결과

## 실험 설명

Mi:dm 온보딩으로 12개 슬롯을 모두 채운 합성 치매 노인 페르소나 10명을
구축하고, 각 페르소나를 사전등록 정보와 실제 이동 방향이 일치·중립·불일치하는
세 조건에 배치했다. 비교군은 A 거리 기준, B 개인 정보를 제거한 일반 치매
EXAONE 예측, C Mi:dm 페르소나를 주입한 EXAONE 예측이다. 정답 경로는 예측과
독립된 OSM 보행 경로로 생성했으며, 정지·은폐형은 이동하다 45~90분 사이에
멈춘 뒤 다시 이동하는 형태로 고정했다.

30개 시나리오를 계획했으나 `SP04-counter`는 재시도 후에도 EXAONE 응답 형식
검증을 통과하지 못해 사전에 정한 규칙대로 제외했다. 따라서 29개 시나리오의
0·45·90·135분, 총 116개 대응 시점을 분석했다. 세 군에는 H3 해상도 8의
7개 구역으로 같은 알림 면적 예산을 적용했다. 여기서 “알림 발송 구역 포함”은
해당 시점의 실제 위치가 알림 대상으로 선택된 구역 안에 있다는 뜻이며, 실제
Expo 푸시 전송·열람·시민 제보·발견 성공을 뜻하지 않는다.

## 결과

| 구분 | A 거리 기준 | B EXAONE 비개인화 | C EXAONE 개인화 |
|---|---:|---:|---:|
| 전체 116시점 포함 | 87.1% (101/116) | 87.9% (102/116) | 86.2% (100/116) |
| D1 밖 31시점 포함 | 51.6% (16/31) | 58.1% (18/31) | **61.3% (19/31)** |

전체 시점에서는 A·B·C의 알림 발송 구역 포함률이 86.2~87.9%로 유사했다.
반면 최초 근거리 구역 D1을 벗어난 31개 시점에서는 C가 A보다 9.7%p,
B보다 3.2%p 높았다. 즉 이 파일럿은 개인화가 알림 면적을 늘려 성능을 만드는
것이 아니라, 같은 면적을 근거리 밖의 실제 이동 위치 쪽으로 재배치할 가능성을
보여준다. 다만 합성 페르소나와 독립 생성 경로를 사용한 소규모 반복측정이므로
“개인화가 항상 우월하다”거나 “발견률이 향상됐다”고 해석할 수는 없다.
