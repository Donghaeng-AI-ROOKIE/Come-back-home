# 동일 면적 한도에서의 res8 타겟팅 비교

## 핵심 결과와 해석

같은 면적 한도로 구역을 선택하면 개인화가 항상 뒤지지는 않았다. 2km²에서 C는 B보다 2시점, 5km²에서는 3시점을 더 포함했고, 3km²에서는 같았다. 다만 1km²에서는 5시점을 덜 포함했다. 개인화의 이점은 면적에 따라 달라졌고, 뚜렷한 일관된 우위는 확인하지 못했다.

- 5km² 한도의 차이는 +2.78%p, 인물 단위 95% 구간은 [0.00, 5.56]%p다. 경계가 0이고 여러 한도를 탐색한 결과이므로 개인화 우위의 확증으로 표현하지 않는다.
- 목표 포함률 70·80·90%에 처음 도달한 시험 한도는 B/C 모두 각각 3·5·7km²로 같았다. 이 간격의 실험에서는 개인화가 더 작은 한도로 목표를 달성했다는 근거가 없다.
- 15·20km²에서는 모두 108/108을 포함했지만 C의 실제 사용 면적은 더 작았다. 후보 구역이 먼저 소진되는 효과를 포함하므로 두 방식이 정확히 같은 면적을 사용한 결과로 해석하지 않는다. 이 합성 표본의 100%는 새 사례의 100%를 뜻하지 않는다.
- 0.5km²에서는 이 지역의 셀 한 개도 한도에 들어가지 않아 모두 빈 선택이었다. 이 행은 성능 비교 근거가 아니다.

앞 운영형 분석의 큰 포함률 격차는 이번 면적 한도·확률합 순위 정책에서는 재현되지 않았다. 따라서 앞 결과만으로 개인화 예측 자체가 항상 열등하다고 판단할 수 없다. 반대로, 이번 비교에서는 누적 커버리지 선택·부모 점수 방식·참여도 문턱이 함께 바뀌었으므로 개선 원인을 문턱 하나로 확정할 수도 없다.

이번 결과로 현재 운영을 바꾸지는 않는다. 원인 구분이 필요하면 구역 점수 방식과 문턱을 하나씩 바꾸는 별도 비교를 미리 설계하고, 설정 채택은 독립 데이터로 검증해야 한다.

## 비교 목적

같은 면적 한도에서 개인화 C와 비개인화 B의 정답 포함률을 비교한다. 운영 정책을 그대로 재현하는 실험이 아니라 위치 순위 선정의 실익을 보는 후속 탐색이다.

## 고정 조건과 해석 범위

- 인물 9명·시나리오 27개·108시점. 입력 파일과 SHA-256은 summary.json에 기록했다.
- res9 확률을 res8 부모별로 합산해 내림차순 정렬했다. 동점은 셀 ID 순으로 처리했다.
- 참여도 문턱과 누적 80% 절단을 적용하지 않았다. 두 요소와 구역 점수 방식이 함께 바뀌므로 이전 실험과의 차이를 문턱 효과 하나로 해석하지 않는다.
- 면적 한도 0.5·1·2·3·5·7·10·15·20km²와 목표 포함률 70·80·90%를 실행 전에 정했다.
- 셀을 쪼개지 않고 순위 접두부만 선택했다. 다음 셀이 한도를 넘으면 멈추며, 확률이 없는 구역으로 채우지 않았다. 따라서 동일한 것은 면적 한도이고 실제 사용 면적은 다르다.
- 인물 단위 대응 부트스트랩 10,000회, seed=20260924, 점별 95% 구간. 9명 소표본·반복 비교에 대한 탐색적 결과이며 비열등 판정은 하지 않는다.
- 과거 결과를 본 동일 데이터의 후속 분석이므로 독립 검증이 아니다. 새로운 설정 채택에는 별도 데이터 검증이 필요하다.

## 목표 포함률에 처음 도달한 시험 한도

| 목표 포함률 | B 한도 / 실제 평균 면적 | C 한도 / 실제 평균 면적 |
|---|---|---|
| 70% | 3 / 2.541km² | 3 / 2.541km² |
| 80% | 5 / 4.574km² | 5 / 4.574km² |
| 90% | 7 / 6.606km² | 7 / 6.578km² |

이는 미리 정한 한도 중 처음 도달한 지점이다. 정확히 같은 포함률을 맞춘 최소 면적 추정이 아니며, 한도 사이를 보간하거나 목표에 맞춰 재조정하지 않았다.

## 재현

backend에서 `python -B -X utf8 -m experiments.personalized_alert_replay.analyze_equal_area_targeting --output-dir <새 결과 경로>`를 실행한다. 기존 출력 경로는 덮어쓰지 않는다.
실제 기기·푸시·모델 호출은 없으며 기존 분석 코드와 운영 설정은 변경하지 않았다.
