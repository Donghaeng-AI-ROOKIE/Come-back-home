# 타겟팅 분석 결과 해석

## 결론

현재 설정에서 res8은 개인화·비개인화의 예측 차이를 발송구역에 더 많이 반영했다. 그러나 **개인화의 발송면적 감소와 정답 위치 포함률 하락이 함께 관측됐다.** 따라서 “정확도를 유지하면서 알림 범위를 줄였다”거나 “res8 전환에 성공했다”고 결론낼 수 없다.

대표적으로 res8·normal에서 C는 B보다 발송면적이 27.62% 작았지만, 정답 포함률도 50.00%에서 39.81%로 10.19%p 낮았다. 운영 해상도는 res7 그대로이며 실제 푸시는 전송하지 않았다.

## 무엇을 측정했고 어떻게 비교했나

B는 비개인화, C는 개인화다. 동일 시나리오·시점의 결과를 짝지어 비교하고, 전체 평균과 인물별·참여도별 결과를 함께 보고한다. 참여도 세 등급을 임의 비율로 합치지 않는다.

해상도 간 비교의 주 지표는 셀 개수가 아니라 **각 H3 셀의 실제 면적을 더한 값**이다. 면적 감소율은 B의 총면적을 기준으로 계산하며, 음수는 증가를 뜻한다. 시점에 걸쳐 합산한 면적은 고유 지리적 면적이 아니다.

정답 위치는 저장된 좌표에서 res7·res8 셀로 직접 변환했다. 정답 res9의 부모를 사용하는 대리 방식 결과도 별도로 남겼다.

신뢰구간은 인물 9명을 묶음 단위로 재표집하는 대응 부트스트랩(10,000회, seed=20260924)으로 계산했다. 뽑힌 인물의 모든 시나리오·시점을 함께 포함했으며, 108시점을 독립 표본으로 재표집하지 않았다. 95% 백분위 구간은 소표본 기반 탐색적 결과이고 다중비교 보정은 하지 않았다. 허용할 포함률 하락폭은 미설정이므로 비열등성이나 정확도 유지의 성공 판정을 내리지 않는다.

주 비교는 res8의 B 비개인화 대 C 개인화이며, res7과의 비교는 해상도 효과를 확인하기 위한 보조 분석이다. 아래 표는 설계안의 8개 지표를 res8·normal 기준으로 연결한 것이다. 전체 해상도·참여도·인물별 수치는 `REPORT.md`에 있다.

| 번호 | 지표 | 확인할 내용 | res8·normal 결과 |
|---:|---|---|---|
| 1 | 전체 res9 예측 셀 수·면적 | 입력 예측구역의 규모 | B 104.04개 / 7.553km² → C 70.47개 / 5.116km² |
| 2 | 선택된 res9 셀 수·면적 | 부모 변환 전 알림용 구역 | B 27.62개 / 2.005km² → C 12.30개 / 0.893km² |
| 3 | 문턱 적용 전 부모 셀 수·면적 | 부모 변환 후 구역 | B 9.27개 / 4.710km² → C 5.01개 / 2.546km² |
| 4 | 문턱 적용 후 발송구역 수·면적 | 최종 선정 지역 | B 1.94개 / 0.988km² → C 1.41개 / 0.715km² |
| 5 | 정답 위치 포함 여부·포함률 | 정답 위치의 가상 기기가 대상에 포함되는지 | B 54/108 (50.00%) → C 43/108 (39.81%) |
| 6 | 비개인화 대비 개인화의 단계별 면적 감소율 | 개인화 효과가 어느 단계까지 유지되는지 | 전체 res9 32.26% → 선택 res9 55.48% → 부모 45.95% → 최종 27.62% |
| 7 | 비개인화·개인화의 정답 포함률 차이 | 범위 축소와 함께 놓침이 증가하는지 | C−B -10.19%p, 95% 구간 [-23.15, -1.85]%p |
| 8 | 선택 res9는 다르지만 최종 발송구역은 같은 시점 비율 | 예측 차이가 발송 단계에서 사라지는 빈도 | 31/108 (28.70%). res7·normal은 74/108 (68.52%) |

## 참여도에 따라 효과가 달랐다

| 참여도 | C 발송면적 감소 | B 정답 포함률 | C 정답 포함률 | C−B |
|---|---:|---:|---:|---:|
| high | 46.84% | 69.44% (75/108) | 46.30% (50/108) | -23.15%p |
| normal | 27.62% | 50.00% (54/108) | 39.81% (43/108) | -10.19%p |
| low | 10.07% | 41.67% (45/108) | 37.04% (40/108) | -4.63%p |

normal의 면적 감소율 95% 구간은 [8.83%, 41.48%], 포함률 차이 구간은 [-23.15, -1.85]%p다.
high에서도 포함률 차이 구간 전체가 음수다. low의 구간은 0을 포함하나 이는 정확도 유지의 입증이 아니다.
9명 인물 단위 탐색적 부트스트랩 구간이며 전체 조건에 대한 다중비교 보정은 하지 않았다.
허용 하락폭이 미설정이므로 통계적 비열등 판정은 하지 않았다.

## 예측 차이가 발송 단계에서 사라지는 현상은 확인됐다

B/C 선택 res9 집합은 108시점 모두 달랐다. 그런데 최종 발송구역 집합이 같았던 수는 다음과 같다.

| 참여도 | res7 | res8 |
|---|---:|---:|
| high | 40/108 (37.04%) | 11/108 (10.19%) |
| normal | 74/108 (68.52%) | 31/108 (28.70%) |
| low | 91/108 (84.26%) | 49/108 (45.37%) |

즉 res8에서 차이가 덜 사라지는 것은 확인했다. 하지만 차이가 더 잘 반영되는 것과 정답을 더 잘 포함하는 것은 별개다.
위 수치는 부모 변환과 문턱 적용 후의 결합 결과이지 부모 변환만의 단독 효과는 아니다.

## 면적이 줄어도 포함률이 유지되지는 않았다

normal 개인화 C는 평균 발송면적이 3.887 → 0.715km²로 81.60% 줄었지만,
정답 포함률도 72.22% (78/108) → 39.81% (43/108)로 32.41%p 낮아졌다.
같은 조건에서 B도 포함률이 81.48% → 50.00%로 낮아졌다.

| normal의 단계 | B 정답 포함 | C 정답 포함 |
|---|---:|---:|
| 누적 80%로 선택한 res9 | 86/108 | 67/108 |
| 문턱 전 res7 부모 | 106/108 | 98/108 |
| 문턱 후 res7 | 88/108 | 78/108 |
| 문턱 전 res8 부모 | 96/108 | 82/108 |
| 문턱 후 res8 | 54/108 | 43/108 |

개인화의 포함률 차이는 부모 변환 이전에도 존재한다. 또한 res8 문턱 적용에서 추가 탈락이 관측된다.
따라서 결과 악화를 “res8이 나빠서” 또는 “문턱 하나 때문”으로 단정하지 않는다.
분포가 집중될 때 최고 셀 대비 상대 점수가 어떻게 변하는지는 후속 원인 분석 대상이다.
이번 실행에서는 결과에 맞춰 문턱이나 예산을 조정하지 않았다.

## 해석 기준에 따른 판정

| 관측 결과 | 해석 기준 | 이번 결과에 적용 |
|---|---|---|
| 개인화의 발송면적 감소, 정답 포함률 유지 | 개인화의 발송 효율 개선을 지지 | 전체 집계에서는 확인하지 못했다. res7·res8의 세 참여도 모두 C 포함률의 관측값이 B보다 낮았다. 인물별 일부 관측값이 같다는 사실만으로 통계적 유지 판정을 내리지 않는다. |
| 면적과 정답 포함률 모두 감소 | 범위 축소와 놓침 증가 사이의 트레이드오프(하나를 줄이면서 다른 성능을 잃는 관계) | 이번 전체 결과가 해당한다. res8·normal은 면적 27.62% 감소와 포함률 10.19%p 하락이 함께 나타났다. |
| 면적 감소가 없거나 증가 | 해당 정책에서 축소 효과 확인 불가 | 전체 평균 면적은 모든 조건에서 감소했지만 인물별로 예외가 있다. res8·normal의 SP02는 면적이 50.00% 증가했고 포함 수는 10/12로 같았다. |
| 일부 참여도·인물에서만 개선 | 개선 조건과 실패 조건을 구분해서 보고 | res8·normal의 SP03은 면적 47.07% 감소·포함 7/12 유지, SP05는 22.48% 감소·4/12 유지, SP06은 14.30% 감소·5/12 유지였다. 반면 SP07은 면적 47.83% 감소와 함께 포함 수가 8/12에서 1/12로 낮아졌다. 모두 소표본 관측 결과다. |
| res7보다 res8에서 개인화의 면적 감소 효과가 커짐 | res8이 개인화 차이를 더 반영한다는 근거 | 같은 해상도 내 B 대비 C 감소율이 high 37.75%→46.84%, normal 20.27%→27.62%, low 8.13%→10.07%로 커졌다. 이는 관측된 패턴이며 해상도 간 효과 차이 자체의 유의성은 별도 검정하지 않았다. 정답 포함률 개선을 뜻하지 않는다. |

전체 평균만으로 효과를 단정하지 않고, 참여도별 결과와 인물별 예외를 함께 보고해야 한다. 인물별 사례는 조건당 12시점이며, 관측상 포함 수가 같다는 사실은 통계적 정확도 유지의 증명이 아니다.

## 계산 검증과 해석 범위

- 기존 분석의 res7 정답 부모 대리 방식으로 계산한 포함 수와 구역 수는 새 분석과 B/C·참여도 6조건 모두 일치했다.
- 주 결과는 폰처럼 정답 좌표에서 직접 res7/res8 셀을 계산한다.
- 정답 res9의 계층 부모와 좌표 직접 변환이 다른 시점이 res7에서 6개, res8에서 10개 있었다.
  이는 H3 경계의 차이이며 표본 수는 군·참여도로 중복 합산하지 않았다. 대리 방식의 포함 수는 summary.json의 proxy_hits에 남겼다.
- 500셀 상한에 도달한 경우는 없었다. 입력 제외, 확률 재정규화, 모델 재호출은 없었다.

실제 기기 수·전달·열람·발견은 측정하지 않았다. 면적 감소를 실제 수신자 감소로 바꾸어 표현하지 않는다. 시점별 포함 여부는 `snapshots.jsonl`의 `truth_included`, 단계별 셀·면적은 `stages`, 인물별 수치는 `summary.json`의 `by_profile`에 있다.

## 다음 결정

이 결과만으로 운영 res8 전환을 확정하지 않는다. 다음 실험이 필요하면 먼저 목표 포함률/허용 손실과
평가 정책을 정하고 별도 데이터 또는 사전에 고정한 절차로 평가한다. 이 데이터에 맞춘 문턱 조정은 탐색으로 명시해야 한다.
실제 수신자 감소는 동일 기기 분포·참여도 기준의 별도 실험이 필요하다.
운영 전환 후속 사항은 TARGETING_RESOLUTION_PLAN.md에 정리했다.
