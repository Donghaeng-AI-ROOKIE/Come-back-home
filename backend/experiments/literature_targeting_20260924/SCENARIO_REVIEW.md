# 시나리오 검토 예시

개발용 6명의 사례다. 평가용 결과는 모델 설정 선택에 사용하지 않는다.
실제 환자 또는 실제 거주지가 아닌 도로망 위 합성 인물·사건이다.

## dev-P01

나이 72세. 합성 치매 유형. 개인화에는 사전 산책 경로와 등록 목적지를 제공한다.
마지막 목격 좌표: {'lat': 37.6108827, 'lng': 127.0141558}. 신고까지 10분.
사전등록 목적지: {'lat': 37.6167282, 'lng': 127.0265798}. 실제 공원/거주지로 확인한 지점이 아니다.

|---|---:|---|---|
| routine_related | 1676.1 | None | 37.613099, 127.022468 |
| route_departure | 1697.7 | 3836538759 | 37.608808, 127.022381 |
