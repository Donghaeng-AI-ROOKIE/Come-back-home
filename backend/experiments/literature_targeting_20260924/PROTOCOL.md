# 문헌 기반 합성 타겟팅 실험 v1

## 질문과 현재 단계

개인의 익숙한 경로 정보가 이동과 관련되는 조건에서, 동일 발송 정책의 개인화 C가 비개인화 B보다 발송면적을 줄이고 정답 포함률을 높이는가?

현재 작업은 새 시나리오와 합성 정답을 생성하고 검증하는 단계다. 예측 실행과 효과 검증 완료를 뜻하지 않는다. 기존 네 실험, V2, 운영 코드는 보존한다. 브랜치는 experiment/alert-targeting-res8 그대로 사용한다.

## 기존 실험과의 차이

| 요소 | 기존 타겟팅 재분석 | 이번 설계 |
|---|---|---|
| 입력 | 저장된 9명 27시나리오 예측 | 새 12명 36시나리오의 입력과 정답부터 고정 |
| 정답 시간 | 신고 후 0/45/90/135분 | 0/15/30/60분, 마지막 목격은 신고 10분 전 |
| 지역 분할 | 기존 동일 자료 재사용 | 개발용 정릉 인근 도로망, 평가용 서강 인근 도로망 |
| 개인화 정보 | 기존 저장된 페르소나 | 동일 인물의 사전등록 경로와 목적지, 보호자 설명 |
| 결과 | 이미 실행한 결과 | 아직 새 예측 없음 |

새 시점과 표본이므로 기존 수치와 직접적인 전후 개선율을 계산하지 않는다.

## 표본과 정답

지역별 6명, 인물별 세 조건, 조건별 4시점: 총 36시나리오 144개 대응 시점. 개발 18시나리오 72시점, 평가 18시나리오 72시점이다. 같은 인물의 세 사건은 별개의 합성 사건이다. 각 조건에서 B/C에 동일 입력을 쓰며 미래 조건 이름과 이동 경로는 숨긴다.

주 분석은 사전에 정한 routine_related 조건이다. route_departure와 unrelated_direction을 함께 보고하여 적용 범위를 확인한다. 세 조건 전체 평균은 인위적인 균등 혼합이며 실제 실종자 평균 효과가 아니다. 개발용 결과는 조정에 사용할 수 있으나 평가용 정답으로 프롬프트/정책을 조정하지 않는다. 평가용도 합성 규칙을 공유하므로 실제 데이터 독립 검증을 대신하지 않는다.

정답 생성기는 예측기·LLM·Phase2 전략을 가져오지 않는다. 저장된 OSM 도로망과 별도 경로 규칙만 사용한다. 곡선 도로는 저장된 edge geometry를 따라 보간한다. 문헌 기반과 연구자 가정은 SOURCES.md에 구분한다. 경로 길이/분기 존재만으로 생성 가능성을 검사하고, H3 경계나 예측 성공 여부를 보고 사례를 고르지 않는다. 도착 뒤 정지 가정의 영향을 보기 위해 전체 결과와 이동 중 시점 결과를 따로 보고한다.

## 입력 분리

`*_inputs.json`: 예측기에 전달 가능한 B/C 자료만 저장한다. B와 C의 나이, 유형, 집, 마지막 위치, 경과 시간, 도보 조건, 지도는 같다. C만 사전 생활 이력을 받는다. 동일 인물의 사건별 C 프로필도 같다. 속도 가정, 조건명, 미래 목적지/이탈 시점은 입력에 넣지 않는다.

`*_truth.json`: 평가 전용. 예측 모듈에서 열지 않는다. 모델 호출 어댑터에는 inputs 경로만 전달한다. 어댑터는 실제 프로젝트에서 쓰는 필드에 매핑하고, 전체 경로를 모델이 소비하지 못한다면 임의로 소비했다고 주장하지 않는다. 모델에 전달된 최종 프롬프트와 필드 보존 여부를 기록해야 한다.

## 고정할 비교와 판정

- 주 정책: res8, 누적 80% res9 선택, 500셀 제한, 부모 최고 상대확률, normal 문턱. high/low와 res7은 보조 결과다. 실제 실행 설정·모델 버전·프롬프트·시드는 예측 전에 추가 고정한다.
- B/C는 같은 예측 시드와 반복 횟수를 쓰며 순서를 교차한다. 정답을 보지 않고 예측하고, 실패는 숨기지 않는다. 스텁 응답을 실제 EXAONE 예측으로 대체하지 않는다.
- 기존 설계의 8개 지표(전체 res9, 선택 res9, 문턱 전 부모, 최종 구역의 수/면적, 포함 여부/비율, 단계별 감소율, 포함률 차이, 최종 동일 구역 비율)를 유지한다.
- 주 결과는 B 대비 C 발송면적 감소율과 C-B 포함률 차이다. 두 관측값이 모두 양수인 것과 통계적으로 뒷받침되는 것은 구분한다. 주 조건에서 두 값의 인물 단위 95% 구간 하한이 모두 0보다 클 때에만 합성 조건 내 동시 개선 근거로 표현한다. 작은 표본 때문에 판정되지 않을 수 있다.
- 인물 단위 대응 부트스트랩 10,000회, seed 20260924. 시점이 아닌 인물을 묶어 추출한다. 조건별/인물별 결과와 움직이는 시점만의 결과도 함께 제시한다. 보조 조건을 사후 주 결과로 바꾸지 않는다.
- 같은 포함률 또는 유의하지 않은 차이를 유지의 증거로 쓰지 않는다. 비열등 허용폭은 정하지 않았으므로 비열등 주장은 하지 않는다.

## 실행 순서

1. 생성 및 검증 후 manifest로 파일과 도로망 해시 고정.
2. inputs만 읽는 안전한 오프라인 모델 어댑터를 준비하고 실제 입력 필드와 예측 설정 고정.
3. 개발용 예측으로 실행 가능성 확인. 실패/폴백을 기록하고 중간 결과 저장 및 재개 지원.
4. 설정 고정 뒤 평가용 예측 실행, 이후 truth와 결합해 타겟팅 평가.

기존 remote_persona_abc 러너는 신고 API를 통해 실제 알림 경로에 진입할 수 있으므로 새 데이터에 그대로 호출하지 않는다. 로컬 예측 경로나 알림 억제가 보장된 격리 환경을 사용한다. 이번 데이터 생성에는 모델 호출·신고·푸시가 없다. 프로토콜 변경 시 새 버전으로 저장하고 기존 고정 데이터를 덮어쓰지 않는다.
