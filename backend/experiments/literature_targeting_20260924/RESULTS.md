# 문헌 기반 합성 타겟팅 실험 결과

이 결과는 기존 V2 예측 결과를 재사용하지 않고, 문헌 기반으로 만든 새 합성 시나리오에 대해 B/C 예측을 새로 실행한 뒤 res7/res8 타겟팅 분석을 적용한 것이다. 신고 API, 실제 푸시, 실제 기기 수신자는 사용하지 않았다.

## 실행 범위

- 개발 split: 6명, 18개 사건, 72개 대응 시점, B/C 36개 arm 완료.
- 평가 split: 6명, 18개 사건, 72개 대응 시점, B/C 36개 arm 완료.
- 주 비교: evaluation split, `routine_related/all_times`, res8, normal 참여도.
- 불확실성: 인물 단위 cluster bootstrap 10,000회.

## 사전 지정 주 비교 결과

평소 경로와 정답이 맞는 조건에서 res8 normal을 비교했다.

| 지표 | B 비개인화 | C 개인화 | C-B 또는 감소율 |
|---|---:|---:|---:|
| 전체 res9 평균 면적 | 4.891 km2 | 3.406 km2 | +30.35% 감소 |
| 선택 res9 평균 면적 | 1.300 km2 | 0.634 km2 | +51.28% 감소 |
| 문턱 전 부모 평균 면적 | 3.126 km2 | 1.605 km2 | +48.65% 감소 |
| 최종 발송 평균 면적 | 0.803 km2 | 0.845 km2 | -5.26% 감소 |
| 정답 포함률 | 9/24, 37.50% | 21/24, 87.50% | +50.00%p |
| 선택 res9 다름, 최종 구역 동일 | 전체 24시점 | 7시점 | 29.17% |

95% 구간은 다음과 같다.

- 최종 발송면적 감소율: -5.26% [-24.99, +9.30].
- 정답 포함률 차이: +50.00%p [+29.17, +66.67].
- 두 지표의 95% 구간 하한이 모두 양수라는 성공 기준: False.

## 해석

개인화는 의도한 대로 예측 확률을 더 좁은 res9 영역에 집중시켰고, res8 부모 구역 단계까지는 그 차이가 유지됐다. 하지만 참여도 문턱을 적용한 최종 발송구역에서는 평균 면적이 줄지 않았다. 주 비교 기준으로는 "정답 포함률은 개선됐지만 발송면적 감소는 입증하지 못했다"가 결론이다.

전체 균등 혼합에서도 같은 패턴이 나온다. res8 normal에서 개인화는 포함률을 28/72에서 40/72로 올렸지만, 최종 발송 평균 면적은 0.767 km2에서 0.859 km2로 커졌다. 선택 res9와 부모 구역은 줄어도 마지막 문턱 통과 셀 조합에서 발송구역이 다시 커질 수 있다는 점이 확인됐다.

res8 자체는 res7보다 최종 발송면적을 크게 줄인다. 예를 들어 주 비교의 C arm에서 res7 normal 대비 res8 normal 최종 발송면적은 약 84.96% 작고, 포함률 차이의 95% 구간은 -12.50%p에서 +25.00%p다. 다만 이것은 해상도 변경 효과이지, 개인화가 비개인화보다 발송면적을 줄인다는 증거는 아니다.

## 한계

이 실험은 합성 사례다. 실제 발생 빈도, 실제 기기 분포, 실제 수신자 수, 푸시 열람, 제보, 발견 성공은 측정하지 않았다. 현재 프로젝트 예측 경로에 전체 산책 경로 좌표를 전달하는 동등한 입력이 없어, C arm은 전체 경로 개인화가 아니라 목적지와 보호자 설명 개인화로 해석해야 한다.
