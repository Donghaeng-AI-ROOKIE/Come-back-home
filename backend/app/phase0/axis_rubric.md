# 축 점수 기준표 (0.1~0.9 행동 앵커)

작성: 2026-07-16 / 상태: **공통 3축·치매 4축 = 임의 초안(회의 합의 대상)**, 발달 4축 = 팀 확정본 원문.
팀원이 공통·치매 기준표를 정리해오면 이 파일을 업데이트한다.

채점 대상 = 한 사람당 축 7개.

- 치매: 공통 3 + 치매 특화 4 (route_environment_familiarity 포함)
- 발달장애: 공통 3 + 발달 특화 4
- lost_behavior·dementia_wandering_pattern 은 점수 없는 관찰 지표(반응 방향 → 전략 확률)라 이 문서에 없음.

## 축 방향 요약 (P1 프롬프트·정답표에 반드시 명시)

| 축 (axis_field) | 방향: 0.9의 의미 |
| --- | --- |
| mobility_transport_capacity | 이동 능력 큼 (수색 반경 확장 — **위험 아님**) |
| hazard_awareness_vulnerability | 위험 인식 낮음 (취약) |
| communication_approach_vulnerability | 발견·구조 어려움 (취약) |
| route_environment_familiarity | 이동이 정해진 경로로 수렴 (예측력↑ — **위험 아님**) |
| autobiographical_destination_pull | 과거 장소 지향이 실종과 반복 연결 (강함) |
| wayfinding_error_recovery_deficit | 길찾기·복귀 손상 심함 (취약) |
| distress_induced_movement_reactivity | 불안이 실제 이탈로 전환됨 (강함) |
| preferred_target_seeking | 선호 대상이 실종과 반복 연결 (강함) |
| aversive_context_escape | 회피가 실제 이탈로 전환됨 (강함) |
| transition_routine_disruption | 전환 상황이 실종과 반복 연결 (취약) |
| elopement_pattern_consistency | 이탈 패턴 고착 (개인화 가중↑ — 위험 크기보다 예측력) |

## 공통 사다리 구조 (발달 4축에서 역추출, 전 축 공통 원칙)

0.1 영향 없음 → 0.3 경향은 보이지만 이동 없음 → 0.5 실제 이동·사건 1회 이상 → 0.7 반복 또는 고위험 → 0.9 실제 실종과 반복 연결.
(능력·예측성 축은 같은 사다리를 "능력/정형성의 크기" 순으로 적용)

**판정 규칙** (파일럿 발견 반영, 2026-07-16): 한 사람에게 여러 단계의 근거가
공존하면(예: 신원은 잘 말하는데 유인에 따라감) 발견·구조를 더 어렵게 만드는 쪽,
즉 **더 높은 단계를 우선**한다. 능력·예측성 축(이동·교통, 경로 친숙성)은 반대로
실제 확인된 **최고 수준의 능력·정형성**으로 판정한다.

# 공통 3축 (치매·발달 공용 — 유형 중립 문구) [초안]

## ① 이동·교통 능력 (mobility_transport_capacity) — 몸축

| 점수 | 기준 |
| --- | --- |
| 0.1 | 보조기구·부축 없이는 단독 보행이 어렵고 집 주변을 벗어나기 힘듦 |
| 0.3 | 집 주변 짧은 거리는 혼자 걷지만 오래 걷지 못하고, 대중교통은 혼자 이용하지 못함 |
| 0.5 | 30분 이상 쉬지 않고 걸을 수 있고 동네 범위를 혼자 다니지만, 대중교통은 혼자 이용하지 못함 |
| 0.7 | 장시간·장거리 보행이 가능하거나, 익숙한 노선의 버스·지하철을 혼자 탄 경험이 있음 |
| 0.9 | 보행 제한이 거의 없고 대중교통(또는 차량)을 혼자 자유롭게 이용함 |

- 0.5→0.7 경계 = 대중교통 단독 이용 여부 (비연속 이동으로 반경 급확장 — 이 축 최대 분기점)
- "30분" 숫자 앵커는 슬롯 answer_example 출처, Koester 프로파일 기준 조정 협의 대상

## ② 환경 위험 취약성 (hazard_awareness_vulnerability) — 마음축

| 점수 | 기준 |
| --- | --- |
| 0.1 | 차도·물가·계단 등 위험을 스스로 알아보고 피함 (신호 준수 포함) |
| 0.3 | 대부분의 위험을 인식하지만, 서두르거나 주의가 흐트러지면 놓치는 경우가 있음 |
| 0.5 | 특정 유형의 위험(신호, 물가, 계단 중 일부)을 일관되게 인식하지 못함 |
| 0.7 | 대부분의 위험을 인식하지 못해 외출 시 보호자의 상시 개입이 필요함 |
| 0.9 | 위험 인식이 거의 없고, 실제 위험 상황(차도 진입·물가 접근 등)이 발생한 적 있음 |

## ③ 의사소통·접근 취약성 (communication_approach_vulnerability) — 마음축

| 점수 | 기준 |
| --- | --- |
| 0.1 | 이름·주소·연락처를 말할 수 있고, 낯선 사람이나 경찰에게 먼저 도움을 요청할 수 있음 |
| 0.3 | 먼저 도움을 요청하지는 못하지만, 질문하면 주소나 보호자 연락처 등 집으로 인계할 수 있는 정보가 나옴 |
| 0.5 | 호명·질문에 반응은 하지만 나오는 신원 정보가 이름 정도뿐이라 보호자 연결이 안 됨 |
| 0.7 | 낯선 사람·경찰의 접근에 반응하지 않거나 자리를 피해서 상호작용 자체가 어려움 |
| 0.9 | 접근 시 도망가거나 숨는 반응이 실제로 목격됐거나, 유인(태워준다 등)에 따라간 사례가 있음 |

- 0.3/0.5 경계 = 집으로 인계 가능한 정보(주소·연락처)가 나오는가 (파일럿 발견 1 반영)
- 혼합 프로필(신원 전달 가능 + 회피/유인 공존)은 아래 판정 규칙대로 높은 단계 우선 (파일럿 발견 2 반영)

# 치매 4축 [초안]

## ① 익숙 경로·환경 친숙성 (route_environment_familiarity) — 마음축

| 점수 | 기준 |
| --- | --- |
| 0.1 | 혼자 나가는 단골 목적지나 정해진 경로가 없음 (단독 외출 자체가 없는 경우 포함) |
| 0.3 | 혼자 나가긴 하지만 목적지·경로가 매번 다르고 일정하지 않음 |
| 0.5 | 단골 목적지가 1~2곳 있고 대체로 비슷한 길로 다님 |
| 0.7 | 목적지·경로·방향이 고정되어 있고, 그 익숙한 길 위에서는 헤매지 않음 |
| 0.9 | 거의 모든 단독 이동이 동일한 경로·목적지로 수렴하고, 과거 실종 시에도 그 경로·목적지 주변에서 발견됨 |

## ② 자전적 기억 기반 목적지 (autobiographical_destination_pull) — 마음축

| 점수 | 기준 |
| --- | --- |
| 0.1 | 과거 장소(옛집·직장·고향 등)를 향한 반복 발화나 지향이 거의 없음 |
| 0.3 | 과거 장소를 그리워하거나 가고 싶다는 말은 하지만 실제로 가려는 행동은 없음 |
| 0.5 | 과거 장소로 실제 가려는 시도(나가려는 행동)가 목격된 적 있음 |
| 0.7 | 특정 과거 장소를 향한 시도가 반복되거나, 본인을 그 시절로 인식함(지금 집을 남의 집으로 여기는 등) |
| 0.9 | 실제 실종·발견 위치가 동일한 과거 장소와 반복적으로 연결됨 |

- 발달 ①(관심·선호 대상 접근성)과 평행 구조 — 대상만 선호 대상 → 자전적 기억 장소

## ③ 길찾기 오류·경로 회복 취약성 (wayfinding_error_recovery_deficit) — 마음축

| 점수 | 기준 |
| --- | --- |
| 0.1 | 익숙한 동네에서 길을 잃는 일이 거의 없음 |
| 0.3 | 가끔 길을 잘못 들지만 스스로 알아차리고 혼자 되돌아옴 |
| 0.5 | 잘못 든 것을 알아차리기는 하지만 혼자 돌아오지 못하고 도움이 필요함 |
| 0.7 | 잘못 간 것을 스스로 알아차리지 못하고, 목적지를 잊거나 아는 건물을 못 알아보는 일이 반복됨 |
| 0.9 | 집 바로 근처에서도 길을 잃고, 실제로 돌아오지 못해 신고·수색으로 이어진 적 있음 |

- 0.3/0.5 경계 = 자각은 되나 복귀 불가, 0.5/0.7 경계 = 자각 자체 상실
  (전략 분기와 대응: 자각 가능 → backtracking, 심한 혼란 → random walk)

## ④ 정서적 불편에 따른 이동 반응성 (distress_induced_movement_reactivity) — 마음축

| 점수 | 기준 |
| --- | --- |
| 0.1 | 불안하거나 초조할 때도 이동 행동이 거의 달라지지 않음 |
| 0.3 | 불안·초조를 표현(안절부절·화내기)하지만 자리를 떠나지는 않음 |
| 0.5 | 불안하거나 의심하는 상황에서 자리를 피하거나 서성이는 등 이동 변화가 목격된 적 있음 |
| 0.7 | 불안·피해 의심·돌봄 저항 상황에서 집이나 보호 범위를 벗어나려 함 |
| 0.9 | 같은 불안·의심 상황에서 실제 실종 또는 반복 이탈이 발생한 적 있음 |

- 점수는 "이동으로 전환되는 강도"만 잰다. 반응 방향(도망/숨기/서성임/멈춤)은 점수와 별개의
  관찰 지표 — 점수만으로 회피 장소 예측 금지 (slots.py why 명시)

# 발달장애 4축 [팀 확정본 — 원문 유지, 임의 수정 금지]

## ① 관심·선호 대상 접근성 (preferred_target_seeking)

| 점수 | 기준 |
| --- | --- |
| 0.1 | 선호 대상 때문에 이동 방향을 바꾼 적이 거의 없음 |
| 0.3 | 관심을 보이지만 보호자 범위를 벗어나지는 않음 |
| 0.5 | 선호 대상으로 이동하거나 보호자와 분리된 경험이 있음 |
| 0.7 | 특정 대상을 향해 반복적으로 이탈함 |
| 0.9 | 실제 실종이 동일한 선호 대상과 반복적으로 연결됨 |

## ② 불편·감각·상황 회피성 (aversive_context_escape)

| 점수 | 기준 |
| --- | --- |
| 0.1 | 불편한 자극이나 상황이 이동에 거의 영향을 주지 않음 |
| 0.3 | 불편함을 표현하지만 장소를 벗어나지는 않음 |
| 0.5 | 특정 상황에서 자리를 피하거나 이동함 |
| 0.7 | 불편 상황에서 보호자 범위를 벗어날 가능성이 높음 |
| 0.9 | 같은 회피 상황에서 실제 실종 또는 반복 이탈 경험이 있음 |

## ③ 루틴·전환 변화 취약성 (transition_routine_disruption)

| 점수 | 기준 |
| --- | --- |
| 0.1 | 일정이나 장소 변화에 비교적 잘 적응함 |
| 0.3 | 변화 시 불안하지만 이동 통제가 가능함 |
| 0.5 | 전환 상황에서 멈춤·거부·되돌아감이 발생함 |
| 0.7 | 루틴 변화 시 보호자와 분리되거나 이탈함 |
| 0.9 | 특정 전환 상황에서 반복적인 실종·이탈 경험이 있음 |

## ④ 이탈 패턴 반복·고착성 (elopement_pattern_consistency)

| 점수 | 기준 |
| --- | --- |
| 0.1 | 이탈 장소·계기·경로가 매번 다름 |
| 0.3 | 일부 유사한 행동이 있으나 일관성이 낮음 |
| 0.5 | 비슷한 장소나 계기가 반복됨 |
| 0.7 | 동일한 목적지·경로·행동이 여러 번 반복됨 |
| 0.9 | 실제 실종에서 거의 동일한 패턴이 반복적으로 확인됨 |
