# 축 점수 기준표 (0.1~0.9 행동 앵커)

작성: 2026-07-16 / 갱신: 2026-08-03 — 대상을 치매 단독으로 좁히면서 발달장애 4축 삭제.
공통 3축·치매 3축은 팀 회의 결과로 확정된 기준표.

채점 대상(EXAONE 0.1~0.9 채점):
- 치매: 공통 3 + 치매 특화 3 = **6축**
- lost_behavior·dementia_wandering_pattern 은 점수 없는 관찰 지표(반응 방향 → 전략 확률)라 이 문서에 없음.

**route_environment_familiarity(경로·환경 익숙함)는 축이 아니다** — 사람 특성이 아니라
(사람, 특정 경로) 쌍의 속성이라 페르소나 단일 점수로 압축하면 정보가 손실된다
(예: "늘 같은 길로만 다녀 그 길에서는 안 헤맴"과 "그 길을 벗어나면 복귀 불가"가 동시에
성립 가능 — 하나의 점수로는 이 둘을 구분 못 함). 이번 개정(2026-07-17)으로 EXAONE
페르소나 채점 파이프라인에서 제외하고, 장소별 관계 변수(`Persona.route_familiarity`,
경로마다 별도 점수)로 분리했다. 실제로 채우는 컴파일러(보호자 발화 → 경로별 점수)는
`phase0/route_familiarity_compiler.py` 에 **구현돼 있다**(PR #44·#45) — 자전적 목적지
유래 끌림점만 채점하고, 자주 가는 곳은 기본 익숙함 0.8 을 쓴다. 채점 기준표는
문서 맨 아래에 있으며 컴파일러가 그 5단계를 그대로 사용한다.

## 축 방향 요약 (P1 프롬프트·정답표에 반드시 명시)

| 축 (axis_field) | 방향: 0.9의 의미 |
| --- | --- |
| mobility_transport_capacity | 이동 능력 큼 (수색 반경 확장 — **위험 아님**) |
| hazard_awareness_vulnerability | 위험 인식 낮음 (취약) |
| communication_approach_vulnerability | 발견·구조 어려움 (취약) |
| autobiographical_destination_pull | 과거 장소 지향이 실종과 반복 연결 (강함) |
| wayfinding_error_recovery_deficit | 길찾기·복귀 손상 심함 (취약) |
| distress_induced_movement_reactivity | 불안이 실제 이탈로 전환됨 (강함) |

## 공통 사다리 구조 (전 축 공통 원칙)

0.1 영향 없음 → 0.3 경향은 보이지만 이동 없음 → 0.5 실제 이동·사건 1회 이상 → 0.7 반복 또는 고위험 → 0.9 실제 실종과 반복 연결.
(능력·예측성 축은 같은 사다리를 "능력의 크기" 순으로 적용)

**판정 규칙** (파일럿 발견 반영, 2026-07-16): 한 사람에게 여러 단계의 근거가
공존하면(예: 신원은 잘 말하는데 유인에 따라감) 발견·구조를 더 어렵게 만드는 쪽,
즉 **더 높은 단계를 우선**한다. 능력·예측성 축(이동·교통 능력)은 반대로
실제 확인된 **최고 수준의 능력**으로 판정한다.

# 공통 3축 (유형 중립 문구)

## ① 이동·교통 능력 (mobility_transport_capacity) — 몸축

| 점수 | 기준 |
| --- | --- |
| 0.1 | 혼자 걷기 어렵거나 실내에서 매우 짧은 거리만 이동 가능함 |
| 0.3 | 집 주변의 짧은 거리만 걸을 수 있으며 장시간 보행은 어려움 |
| 0.5 | 생활권 내에서 약 30분~1시간 정도 혼자 걸을 수 있음 |
| 0.7 | 장시간(수 km) 연속 보행이 가능함 |
| 0.9 | 장거리 보행이 가능하며 실제로 멀리까지 걸어서 이동한 경험이 있음 |

- 점수는 평소 평균 이동량이 아니라, 보호자 없이 실제로 가능한 **최대** 이동 능력 기준.
- **차량 이용·운전 가능성은 이 축에서 제외**(2026-07-17 팀 결정) — 운전 가능은 "이동 능력이
  조금 더 큼"이 아니라 탐색 반경·방법 자체가 통째로 바뀌는 별개 시나리오라 이 축 척도로
  다루지 않는다. (하위변수 `vehicle_use`·`transit_use` 삭제 — 후자는 2026-07-24 안1(대중교통
  미반영) 결정, `slots.py` 동반 수정)

## ② 환경 위험 취약성 (hazard_awareness_vulnerability) — 마음축

| 점수 | 기준 |
| --- | --- |
| 0.1 | 차도, 신호, 물가, 계단 등의 위험을 스스로 인식하고 대부분 피할 수 있음 |
| 0.3 | 기본적인 위험은 인식하지만 낯선 환경이나 복잡한 상황에서는 판단이 불안정함 |
| 0.5 | 위험을 일부 인식하지만 반복적인 안내나 보호자의 확인이 필요함 |
| 0.7 | 차도, 물가, 추락 위험 등을 제대로 인식하지 못하고 위험구역에 들어갈 가능성이 높음 |
| 0.9 | 위험을 거의 인식하지 못하며 교통사고·익사·추락 등의 실제 사고 또는 중대한 위험 경험이 있음 |

## ③ 의사소통·접근 취약성 (communication_approach_vulnerability) — 마음축

| 점수 | 기준 |
| --- | --- |
| 0.1 | 이름과 신원(소속 기관명 포함)을 말할 수 있고 시민·경찰의 질문에 응답하며 도움을 받을 수 있음 |
| 0.3 | 이름을 부르면 반응하고 간단한 대화는 가능하지만 주소나 연락처 설명은 어려움 |
| 0.5 | 이름 반응과 의사소통이 일관되지 않으며 낯선 사람의 도움을 받을 수 있을지 불확실함 |
| 0.7 | 질문에 거의 응답하지 못하고 낯선 사람이 접근하면 무시·회피·멈춤·도주 행동이 나타남 |
| 0.9 | 신원과 도움 요청이 불가능하고 시민이나 경찰의 접근 시 강한 도주·방어 행동으로 위험이 커질 수 있음 |

# 치매 3축

## ① 길찾기 오류·경로 회복 취약성 (wayfinding_error_recovery_deficit) — 마음축

| 점수 | 기준 |
| --- | --- |
| 0.1 | 익숙한 경로와 목적지를 기억하고, 잘못 들어가도 스스로 알아차려 돌아올 수 있음 |
| 0.3 | 낯선 장소에서만 길을 혼동하며 안내나 표지판을 이용해 경로를 회복할 수 있음 |
| 0.5 | 익숙한 생활권에서도 가끔 목적지나 방향을 혼동하고 주변 사람의 간단한 도움이 필요함 |
| 0.7 | 익숙한 동네에서도 자주 길을 잃으며 잘못된 경로를 스스로 알아차리거나 복구하기 어려움 |
| 0.9 | 현재 위치·목적지·방향을 거의 유지하지 못하고 스스로 경로를 복구하는 것이 사실상 불가능함 |

- 권장 하위변수(전략 분기용, 관찰 지표): destination_retention·landmark_recognition·
  intersection_decision·route_error_awareness·route_recovery_ability. 오류를 인식할
  때만 backtracking, 심한 혼란(목적지 자체를 잊음)은 random walk 증가로 반영.

## ② 자전적 기억 기반 목적지 접근성 (autobiographical_destination_pull) — 마음축

| 점수 | 기준 |
| --- | --- |
| 0.1 | 옛집, 과거 직장, 시장 등 과거 장소를 찾거나 언급하는 행동이 거의 없음 |
| 0.3 | 과거 장소를 가끔 이야기하지만 실제로 찾아가려는 행동은 없음 |
| 0.5 | 특정 과거 장소에 가야 한다는 말을 반복하거나 그 방향으로 이동하려 한 적이 있음 |
| 0.7 | 옛집·직장·시장·병원 등 특정 기억 장소를 반복적으로 찾거나 혼자 이동하려 함 |
| 0.9 | 과거 실종에서 동일한 기억 장소 또는 그 주변에서 발견된 경험이 있거나 같은 장소로 반복 이동함 |

- **사람의 일반 성향(이 점수)과 개별 장소는 분리** — 장소별 근거·강도는 `anchors`로
  별도 저장(예: `{"place": "과거 거주지", "place_type": "former_home",
  "evidence": "previous_missing_found", "anchor_strength": 0.9}`). 이 anchors 구조는
  Phase C(evidence 태그, `feat/evidence-preferred-targets`)와 동일 패턴.

## ③ 정서적 불편에 따른 이동 반응성 (distress_induced_movement_reactivity) — 마음축

| 점수 | 기준 |
| --- | --- |
| 0.1 | 불안·초조·의심이 나타나도 이동 행동에는 거의 변화가 없음 |
| 0.3 | 불편함을 표현하거나 안절부절못하지만 장소를 벗어나지는 않음 |
| 0.5 | 불안하거나 의심할 때 걷기 증가, 자리 이동, 출입구 접근 등의 행동이 가끔 나타남 |
| 0.7 | 불안·초조·망상 상황에서 도주, 숨기, 반복보행, 외출 시도 등 뚜렷한 이동 변화가 나타남 |
| 0.9 | 불안·망상·공포로 인해 실제 이탈이나 실종이 발생했거나 같은 반응이 반복적으로 확인됨 |

- 반응 방식(escape/hide/pacing/freeze)은 점수와 별도로 저장 — 점수만으로 회피 장소
  예측 금지. 과거 행동·실종 직전 상황이 확인된 경우에만 특정 장소 가중치 상향.

# 참고: 경로·환경 익숙함 (route_familiarity) — 축 아님, 장소별 관계 변수 [백로그]

EXAONE 페르소나 채점 파이프라인 밖. `routine_destinations` 슬롯이 모으는 근거
(axis_evidence/axis_quotes의 `route_environment_familiarity` 키)는 그대로 쌓이지만,
`scored_axes()`는 이 문서에 없는 축은 자동 제외하므로 채점 호출은 발생하지 않는다.
아래 기준표는 `route_familiarity_compiler` 가 실제로 사용하는 판정 기준이다.

| 점수 | 기준 |
| --- | --- |
| 0.1 | 처음 가거나 거의 경험하지 않은 장소·경로임 |
| 0.3 | 방문 경험은 있지만 혼자 이동한 경험은 거의 없음 |
| 0.5 | 가끔 이용했으며 일부 랜드마크나 구간을 알아봄 |
| 0.7 | 반복적으로 이용한 익숙한 경로이며 평소 혼자 이동한 경험이 있음 |
| 0.9 | 일상적으로 반복 이용하고 최근까지도 독립적으로 이동한 핵심 생활경로임 |

목표 스키마(예): `Persona.route_familiarity: [{"route": "집-시장", "score": 0.9}, ...]`
— 경로마다 따로 저장. 단일 페르소나 점수로 뭉치지 않는다.
