# 축 점수 기준표 (0.1~0.9 행동 앵커)

작성: 2026-07-16 / 갱신: 2026-07-17 — 공통 3축·치매 3축 = **팀 확정본**(회의 후 팀원 전달, 임의 수정 금지)
으로 교체. 발달 4축도 팀 확정본(불변).

채점 대상(EXAONE 0.1~0.9 채점):
- 치매: 공통 3 + 치매 특화 3 = **6축**
- 발달장애: 공통 3 + 발달 특화 4 = 7축
- lost_behavior·dementia_wandering_pattern 은 점수 없는 관찰 지표(반응 방향 → 전략 확률)라 이 문서에 없음.

**route_environment_familiarity(경로·환경 익숙함)는 축이 아니다** — 사람 특성이 아니라
(사람, 특정 경로) 쌍의 속성이라 페르소나 단일 점수로 압축하면 정보가 손실된다
(예: "늘 같은 길로만 다녀 그 길에서는 안 헤맴"과 "그 길을 벗어나면 복귀 불가"가 동시에
성립 가능 — 하나의 점수로는 이 둘을 구분 못 함). 이번 개정(2026-07-17)으로 EXAONE
페르소나 채점 파이프라인에서 제외하고, 장소별 관계 변수(`Persona.route_familiarity`,
경로마다 별도 점수)로 스키마만 분리해뒀다. 실제로 채우는 컴파일러(보호자 발화 →
경로별 점수)는 **미구현 — 백로그**. 참고용 기준표는 문서 맨 아래에 남겨둔다.

## 공통 사다리 구조 (발달 4축에서 역추출, 전 축 공통 원칙)

0.1 영향 없음 → 0.3 경향은 보이지만 이동 없음 → 0.5 실제 이동·사건 1회 이상 → 0.7 반복 또는 고위험 → 0.9 실제 실종과 반복 연결.
(능력·예측성 축은 같은 사다리를 "능력의 크기" 순으로 적용)

**판정 규칙** (파일럿 발견 반영, 2026-07-16): 한 사람에게 여러 단계의 근거가
공존하면(예: 신원은 잘 말하는데 유인에 따라감) 발견·구조를 더 어렵게 만드는 쪽,
즉 **더 높은 단계를 우선**한다. 능력·예측성 축(이동·교통 능력)은 반대로
실제 확인된 **최고 수준의 능력**으로 판정한다.

# 공통 3축 (치매·발달 공용 — 유형 중립 문구) [팀 확정본, 2026-07-17]

| 점수 | 기준 |
| --- | --- |
| 0.1 | 혼자 걷기 어렵거나 실내에서 매우 짧은 거리만 이동 가능함 |
| 0.3 | 집 주변의 짧은 거리만 이동 가능하며 장시간 보행과 교통수단 이용은 어려움 |
| 0.5 | 생활권 내에서 약 30분~1시간 정도 혼자 걸을 수 있으나 대중교통은 혼자 이용하기 어려움 |
| 0.7 | 장시간 보행이 가능하거나 익숙한 버스·지하철 노선을 혼자 이용할 수 있음 |

  조금 더 큼"이 아니라 탐색 반경·방법 자체가 통째로 바뀌는 별개 시나리오라 이 축 척도로
  다루지 않는다. (하위변수 `vehicle_use` 삭제, `slots.py` 동반 수정)

| 0.7 | 옛집·직장·시장·병원 등 특정 기억 장소를 반복적으로 찾거나 혼자 이동하려 함 |

# 참고: 경로·환경 익숙함 (route_familiarity) — 축 아님, 장소별 관계 변수 [백로그]

EXAONE 페르소나 채점 파이프라인 밖. `routine_destinations` 슬롯이 모으는 근거
(axis_evidence/axis_quotes의 `route_environment_familiarity` 키)는 그대로 쌓이지만,
`scored_axes()`는 이 문서에 없는 축은 자동 제외하므로 채점 호출은 발생하지 않는다.
아래 기준표는 컴파일러(경로별 점수 추출, 미구현)를 만들 때 참고용으로 남겨둔다.

| 점수 | 기준 |
| --- | --- |
| 0.1 | 처음 가거나 거의 경험하지 않은 장소·경로임 |
| 0.3 | 방문 경험은 있지만 혼자 이동한 경험은 거의 없음 |
| 0.5 | 가끔 이용했으며 일부 랜드마크나 구간을 알아봄 |
| 0.7 | 반복적으로 이용한 익숙한 경로이며 평소 혼자 이동한 경험이 있음 |
| 0.9 | 일상적으로 반복 이용하고 최근까지도 독립적으로 이동한 핵심 생활경로임 |

목표 스키마(예): `Persona.route_familiarity: [{"route": "집-시장", "score": 0.9}, ...]`
— 경로마다 따로 저장. 단일 페르소나 점수로 뭉치지 않는다.
