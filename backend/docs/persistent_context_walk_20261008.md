# 미확인 사실을 시간에 걸쳐 보존하는 실행 후보

PersistentContextPopulation은 PlaceBoundPopulation을 확장한 연구 실행기다. 단어 파싱이나 새 K 응답 없이 저장된 개인 규칙을 실행한다. 운영 API의 기본 Population은 바꾸지 않았다.

새 정보 없이 휴식 후보가 생길 때마다 행동을 다시 추첨하던 방식은 대기로 쏠렸다. 후보는 사실별·장소별 가정을 보존하고, 유효 관측이 있으면 그것을 우선하며 만료 시 새 미확인 구간으로 표시한다. 원래 입력 사실은 None으로 유지한다. 기본 동일 가중은 임상 확률이 아니다. 새 관측이 없는 내부 상태의 자연 변화율을 만들지 않는다.

명시적 대기 시간은 시작부터 계산하며 매 분 연장하지 않는다. 만료 후 같은 조건에서는 바로 재시작하지 않고 조건 해제 후 재발동한다. 이동 조건으로 시작된 대기는 스스로 멈췄다는 이유로 즉시 해제하지 않으며, 외부 조건 해제는 반영한다. 시간 미제공 대기에 개인 재출발 시간을 만들어 넣지 않는다.

기존 Population에는 선택·대기 마감 계산 훅과 상태 저장 필드, 실행기 계열 검사만 추가했다. 일반 실행기의 선택 결과는 그대로다. 가정 방식이 다른 실행기 간 체크포인트를 조용히 재사용하지 않는다.

검증:
- 신규17개 포함 관련92개 통과.
- 실제 앱 합성1개·저장 D12 출력·3시드×500명×6시간: 기존 모두 대기 → 후보 대기204~213명, 나머지 이동·휴식 지속.
- 알려진 휴식·회피 2장면의 시간별 분포·집계는 기존과 동일.
- 저장된48개 규칙의 기준선/후보 실행에서 오류·지도 미완주 없음. 공통 초기 기본값의 실행 검사이며 행동 정답48/48이 아니다.
- 자각 가중0.1/0.9에서 대기131~288명: 실제 확률이 아니며 가정 민감도를 별도 공개.

초기 클래스명 저장 검사로 깨진3건과 확정된 행동 충돌 선택을 바꿔 생긴 회귀는 수정하고 재검증했다. 수정 전 실패도 연구 기록에 보존했다.

연구 PR #272의 evidence_20261008/persistent_context/README.md에 원인 재현·그림·전체 분모·소스 해시가 있다. 이 변경은 반복 추첨 편향 수정까지의 근거이며 임상 타당성이나 운영 배포 완료 판정이 아니다.

명시 시간 종료 뒤에는 기존 초기 성향을 따른다. 초기 머무름 성향에서는 해당 개인 대기 규칙이 끝나도 기본 대기가 계속될 수 있다. 원문이 후속 보행까지 명시한 경우의 행동 전이 계약은 별도 과제다. 근거 없이 후속 보행을 강제하지 않는 보충 검사를 남겼다.
