# 발견 후 예측 종료 경계 — 2026-10-08

확인된 발견·안전 확보는 실종 사건의 종료다. 가족 귀환을 마음 규칙의 해제 후 재출발로 처리하는 연구 장면과 서비스 수명주기를 구분한다. family_present만으로 사건을 자동 종료하지 않는다.

## 수정

- pipeline.run_prediction, poa_at_elapsed, continuous_prediction.run/run_pair는 종결 검사를 모델·지도·정책 조회 전에 수행한다.
- ensure_not_closed는 전달받은 객체와 저장소의 최신 사건을 확인한다. 대기열의 오래된 활성 복사본으로 종결 사건을 되살리지 못한다.
- close_case와 예측·미리보기는 기존 사건별 재진입 잠금을 공유한다. 종결 시 최신 저장 객체를 사용하여 이미 계산된 결과를 오래된 복사본으로 덮지 않는다.
- 일반/디버그 예측 API는 내부 진입 시 종결된 경쟁 상황도 409로 반환한다.
- 시간 슬라이더는 종결 사건의 캐시가 있어도 추가 시간 예측을 거절한다. 시간 인수 없이 이미 저장된 마지막 지도를 읽는 것은 과거 기록 조회다.

## 검증과 한계

관련 5개 테스트 파일 57개 통과. 신규 종료 경계 검사는 11개다. 내부 예측, 과거 복사본, 캐시 유무, 연속 예측, 자동 갱신, API 진입 경쟁, 동시 종결을 검사했다. 확인 전 7개 실패·1개 통과로 누락된 경계를 재현했으며 이후 두 API 경쟁 검사와 동시성 검사를 추가했다. 새 외부 모델·지도·GPU 호출은 없다.

현재 잠금은 **단일 프로세스** 범위다. 종결 요청이 진행 중 예측을 즉시 취소하지 않고, 해당 예측의 완료 후 종결을 확정한다. 여러 작업자 프로세스·DB 분산 잠금·강제 취소를 검증한 것은 아니다. 시뮬레이션 자체의 미확인 상태 대기 쏠림을 해결한 변경도 아니다.

연구 PR #272의 evidence_20261008/search_scope/README.md에 원문 해석·사건 종료·미확인 관측을 구분하는 평가 정정과 새 오프라인 결과를 남겼다. 기존 500명×3상황 회귀는 합성 조건을 제공한 부품 검사이며, 발견 후 예측의 정당성이나 임상 행동 정확도를 뜻하지 않는다.
