# 등록 목적지와 마음 행동 규칙의 연결 복구

보호자가 등록 대화에서 말한 망원시장은 인터뷰 원문에 남아 있었지만, 장소 검색에 실패한 뒤 확정 프로필에서 빠졌습니다. 그 결과 마음 규칙 생성 입력의 등록 목적지 목록도 비었고, 목적지로 향하는 규칙이 `seek_without_registered_goal`로 제외되었습니다. 별도로 보행 능력을 무조건 이동 규칙으로 표현한 출력도 조건 검사에서 제외되었습니다.

## 수정

- 이름이 있는 목적지의 좌표를 확인하지 못하면 등록을 완료하지 않습니다. 답변, 집 위치, 목적지 초안은 보존하며 확인을 이어갑니다.
- 사전에 받은 OSM 지도에서 이름과 좌표를 확인한 장소 후보를 사용합니다. 후보 선택과 재확인은 기존 Mi:dm 절차를 유지합니다. 장소 캐시는 집 주소를 대신 정하지 않습니다.
- 앞의 검색 제공자가 빈 결과를 반환하면 다음 제공자로 넘어갑니다. Nominatim 검색 결과도 기존 후보 선택 절차에 전달합니다.
- 마음 규칙 수정 요청에 실패한 규칙 전체의 오류를 전달합니다. 보행 능력만으로 무조건 이동 규칙을 만들지 않고, 원문에 있는 휴식 조건과 시간을 보존하도록 명시합니다.
- 규칙 검증기, 지도 결합 비율, 알림 면적과 예측 엔진의 선정 기준은 변경하지 않습니다.

## 지도 캐시

`ROADNET_CACHE_DIR/bundles/named-places.json`의 선택적 캐시를 사용합니다. 파일이 없거나 유효하지 않으면 기존 검색 제공자로 넘어갑니다. 앵커 위치가 해당 범위 밖인 경우에도 캐시를 사용하지 않습니다.

필수 형식: `schema_version: 1`, 원본의 `source_sha256`, `[south, west, north, east]` 순서의 `bbox_south_west_north_east`, `places` 목록. 각 장소에는 `name`, `lat`, `lng`, `osm_type`, `osm_id`, `precision`을 보존합니다. 출처와 OSM 이용조건도 캐시 메타데이터에 기록합니다.

이번 캐시는 이미 확보한 Geofabrik의 `south-korea-261025.osm.pbf`에서 추출했습니다. 망원시장의 OSM 식별자는 `node/4196342490`입니다. 새 지도 API 호출은 없습니다. 캐시는 범위 안의 이름 있는 OSM 노드 37,777개를 포함하며 모든 지역과 모든 장소를 포함하는 데이터가 아닙니다.

출처: [Geofabrik South Korea](https://download.geofabrik.de/asia/south-korea.html), © OpenStreetMap contributors, ODbL 1.0.

## 검증

외부 연결을 차단한 관련 테스트 183개 통과, 기존 테스트 2개 건너뜀. 목적지 누락 방지, 빈 검색 결과 후 다음 제공자 사용, 집 위치와 입력 보존, 모든 규칙 오류 전달, 기존 서비스 준비와 보행 연동을 검사했습니다.

실제 모델 재검증은 기존 합성 보호자 답변과 등록 장소를 사용하며 별도 결과에 기록합니다. 단위 테스트 통과를 실제 모델의 의미 정확도 또는 새 실종 신고·푸시 검증으로 간주하지 않습니다.
