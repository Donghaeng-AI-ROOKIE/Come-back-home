# 지역 도로망 사전 저장 및 망원 적용 — 2026-10-26

KINTEX 고정 지도 범위 밖의 신고가 동적 로더에 도달하지 않고 도로망 없는 예측으로 빠지던 분기를 수정했다. 준비된 지역은 Supabase Storage의 비공개 지도 파일과 서버 영구 캐시를 사용한다.

## 로딩 순서
1. 기존 검증된 KINTEX 지도 범위 안: 기존 경로 유지.
2. 범위 밖: `ROADNET_CACHE_DIR/bundles/index.json`에서 요청 반경 전체를 포함하는 준비된 지도 선택.
3. 서버 캐시의 SHA-256을 확인한다. 없거나 손상되면 같은 Supabase 프로젝트의 비공개 `road-network-cache` 버킷에서 불변 지도 파일을 받아 해시 검증 후 저장한다.
4. 준비되지 않은 지역은 기존 동적 도로망 로더로 넘어간다. 전국 모든 지역의 사전 적재 완료를 의미하지 않는다.

서버 배포/지도 준비 단계에서 Storage의 index.json을 내려받아 영구 캐시에 설치한다. 신규 지역을 Storage에 업로드한 것만으로 실행 중인 서버 index가 자동 갱신되는 구조는 아니다. 새 지역 준비 시 index 동기화가 필요하다. 기존 지도와 DB를 교체하거나 KINTEX를 망원으로 덮어쓰지 않는다.

## 망원 지도
- 공개 망원역 기준 반경 6.5km, 54,068개 노드와 153,100개 연결.
- Geofabrik의 2026-10-25 한국 OSM 추출물에 OSMnx 보행 필터를 적용하고 OSMnx 2.1.1로 보행 그래프를 생성했다.
- [지도 출처와 해시](mangwon-manifest.json). OpenStreetMap contributors, [ODbL / 저작자 표시](https://www.openstreetmap.org/copyright).
- 압축 지도 약 6.3MB. Supabase 업로드 후 다시 내려받은 그래프의 SHA-256 일치 확인.
- 지도는 도로 연결 자료다. 추가 환경부 토지피복 및 OSM 환경 거리 레이어는 이번 파일에 포함하지 않았다. 실제 혼잡·소음 관측값으로 해석하지 않는다.

## 검증 결과
- 관련 회귀검사 17개 통과: 고정 지역 범위 밖 연결, 준비된 지도 우선 사용, 요청 범위 확인, 손상 검출·복구, 디스크 캐시 재사용.
- 외부 네트워크를 차단한 별도 컨테이너에서 기존 합성 개인 프로필을 이용한 1시간 재생 검증. 운영 사건의 시각이나 상태는 변경하지 않았다.
- 개인화 30%, 문헌통계 70%, res9, 최대 알림 면적 5.8㎢ 유지.
- 개인 마음 정책 ready, 연속 보행 엔진 사용, 미계산 확률 0, 최종 확률 합 1.0, 확률지도 869셀, 알림 대상 80셀.
- 최초 지도 로딩 19.565초, 같은 프로세스 내 재사용 0.288초. 예측 전체 소요시간을 뜻하지 않는다.
- 운영 이미지 `cbh-cloud-worker:20261026-road-bundles` 배포: 2026-10-26 17:14 KST. 기존 이미지와 환경·DB 보존, 작업 heartbeat가 없는 상태에서 교체.
- 배포된 컨테이너의 실제 로더도 외부 지도 요청 0회로 동일 해시의 망원 지도를 반환했다.

이 검증에는 모델 신규 호출이나 실제 푸시 발송이 없다. 새 신고의 앱 화면 표시와 동일 사건의 OS 알림 재수신은 별도 E2E 확인 사항이다. 기존 운영 사건의 과거 확률지도는 이번 검증을 위해 덮어쓰지 않았다.

## 공개 지도 확보 과정
실시간 Overpass 요청은 서버에서 HTTP 502/응답 대기 초과, 로컬에서 HTTP 406/429로 실패했다. 실시간 질의 재시도를 중단하고 공개 배포된 원본을 서버에서 내려받아 추출했다. 원본 다운로드 290,087,135바이트, 약 32.5초. 성공·실패 시도와 Storage 사용량은 연구지원 원장에 기록했고 금액은 미확인이다.
