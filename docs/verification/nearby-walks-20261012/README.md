# 주변 산책 추천 복구 — 2026-10-12

마포구 시민 화면의 빈 추천을 확인했다. 운영 로그는 개인정보 없이 서버 내부에서 오류 종류만 집계했으며 HTTPError3·TimeoutError3을 확인했다. 사용자GPS는 읽거나 검증 입력으로 쓰지 않았다.

## 원인과 수정

- 외부 지도 오류를200+빈 목록으로 숨겨 ‘주변 장소 없음’으로 표시했다. 이제실패는503·재시도 안내로 구분한다.
- 대체서버`overpass.osm.ch`는 스위스 데이터 전용이다. 한국 조회에 맞는 global 서버2개로 정리했다. 이전kumi 서버의 현재주소는private.coffee다. [OSM 공식 서버목록](https://wiki.openstreetmap.org/wiki/Overpass_API#Public_Overpass_API_instances).
- Overpass HTTP200의timeout remark도실패로 처리한다. 최대2서버·각15초, 클라이언트45초대기로 변경한다. 별도경로검색/모델호출을 추가하지 않는다.
- 성공한빈 결과를서버 메모리에영구캐시하지 않고앱 캐시도5분으로제한한다. 다시검색 버튼과화면새로고침에추천재조회도연결한다.
- 이름 있는400m이상OSM구간·반경2km 필터와길이계산은유지한다. 모든산책가능도로의경로생성이나접근가능성보증은아니다. 특히공원카드는공원경계이지검증된공원내부통행경로가아니다.
- 좌표수집설명 주석을정정했다: 산책조회는현재좌표를서버와공공지도로전송한다. 비용원장에는좌표·쿼리·보호자자료를넣지않는다. 실패·재시도도기록하며금액은미확인이다.

## 검증 상태

백엔드geo·bridge·auth·walk44검사,프런트29검사,TypeScript통과. 실제화면컴포넌트의오류/빈목록구분·재검색·당겨새로고침·경로표시를외부컴포넌트만대체하여검사했다. 실기기GPS의성공판정은아니다.

첫온라인검사는기존GPU서버에서공개마포/킨텍스지점으로최대4회,8초상한으로수행했다. 마포는두서버시간초과,킨텍스는한서버실패뒤실제4개경로수신. 원본공공지도의시각·범위·쿼리·해시를격리검증폴더에보존하고예측용KINTEX자산은교체하지않았다. 이후15초상한마포추가2회는자동승인검토가범위초과로차단해사용자승인을요청했다. 승인/실제결과가완료되기전마포성공또는배포완료로쓰지않는다.
