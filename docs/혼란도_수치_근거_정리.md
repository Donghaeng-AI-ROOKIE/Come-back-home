# 혼란도 수치 근거 정리 (2026-08-04)

혼란도(confusion)는 시뮬레이터에서 **방향이 얼마나 흩어지는가** 하나를 정하는
파라미터다. 이 문서는 그 경로에 들어간 **모든 수치**를 나열하고, 각각이 문헌
근거인지 잠정값인지 구분한다.

작성 이유: 제안서·발표에서 "이 값은 어디서 나왔습니까"에 답할 수 있어야 하는데,
현재 코드 주석은 방향("혼란할수록 흩어진다")만 적고 수치 출처를 적지 않는다.
근거 있는 것과 없는 것을 섞어 말하면 있는 근거까지 신뢰를 잃는다.

---

## 1. 구성개념 — 근거 있음

"방향 흩어짐"이라는 변수를 두는 것 자체는 문헌에 근거가 있다.

| claim | 진술 | 출처 |
|---|---|---|
| CLM-0031 | **공간적 방향상실과 지속 보행이 배회의 핵심 차원**을 이룬다 | DEM-33 p11 (Algase Wandering Scale 심리측정) |
| CLM-0022 | 초기에는 낯선 곳의 길찾기가 손상되고, **진행되면 익숙한 주변에서도** 어려워진다 | DEM-34 p6 |
| CLM-0025 | 길찾기 능력이 **낮을수록** 이탈행동과 공간적 방향상실이 더 많이 나타난다 | DEM-26 p1 |
| CLM-0015 | 공간적 방향상실이 발생하면 **길찾기 오류를 스스로 회복하지 못한다** | DEM-31 p6 |
| CLM-0008 | 익숙한 장소에 있더라도 길찾기 표시를 알아보지 못할 수 있다 | DEM-24 p6 |

여기서 따라 나오는 설계 함의 두 가지:

1. **방향상실은 사람의 특성에 가깝다.** Algase 척도는 보호자가 평소 관찰한
   경향을 점수화하는 도구이고(CLM-0031), 중증도에 따라 달라진다(CLM-0022).
   순간순간 변하는 상태로 두면 문헌 구성개념과 어긋난다.
2. **기능 수준에서 뽑는 것이 맞다.** 길찾기 능력이 낮을수록 많다(CLM-0025).

이 두 가지가 "혼란도를 LLM 이 매 호출 내는 값이 아니라 등록 시 정해지는
페르소나 속성으로 둔다"는 현재 방향을 뒷받침한다. LLM 이 혼란도를 못 낸
실측(2026-07-30 8셀 비교, 고득점 셀 전원 "중" 퇴화)도 이것으로 설명된다 —
상황마다 다른 값을 요구했는데 실제로는 사람 특성이라 낼 것이 없었다.

## 2. 수치 — 전부 잠정값 (근거 없음)

방향 분산을 **각도(라디안)나 집중도(κ)로 보고한 연구가 코퍼스 13편에 없다.**
아래 수치는 어느 것도 논문에서 나오지 않았다.

### 2-1. 등급 → 수치 (`guardrail.CONFUSION_LEVELS`)

| 등급 | 값 | 근거 |
|---|---|---|
| 상 | 0.85 | 없음 |
| 중 | 0.6 | 없음 |
| 하 | 0.35 | 없음 |

### 2-2. 수치 → 보행 (`simulation.py`)

| 식 | 값 | 근거 |
|---|---|---|
| `kappa = max(0.2, 2.5 × (1 − 혼란도))` | 2.5, 하한 0.2 | 없음 |
| `wobble = 0.3 + 혼란도 × 0.9` (rad) | 0.3, 0.9 | 없음 |
| 목표 있을 때 `gauss(0, wobble × 0.5)` | 0.5 | 없음 |
| `direction_keeping` 시 `gauss(0, wobble × 0.3)` | 0.3 | 없음 |

### 2-3. 규칙 산정 (`phase2/confusion_rule.py`)

| 조건 | 값 | 근거 |
|---|---|---|
| 정보 빈약(모름 2회 이상) | 0.65 | 없음 — dev 판정 범위에 맞춘 값 |
| 손상−명료 ≥ +2 | 0.70 | 없음 — 동일 |
| 손상−명료 ≤ −2 | 0.40 | 없음 — 동일 |
| 그 외 | 0.60 | 없음 — 동일 |
| 불안 상황 보정 | +0.15 | 없음 — dev 8상황에서 판정자 범위가 일관되게 상방이었다는 관찰 |

⚠ 이 다섯 값은 **dev(G01~G04)를 보고 정했다.** dev 적합 8/8 은 일반화 증명이
아니다. 봉인 test 로 검증되지 않았다.

### 2-4. 폴백

| 상황 | 값 | 근거 |
|---|---|---|
| LLM 실패·풀 고갈 | `현재값 + 0.2` | 없음 |
| 마음 미사용 | 0.5 | 없음 (중립값) |

## 3. 대외 인용 시 지켜야 할 구분

- **말해도 되는 것**: "치매 배회의 핵심 차원으로 공간적 방향상실이 보고되며
  (Algase 척도), 기능 수준이 낮을수록 더 많이 나타난다. 우리는 이를 개인 특성
  파라미터로 모델링해 보행 방향의 분산에 반영한다."
- **말하면 안 되는 것**: "혼란도 0.85는 문헌 값이다", "κ 2.5는 논문 근거다"
  — 어느 것도 사실이 아니다.
- 수치를 물으면 **"보행 분산을 각도로 보고한 선행 연구를 찾지 못해 잠정값을
  쓰고 있고, 골드셋 판정 범위로 간접 검증했다"**가 정확한 답이다.

## 4. 근거를 붙이려면

우선순위 순.

1. **등급→수치와 규칙값을 골드셋으로 역산.** 판정자 3인이 합의한 confusion
   범위가 실측 데이터다. 지금은 규칙이 그 범위에 "들어가는지"만 보는데,
   범위 중앙값에 맞추는 최적화로 값을 정하면 "판정 합의에서 도출"이라는
   근거가 생긴다. dev 만 쓰면 과적합이므로 test 확대가 선행돼야 한다.
2. **κ·wobble 은 궤적 데이터로만 검증 가능.** GPS 궤적에서 방향 전환 각도
   분포를 재야 하는데, 코퍼스에 그런 논문이 있는지 재검색이 필요하다
   (DEM-30 이 시공간 보행 파라미터를 다루지만 보폭·속도이지 방향이 아니다).
   없으면 "잠정값 + 민감도 분석"으로 가는 것이 정직하다.
   실제로 P2-2 실험(`experiments/prior_mapping`)이 μ 보정폭에 대해 같은 방식을
   썼다 — 최적값을 주장하지 않고 **폭주 구간을 피하는 상한**을 실측으로 정했다.
3. **wayfinding_error_recovery_deficit 축 점수로 교체.** 현재 규칙 입력은
   보호자 진술 정규식 매칭이라 표현이 목록을 벗어나면 못 잡는다. 축 채점은
   기준표를 주고 LLM 이 A~F 로 판정하므로 어휘 의존이 사라진다.
   (`.env` 의 `AXIS_SCORING_ENABLED` 가 꺼져 있어 켜는 비용 검토가 선행.)
