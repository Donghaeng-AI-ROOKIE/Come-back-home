# 최종 알림 정책 확정 — 2026-10-12

사용자 지시 “그러면 그냥 지금까지 중에서 제일 좋은걸로 픽스하자”에 따라 기존에 구현·검증된 **개인화30% + 문헌 통계70%, 실제 알림res9, 면적 상한5.8㎢**를 최종 선택한다. 이번 목표의 추가 후보 탐색은 종료한다. 선택은 지금까지 검증한 후보 중 개인화 준수 보존·면적당 효율·기존 앱/웹/발송 연결을 함께 고려한 출시 정책 결정이며, 모든 행동에서 최적이라는 통계적 증명은 아니다.

## 고정한 설정

독립적으로 계산한 개인화 보행 지도와 문헌 거리분포 지도를 결합한다. 가중치30%는 개인화 규칙의 실행 비율이나 준수 적중률이 아니다. 면적 상한은 실제 발송 해상도의 지리적 구역 합집합으로 계산한다. 적용되는 코드 기본값은 `backend/app/config.py`에 이미 일치하며 이번 확정으로 모델·보행·알림 구현을 변경하지 않는다. 확정 당시에는 운영 배포를 수행하지 않았으나, 이후 사용자 승인으로2026-10-12 최종 worker·웹 앱을 배포하고 실제 설정과 인증된 예측 응답까지 확인했다. [배포 증빙·범위](../releases/final-service-deploy-20261012.md).

전체 효율은 전체 정답 위치 포함률(%) / 평균 알림 대상 면적(㎢)이다. 확정안은 이번 새 확인에서 본선 대비 전체 포함률+10.22%p, 개인화 준수+22.54%p, 면적당 효율+28.18%다. 기존 #286의 별도 새 확인1231–1233에서는 본선 대비 효율 개선의95% CI가 양수였고, 동일 면적 상한의 통계만 대조군보다 준수+21.05%p(CI[14.74,27.88])였다. 두 표본의 수치와 검정을 섞지 않는다.

방향5% 추가는 현재 적중을 보존하고 반대 포함률을 높였지만, 현재 대비 전체 효율 차이95% CI[-0.0777,+0.2959]로 개선이 확인되지 않았다. 평균 면적을 늘리는 새 선택기를 운영에 도입하지 않는다. 개인화50% 이상/res8 후보는 준수 보존 기준을 만족하지 못했다. 방향20% 예약안의 더 높은 효율만으로 준수 손실6.94%p를 받아들이지 않는다. 따라서 추가안이나 res8을 최종 기본값으로 바꾸지 않는다.

반대 행동 포함률은 이 표본에서 본선보다2.88%p 낮다. 본선 대비 반대 행동의 우월성·비열등성은 입증하지 못했고, 확정안은 반대 행동 **678/936판정**을 놓쳤다. 본선이 맞춘 개별 경로를 모두 보존하지도 않는다. 최종 선택은 이 문제를 해결했다는 선언이 아니다. 실제 발견률·수신률·임상 정확도·원화 발송 비용도 검증하지 않았다.
