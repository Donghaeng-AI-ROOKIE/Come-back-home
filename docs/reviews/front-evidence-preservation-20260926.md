# 앞단 수정과 배포 판정 — 2026-09-26

선행 PR #252 위의 수정이다. 실제 모델 정확도가 배포 기준을 넘었다고 판정한 변경이 아니다.

## 수정 이유와 동작

1. 가족 이름만 수정해도 앱이 행동 요약 전체를 보내고, 서버는 이를 보호자가 원문 전체를 대체한 것으로 처리했다. 이제 앱과 서버 모두 실제 변경을 구분한다. 행동 수정·삭제는 바뀐 항목의 before/after와 수집 시각만 별도 저장한다. 다른 질문·답은 계속 K에 전달한다.
2. 오래전에 등록한 사람이 사건 후 현재 목적지를 추가해도 최초 등록일 때문에 과거로 내려갔다. 이제 K가 현재 의도로 판단한 값에 인용된 근거의 수집 시각을 확인한다. 관계없는 최신 수정은 오래된 목적지를 되살리지 않는다. 수집 시각과 관찰 시각은 다르므로 과거 사건 문맥을 현재 의도로 해석하지 않도록 명시한다.
3. 제품 Mi:dm 클라이언트를 공통 사용량 기록 함수로 연결했다. 성공·실패·토큰을 기록하고 원문·키·오류 응답 본문은 기록하지 않는다. 단가·청구액이 미확인일 때 0원으로 만들지 않는다.

새 수정 기록은 공개 Persona 응답에서 제외한다. K 준비 버전을 v4로 올려 기존 해석을 새 계약의 결과로 오인하지 않는다. 이전 결과는 stale 상태에서 SAR 기준선을 사용하며, 기존 프로필의 유료 재준비는 자동 일괄 실행하지 않는다. 삭제·종결 등 기존 개인정보 수명주기는 그대로 유지한다.

- 입력 근거 메타데이터 보강 후 관련 테스트 38개 추가 재확인.

- Mi:dm 성공/실패 원장 테스트: 요청 본문·키 비기록 및 토큰 보존.

이는 코드 연결 테스트이며 새 K 실호출 의미 평가가 아니다. 정정 전후 원문을 함께 읽는 새 입력을 K가 실제로 적절히 해석하는지는 별도 확인해야 한다.

## 배포 범위

맥미니 운영본은 bcfc811이다. 검증 후보는 별도 localhost 포트와 빈 저장소, 모델 키 없이 올려 부팅·API 연결만 확인한다. 운영 데이터와 원래 컨테이너를 교체하지 않는다. 실제 모델 의미 검증, 준비 실패 상태의 복구 동선, API 접근 제어가 확인되기 전에는 일반 이용자 대상 수색 운영에 배포했다고 보고하지 않는다.

접근 제어는 별도 미해결: 기존 /phase0 API는 인증·소유권 검증이 없다. 이 변경이 이를 해결한 것으로 주장하지 않는다.
